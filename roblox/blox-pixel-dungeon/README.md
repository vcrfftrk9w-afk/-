# Blox Pixel Dungeon

Перенос **[Shattered Pixel Dungeon](https://github.com/00-Evan/shattered-pixel-dungeon)** на Roblox: пошаговый рогалик с той же графикой, монстрами и формулами боя, переписанный на Luau. Так же поступил автор переноса OpenFront: игра открытая, лицензия GPL-3.0 разрешает брать её код и графику и переделывать.

Версия 0.1 — **глава 1, Канализация**: этажи 1–5 и босс Гу.

## Как запустить (5 минут)

1. Скачайте файл [`BloxPixelDungeon.rbxlx`](BloxPixelDungeon.rbxlx). На GitHub откройте его и нажмите кнопку **Download raw file**.
2. Откройте **Roblox Studio** → **File → Open from File…** → выберите скачанный файл.
3. Нажмите **Play** (F5). Появится титульный экран, нажмите «Играть».

Графика встроена в сам файл. При запуске игра распаковывает её через `EditableImage`, загружать картинки не нужно.

### Если вместо графики цветные квадраты

Значит, Roblox не дал создать `EditableImage`: эта функция требует разрешения, а в опубликованных играх её могут отключить. Решение — один раз загрузить картинку:

1. В Studio: **View → Asset Manager → Bulk Import** и выберите файл [`assets/atlas.png`](assets/atlas.png).
2. В Asset Manager нажмите на загруженную картинку правой кнопкой → **Copy Asset ID**.
3. Откройте `ReplicatedStorage → BPD → Config` и вставьте ID:
   ```lua
   ATLAS_ID = "rbxassetid://ВАШ_ID",
   ```

Перед публикацией так лучше сделать в любом случае: с загруженной картинкой графика работает у всех игроков.

## Как опубликовать

1. **File → Publish to Roblox**, придумайте название (не «Shattered Pixel Dungeon» — это имя оригинала, его брать нельзя).
2. В описание игры добавьте:
   > Основано на Shattered Pixel Dungeon (Evan Debenham), лицензия GPL-3.0. Исходный код: github.com/vcrfftrk9w-afk/-/tree/main/roblox/blox-pixel-dungeon
3. В Creator Hub откройте доступ к игре (Public).

### Условия лицензии (важно!)

GPL-3.0 разрешает всё это, но с условиями:
- исходный код вашей версии должен быть открыт. Он лежит в этом публичном репозитории, а ссылка есть в игре (кнопка «Об игре»);
- титры авторов оригинала удалять нельзя (окно «Об игре»);
- изменённая версия тоже распространяется под GPL-3.0;
- игру нельзя называть «Shattered Pixel Dungeon», так просит автор оригинала.

## Что уже есть

- **Подземелье**: генерация комнат и коридоров с дверями, вода и высокая трава (тот же клеточный автомат, что в SPD), объёмные стены с нависающими верхушками, туман войны, поле зрения на 8 клеток. Можно ходить вверх и вниз, этажи сохраняются.
- **Воин**: 20 ОЗ, сила 10, изношенный короткий меч и тканая броня. Уровни прокачки: +5 ОЗ, +меткость, +уклонение.
- **Монстры** с оригинальными характеристиками и анимациями: сумчатая крыса, сточная змея, гнолл-разведчик, сточный краб, слизень. ИИ как в SPD: спят, бродят, охотятся, замечают по формуле скрытности. Внезапные атаки по спящим всегда попадают.
- **Босс Гу**: накачивается жижей для тройного удара на 2 клетки, лечится в воде, накладывает едкую слизь, которая смывается водой.
- **Бой**: формулы попадания, урона, брони и штрафы за нехватку силы перенесены из `Char.java`, `Weapon.java`, `Armor.java`.
- **Предметы**: 10 видов оружия, 4 вида брони, улучшения +1/+2. 6 зелий и 6 свитков, у которых в каждой партии свои случайные цвета и руны, их надо опознавать. Еда, золото, рюкзак на 20 ячеек.
- **Голод и регенерация**: «голоден» после 300 ходов, «истощён» после 450, 1 ОЗ за 10 ходов.
- **Интерфейс**: панель здоровья и опыта, журнал, рюкзак, окна предметов, кнопка атаки ближайшего врага, осмотр клеток, полоса здоровья босса.
- **Рекорды**: таблица лидеров (глубина и победы) с сохранением в DataStore.
- Тексты на русском взяты из официального перевода SPD.

## Чего пока нет

Остальные главы (тюрьма, пещеры, город, демонические залы), другие классы героев, таланты, ловушки и тайные двери, магазины, квесты, жезлы, кольца, артефакты, метательное оружие, звуки и музыка. Ядро устроено так, что всё это добавляется по образцу уже перенесённого.

## Управление

| Действие | Мышь / касание | Клавиатура |
|---|---|---|
| Идти / атаковать | нажать на клетку или врага | WASD, стрелки, цифровой блок; Q E Z C — по диагонали |
| Ждать ход | кнопка с часами | Пробел |
| Отдыхать до полного здоровья | удержать кнопку с часами | R |
| Атаковать ближайшего врага | красная кнопка с монстром | F |
| Рюкзак | кнопка с рюкзаком | I или Tab |
| Осмотреть клетку | лупа, затем клетка; или долгое нажатие / правый клик | — |
| Масштаб | кнопки + и − | — |

## Для разработчиков

```
src/shared/Core/   ядро без API Roblox: Game (ходы, бой, ИИ, предметы), LevelGen, Fov, Tiles, Defs, Rng, Terrain
src/shared/        Config, Atlas (координаты спрайтов), AtlasData (атлас в base64), Png (распаковка PNG на Luau)
src/client/        Main (ввод, окна, титульный экран), Modules/View (отрисовка), Modules/Hud (интерфейс), Modules/Ui
src/server/        Records (таблица лидеров)
third_party/spd/   исходные картинки из Shattered Pixel Dungeon и её лицензия
tools/             build-atlas.js (собрать атлас), build-place.js (собрать .rbxlx), png.js
tests/             проверки ядра и интерфейса вне Roblox (виртуальная машина Lua fengari)
```

Проект совместим с [Rojo](https://rojo.space): `rojo serve` использует `default.project.json`.

Пересборка и проверки (нужен Node.js):

```
npm install          # ставит fengari — Lua для тестов
npm run atlas        # пересобрать assets/atlas.png и src/shared/AtlasData.luau
npm run place        # пересобрать BloxPixelDungeon.rbxlx
npm test             # синтаксис, распаковщик PNG, 20 партий бота, прогон интерфейса на имитации Roblox
node tests/render-level.js level.png 3 42   # нарисовать этаж в картинку
```

Ядро и клиент написаны на общем подмножестве Lua 5.1/Luau. Поэтому тесты гоняют тот же код, что работает в Roblox: бот проходит партии до босса, а интерфейс прогоняется на имитации Roblox API.
