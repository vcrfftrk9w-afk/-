# ViralPilot — AI-продюсер для TikTok

Подключаешь свой TikTok — приложение анализирует контент, находит свежие тренды в интернете под твою нишу, придумывает следующие видео с готовым сценарием съёмки и ведёт по плану на 30 дней к цели.

## Что умеет

| Раздел | Что делает |
| --- | --- |
| **Обзор** | Viral Score 0–100, уровень автора, подписчики, медиана просмотров, вовлечённость, вердикт AI, задачи на сегодня, прогноз роста |
| **Анализ** | AI-аудит: диагноз, приоритеты по порядку, сильные стороны и точки роста, контент-рубрики, упаковка профиля, готовые хуки. Метрики: просмотры по видео, лучшая длина ролика, хэштеги по эффективности, тепловая карта «день × час», лучший и худший ролик |
| **Тренды** | AI ищет в интернете актуальные звуки, форматы, челленджи и мемы под нишу. К каждому — почему работает и пошаговая инструкция «как снять» |
| **Идеи** | Персональные идеи следующих видео: хук, концепт, формат, длительность, прогноз вирусности, хэштеги, звук |
| **Студия** | Полный сценарий: 3 хука для A/B-теста, посекундная раскадровка, текст на экране, что снять по порядку, свет, монтаж, подпись, закреп, время публикации, чек-лист |
| **План** | 30 дней с конкретными задачами, фазы роста, XP, уровни, серия дней, конфетти |
| **AI-коуч** | Чат со стримингом ответов, знает твои цифры и нишу |
| **Инструменты** | Генераторы хуков, подписей, хэштегов, био, названий серий, улучшение текста. Разбор ролика по ссылке или описанию |

## Главное: вводишь @ник — приложение делает всё

На главном экране вводишь свой ник, приложение сканирует аккаунт (профиль и последние 30 роликов со статистикой), само определяет нишу и строит анализ, тренды, идеи и план.

Сканирование работает в серверной версии (на твоём компьютере или хостинге), потому что только сервер может обращаться к TikTok. Для загрузки роликов нужен `APIFY_TOKEN` (см. ниже). Без него подтянутся только цифры профиля.

### Запуск на своём компьютере за 5 минут

1. Установи Node.js 20+ с <https://nodejs.org>.
2. Скачай код этой ветки (Code → Download ZIP) и распакуй.
3. В папке проекта создай файл `.env.local`:

```env
APIFY_TOKEN=твой_токен_apify
ANTHROPIC_API_KEY=твой_ключ_claude
```

4. В терминале в папке проекта:

```bash
npm install
npm run dev
```

5. Открой <http://localhost:3000>, введи свой @ник.

## Быстрый старт

```bash
npm install
cp .env.example .env.local   # заполни ключи (см. ниже)
npm run dev                  # http://localhost:3000
```

Без ключей приложение тоже работает: встроенный офлайн-движок (правила и база знаний) считает аналитику, выдаёт проверенные форматы, идеи, сценарии и план. Есть демо-аккаунт.

## Веб-версия в один файл

```bash
npm run build:web   # → dist-web/index.html
```

Это то же приложение без своего сервера. Запросы к ИИ идут через Claude прямо на странице (на аккаунте того, кто открыл страницу, с его разрешения). Отличия от полной версии: тренды ИИ подбирает сам, без поиска в интернете, а вход через TikTok и импорт по нику недоступны. Цифры профиля и статистику видео вводят вручную.

## Ключи

### 1. AI (обязательно для «умного» режима)

Ключ Claude API: <https://console.anthropic.com/> → API Keys.

```env
ANTHROPIC_API_KEY=sk-ant-...
ANTHROPIC_MODEL=claude-opus-5
```

С ключом включаются: глубокий AI-аудит, **поиск трендов в интернете** (веб-поиск), персональные идеи и сценарии, план и коуч.

### 2. Сканирование по @нику (Apify)

Зарегистрируйся на <https://apify.com> (есть бесплатный тариф), открой Settings → API & Integrations и скопируй Personal API token:

```env
APIFY_TOKEN=apify_api_...
```

Используется готовый сканер `clockworks/tiktok-scraper`. Другой можно указать в `APIFY_TIKTOK_ACTOR`.

### 3. Вход через TikTok (необязательно)

Даёт доступ ко всем твоим видео со статистикой (просмотры, лайки, комментарии, репосты).

1. Зайди на <https://developers.tiktok.com/> → **Manage apps** → **Create app**.
2. Добавь продукты **Login Kit** и **Display API**.
3. Включи scopes: `user.info.basic`, `user.info.profile`, `user.info.stats`, `video.list`.
4. Redirect URI: `http://localhost:3000/api/tiktok/callback` (для продакшена — свой домен).
5. Скопируй ключи в `.env.local`:

```env
TIKTOK_CLIENT_KEY=...
TIKTOK_CLIENT_SECRET=...
TIKTOK_REDIRECT_URI=http://localhost:3000/api/tiktok/callback
```

Пока приложение TikTok на ревью, войти смогут только аккаунты, добавленные в Sandbox как тестовые.

### Без входа через TikTok (без ручного ввода)

- **Скриншоты.** Профиль с сеткой роликов и экраны TikTok Studio → «Аналитика». Claude распознаёт подписчиков, лайки и статистику каждого ролика.
- **Файл аналитики.** CSV или XLSX из TikTok Studio, или `user_data_tiktok.json` из «Настройки → Скачать данные».
- **По @username** (только серверная версия) — публичная страница профиля. TikTok иногда отвечает капчей.
- Повторная загрузка во вкладке «Профиль» обновляет данные и копит историю роста.

### Разбор ролика по видеофайлу

«Инструменты» → «Разбор ролика» → загрузи видео. Кадры хука и всего ролика вырезаются в браузере, само видео никуда не отправляется. Claude оценивает хук, кадр, свет, текст на экране и безопасные зоны.

## Технологии

Next.js 16 (App Router) · React 19 · TypeScript · Tailwind CSS 4 · Framer Motion · Recharts · Anthropic SDK.

```
src/
  app/                 страницы и API-маршруты
    api/ai/*           анализ, тренды (веб-поиск), идеи, сценарий, план, чат, инструменты, разбор
    api/tiktok/*       OAuth, профиль и видео, публичный импорт, oEmbed
  components/          UI-кит, графики, онбординг, вкладки дашборда
  lib/
    analytics.ts       Viral Score, метрики, тепловая карта, прогноз роста
    knowledge.ts       15 ниш, формулы хуков, проверенные форматы
    offline.ts         офлайн-движок (работает без ключа)
    server/ai.ts       Claude API: стриминг, веб-поиск, резервные модели
```

Данные пользователя хранятся в браузере (localStorage). Токен TikTok — в httpOnly-cookie.

## Деплой

Подходит любой хостинг Next.js, например Vercel: импортируй репозиторий, добавь переменные окружения, в TikTok Developer укажи redirect URI на свой домен.
