# Terra Forge (Roblox)

Стратегия в реальном времени в духе Rusted Warfare: вид сверху, своя база, экстракторы на месторождениях, заводы, танки, пехота, артиллерия и авиация. Четыре базы по углам карты, свободные базы берут боты. Разрушь командные центры врагов.

## Как играть

- **Старт:** нажми «ИГРАТЬ». Ты получаешь базу с командным центром и тремя юнитами. Зайти в бой можно в первую минуту, потом — только смотреть.
- **Деньги:** командный центр даёт +8 $/с. Экстрактор на светящемся месторождении даёт +6 $/с, фабрикатор (ставится где угодно на базе) +5 $/с.
- **Постройки:** выбери постройку внизу и нажми на карту рядом со своей базой. Она строится несколько секунд. На компьютере контур постройки следует за мышкой: зелёный — можно ставить, красный — нельзя.
- **Заказ войск:** нажми на свою казарму, завод бронетехники или аэродром. «+1» ставит юнит в очередь, «Авто» выпускает его по кругу, «Точка сбора» задаёт, куда новым юнитам ехать.
- **Армия:** нажми на юнит или выбери группу (пехота, техника, авиация, все), потом нажми на карту. Войска едут в объезд воды и скал и сами стреляют по врагам в радиусе.
- **Камера:** тащи карту пальцем или мышкой, приближай двумя пальцами, колёсиком или кнопками «+» и «−». На компьютере ещё WASD и стрелки. Правая кнопка мыши — отправить выбранные войска или отменить стройку. Кнопка с командным центром наверху возвращает к базе, мини-карта — к любому месту.
- **Кто кого бьёт:** танк силён против пехоты, ракетчик против техники и авиации, артиллерия бьёт издалека по постройкам, истребитель охотится за авиацией, вертолёт бьёт по наземным целям, пушечная башня и ПВО защищают базу.
- **Конец боя:** остался один командный центр или прошло 20 минут (тогда побеждает самая сильная база).

Вкладка «Карта мира» в меню — следующий режим, пока он помечен «Скоро». Название игры пока рабочее.

## Как запустить

Нужен компьютер (Windows или Mac) с Roblox Studio.

1. Скачай `build/TerraForge.rbxlx`.
2. В Roblox Studio выбери **File → Open from File** и открой этот файл.
3. Опубликуй игру: **File → Publish to Roblox**.
4. Нажми **Play**. Проверить игру с друзьями можно через **Test → Clients and Servers**, там же выбирается число игроков.

## Как устроено

| Где | Что |
| --- | --- |
| `src/shared` | общее для сервера и клиента: правила (`Config`), карта боя (`Map`, `MapData`), ячейки спрайтов (`SpriteData`), номера картинок (`MapArt`), движение юнитов (`Motion`) |
| `src/server` | сервер: бой, боты, экономика, постройки, войска (`Match`), поиск пути (`Path`) |
| `src/client` | клиент: поле боя в 2D (`MapView`), спрайты (`Sprites`), картинки игры (`Art`), меню и интерфейс (`Ui`), стиль (`Theme`) |
| `tools` | генераторы карты и спрайтов, загрузка картинок, сборка и публикация |

Сервер ведёт один бой на четыре базы. Всё считает сервер, клиенты только рисуют. Каждые 0,2 секунды сервер рассылает пачку изменений: новые постройки и приказы, здоровье, выстрелы, взрывы.

Войска движутся по маршрутам. Маршрут по суше ищет A* (`src/server/Path.luau`) и спрямляет его. Позицию юнита в любой момент считает общая функция `src/shared/Motion.luau` по маршруту, скорости и времени старта. Поэтому по сети уходят только приказы, а не координаты каждый кадр. Бой идёт на сервере: каждый юнит и каждая башня бьют ближайшего врага в радиусе.

Поле боя — это интерфейс Roblox, а не 3D: нарисованная карта из четырёх картинок, поверх неё постройки и юниты из листа спрайтов (ImageLabel с ImageRectOffset). Цвет команды даёт второй лист, где цветные части серые: его подкрашивает ImageColor3. Корпус и башня танка поворачиваются отдельно, башня следит за целью. Все объекты стоят на доске в долях её размера, поэтому камера двигает и масштабирует только саму доску.

Карту рисует `tools/gen_battlemap.py`: клетки 112 × 72 (трава, песок, земля, скалы, вода, 24 месторождения), зеркальные четверти для честного старта и картинку по тем же клеткам. Спрайты рисует `tools/gen_sprites.js` (нужен Playwright). `tools/upload_art.py` загружает картинки в Roblox наклейками через Open Cloud и записывает их номера в `src/shared/MapArt.luau`. Сервер при старте достаёт из наклеек картинки (InsertService) и передаёт их клиентам.

Картинки на лету (EditableImage) игра не использует: в опубликованной игре Roblox разрешает их только владельцу с подтверждённым возрастом 13+ и документом.

## Если что-то сломалось

Ошибки показываются прямо на экране красной плашкой, в том числе ошибки сервера. Сделай скриншот: по нему видно, где ошибка.

## Правка и пересборка

Код можно править прямо в Studio. Если работаешь с файлами из этой папки, после правок собери файл игры заново:

```
python3 tools/build_place.py
```

Ещё можно подключить [Rojo](https://rojo.space) к `default.project.json`.

Опубликовать новую версию в Roblox без Studio:

```
tools/publish.sh
```

Скрипт проверяет код, собирает файл и отправляет его через Open Cloud. Перерисовать и заново загрузить карту и спрайты:

```
python3 tools/gen_battlemap.py /tmp/battle
node tools/gen_sprites.js /tmp/sprites
python3 tools/upload_art.py map0=/tmp/battle/map_0.png map1=/tmp/battle/map_1.png map2=/tmp/battle/map_2.png map3=/tmp/battle/map_3.png atlas=/tmp/sprites/atlas_base.png team=/tmp/sprites/atlas_team.png
```

Нужен ключ API с правами universe-places: write и assets (чтение и запись). В облачной среде Claude ключ лежит в сетевом секрете для `apis.roblox.com` (заголовок `x-api-key`). Ещё ключ можно передать вручную: `ROBLOX_API_KEY=... tools/publish.sh`.

`tools/check_luau.py` быстро проверяет код Luau: блоки, скобки, неизвестные имена.
