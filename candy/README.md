# 🍬💥 Бомба Конфетка

Игра «три в ряд»: 60 уровней, 6 регионов, особые конфеты, супер-комбо, бустеры, колесо подарка дня.
Один файл `index.html` — чистые HTML/CSS/JS, без сборки, работает офлайн (PWA).

## Как играть
- Свайпни конфету (или тапни две соседние) — собери 3 в ряд.
- 4 в ряд → **полосатая** (взрывает линию), Г/Т → **обёртка** (большой взрыв), 5 в ряд → **шоко-бомба** 🌈.
- Поменяй две особые конфеты местами → супер-комбо (крест, супер-лазер, двойной бабах, бомбопад, МЕГА ВЗРЫВ).
- Цели уровней: очки, собрать конфеты, убрать желе, открыть подарки 🎁. С 10-го уровня — лёд 🧊.
- Оставшиеся ходы в конце превращаются в полосатые конфеты и взрываются — «БОМБА КОНФЕТКА!».

## Запуск
```bash
cd candy && python3 -m http.server 8080   # http://localhost:8080
```
На телефоне: открыть адрес → «На экран „Домой“» (iPhone) или «Установить приложение» (Android).

## В App Store
Для публикации в App Store нужен аккаунт Apple Developer (99 $/год) и Mac с Xcode.
Папку `candy/` можно обернуть в нативное приложение через Capacitor (`npx cap add ios`, `webDir: "candy"`).
