# WhatsApp-бот «Сортировщик идей»

Пишешь сам себе в WhatsApp (чат **«Я»** / «Заметки»), а бот раскладывает это по папкам:

| Пишешь | Куда попадёт |
|---|---|
| `тт: кот пугается огурца` / `идея для тт …` / `тикток …` | 🎬 **Идеи для ТТ** |
| `в жизнь: сходить к стоматологу` / `жизнь …` | 🌱 **В жизнь** |
| `хочу снять видео про утро` (папку не назвал) | угадает по словам («видео» → ТТ, «купить», «надо» → жизнь) и скажет, как перенести, если не туда |
| `бабушкин рецепт пирога` (непонятно) | спросит «Куда это? 1 — ТТ, 2 — Жизнь», ответь цифрой. Не ответил — лежит в 📥 **Разное** |

Команды (тоже просто сообщением):

- `все` — показать все папки
- `тт` / `жизнь` / `разное` — показать одну папку
- `готово тт 2` — сделал, убрать из списка (`готово 2 5` — если эту папку только что смотрел)
- `удали тт 2` — удалить
- `перенеси тт 2 в жизнь` — переложить
- `помощь` — подсказка

Бот отвечает только в чате «Я» — твои переписки с людьми и группы он не трогает. Его ответы начинаются с 🤖.

## Запуск на компьютере

Нужен [Node.js](https://nodejs.org) 20 или новее.

```bash
cd bot/whatsapp
npm install
npm start
```

В терминале появится QR-код. На телефоне: **WhatsApp → Настройки → Связанные устройства → Привязка устройства** → отсканируй.
Появится «✅ Бот подключён» — напиши себе в WhatsApp `помощь`.

Бот работает, пока открыт терминал. Вход запоминается (папка `data/auth`), второй раз QR не нужен.

## Запуск прямо на Android-телефоне (Termux)

Если нет компьютера, который всегда включён. Установи **Termux** из F-Droid, затем:

```bash
pkg install nodejs git
git clone <адрес этого репозитория> && cd <папка>/bot/whatsapp
npm install
PHONE=79991234567 npm start      # свой номер, только цифры, с кодом страны
```

QR со своего же экрана не отсканировать, поэтому с `PHONE` бот покажет **8-значный код**.
WhatsApp → **Связанные устройства → Привязка устройства → «Привязать по номеру телефона»** → введи код.
Чтобы Android не усыплял бота: в шторке Termux нажми **Acquire wakelock**.

## Бот на отдельном номере

Если бот стоит на втором номере (второй SIM / рабочий WhatsApp), разреши себе писать ему:

```bash
OWNERS=79991234567 npm start     # несколько номеров — через запятую
```

Тогда пишешь в чат с этим номером, а не себе.

## Где лежат идеи

`data/ideas.json` — обычный текстовый файл, его можно открыть и скопировать. `data/auth` — вход в WhatsApp,
**никому не отправляй и не клади в git** (папка `data/` уже в `.gitignore`).
Отвязать бота: WhatsApp → Связанные устройства → нажми на «Сортировщик идей» → Выйти.

## Свои папки и слова

Всё в начале `sorter.js`, массив `CATEGORIES`: допиши блок со своим значком, названием, словами-названиями
(`names` — «деньги: …») и словами-подсказками (`hints`). Порядок в массиве = цифры в вопросе «Куда это?».

## Проверка без WhatsApp

```bash
node tests/whatsapp_sorter_test.mjs      # из корня репозитория
```

> Бот подключается как неофициальный WhatsApp Web (библиотека [Baileys](https://github.com/WhiskeySockets/Baileys)).
> Для личных заметок это нормально, но не рассылай через него спам — за это WhatsApp банит номера.
