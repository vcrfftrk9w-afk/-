# 🦥 Из Ленивца в Миллионеры

Геймифицированное веб-приложение для саморазвития и продуктивности с отдельным **СДВГ-режимом**. Полностью на чистых HTML/CSS/JS — без бэкенда, без сборки, работает офлайн (PWA).

## Как запустить

Просто открой `index.html` в браузере, либо подними локальный сервер:

```bash
python3 -m http.server 8080
# затем открой http://localhost:8080
```

## Возможности

- **Геймификация**: уровни, опыт (XP), монеты, стрики. Персонаж эволюционирует от 🦥 ленивца до 👑 магната и 💎 миллионера.
- **Задачи**: категории, приоритеты с разным XP, фильтры, конфетти и звук при выполнении.
- **СДВГ-режим** (вкладка ⚡):
  - Фокус-таймер (Pomodoro) с анимированным кольцом прогресса, автопереходом в перерыв и «компаньоном», который подбадривает.
  - Фонотека фокус-звуков: дождь, белый/коричневый шум, бинауральный ритм, lo-fi — всё генерируется на лету через Web Audio API (без аудиофайлов), с живым визуализатором.
  - «Разбей слона на кусочки» — разбивка больших задач на чек-лист маленьких шагов.
  - Журнал отвлечений — фиксируй отвлекающую мысль и спокойно возвращайся к делу.
  - Пупырчатая плёнка для сенсорной разрядки.
  - Дыхательное упражнение 4-4-6 с анимированным кругом.
  - «Не могу начать» — кнопка с микро-шагом для преодоления ступора.
- **Привычки**: недельная сетка отметок, счётчик стрика.
- **Достижения и магазин наград**: 18 достижений + собственные награды за монеты.
- **Статистика**: графики задач/фокуса за 7 дней, сводные показатели.
- **Настройки**: тёмная/светлая тема, звуковые эффекты вкл/выкл, режим «меньше анимаций» (accessibility), переключение обычный/СДВГ режим.
- Прогресс хранится в `localStorage`, есть экспорт/импорт JSON-бэкапа.

## Структура

```
index.html      — разметка и все вкладки
css/style.css   — стили и анимации
js/app.js       — вся логика (состояние, геймификация, звук, таймер, рендер)
manifest.json   — PWA-манифест
sw.js           — service worker для офлайн-кэша
icons/icon.svg  — иконка приложения
```
