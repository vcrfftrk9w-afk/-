@lesson snake-1
title: Шаг 1. Поле и змейка

@theory
Добро пожаловать в первый большой проект! Мы шаг за шагом напишем **«Змейку»** — одну из самых известных игр в мире. Каждый урок добавляет новую часть, а в конце у тебя будет полноценная игра.

## Как устроена змейка

Поле — это сетка **20 × 20 клеток**. Каждая клетка — квадрат 20 × 20 пикселей (холст 400 × 400).

Змейка — это **массив клеток**. У каждой клетки есть номер столбца `x` и строки `y` (не пиксели, а номера клеток!). Первый элемент массива — **голова**.

```code
let snake = [
  { x: 10, y: 10 },  // голова
  { x: 9, y: 10 },   // тело
  { x: 8, y: 10 }    // хвост
];
```

Чтобы нарисовать клетку, переводим номер клетки в пиксели — умножаем на размер клетки:

```code
пиксель X = x * SIZE
пиксель Y = y * SIZE
```

Клетка (10, 10) рисуется в пикселях (200, 200).

## Красивая сетка

Если рисовать квадрат чуть меньше клетки (на 1 пиксель отступ с каждой стороны), между клетками будут видны тонкие линии — змейка станет «сегментной»:

```js canvas w=400 h=400
const SIZE = 20;
ctx.fillStyle = "#111a33";
ctx.fillRect(0, 0, canvas.width, canvas.height);
for (let x = 0; x < 20; x++) {
  for (let y = 0; y < 20; y++) {
    ctx.fillStyle = (x + y) % 2 === 0 ? "#18234a" : "#141d3d";
    ctx.fillRect(x * SIZE + 1, y * SIZE + 1, SIZE - 2, SIZE - 2);
  }
}
```

@lesson snake-2
title: Шаг 2. Змейка ползёт
xp: 20
@theory
Как двигается змейка? Хитрость в том, что двигать **все** клетки не нужно! Достаточно:

1. Добавить **новую голову** на шаг впереди старой.
2. **Убрать хвост** (последнюю клетку).

Тело при этом «переползает» само собой.

```text
Было:      [Г][Т][Т]  →
Новая голова:  [Н][Г][Т][Т]
Убрали хвост:  [Н][Г][Т]
```

## Направление

Направление храним как объект `dir` с двумя числами:

| Куда | dir |
|---|---|
| вправо | `{ x: 1, y: 0 }` |
| влево | `{ x: -1, y: 0 }` |
| вниз | `{ x: 0, y: 1 }` |
| вверх | `{ x: 0, y: -1 }` |

Новая голова = старая голова + направление:

```code
const head = { x: snake[0].x + dir.x, y: snake[0].y + dir.y };
snake.unshift(head);  // добавить в начало массива
snake.pop();          // убрать последний элемент
```

`unshift` добавляет в **начало** массива, `pop` убирает из **конца** — помнишь из модуля про массивы?

## Тики вместо кадров

Змейка не двигается 60 раз в секунду (это слишком быстро) — она ходит **рывками**, клетка за клеткой. Поэтому вместо `requestAnimationFrame` используем `setInterval`: каждые 150 мс — один шаг. Такой шаг называется **тик**.

> 🎮 Чем меньше интервал — тем быстрее змейка и сложнее игра. Можно ускорять змейку с каждым съеденным яблоком!

@lesson snake-3
title: Шаг 3. Управление стрелками
xp: 20
@theory
Теперь научим змейку поворачивать. При нажатии стрелки меняем направление.

## Запрет разворота

Змейка не может развернуться на 180°: если она ползёт вправо, повернуть сразу влево нельзя — она врежется сама в себя. Поэтому проверяем: повернуть **вверх** можно, только если змейка **не ползёт вниз** (`dir.y !== 1`), и так далее.

## Хитрая ошибка и её исправление

Представь: змейка ползёт вправо, и игрок очень быстро нажимает ↑ и сразу ←, — оба нажатия между двумя тиками. Первое нажатие поменяет направление на «вверх», второе проверит «не ползёт ли вправо?» — нет, ведь уже «вверх»! — и поставит «влево». На следующем тике змейка развернётся в себя.

Решение — копить нажатие в отдельной переменной `nextDir` («следующее направление»), а проверку делать по **текущему** `dir`:

```code
let nextDir = { x: 1, y: 0 };

document.addEventListener("keydown", (e) => {
  if (e.key === "ArrowUp" && dir.y !== 1) nextDir = { x: 0, y: -1 };
  // ... остальные стрелки
});

function step() {
  dir = nextDir;   // применяем поворот только в момент шага
  // ...
}
```

> 🧠 Такие «пограничные случаи» — то, что отличает игру-поделку от качественной игры. Профессиональные разработчики игр постоянно ищут, как игрок может «сломать» игру.
@task
Допиши обработчик клавиш: для каждой из четырёх стрелок задавай `nextDir`, но **запрещай разворот** назад (сравнивай с текущим `dir`):

- `ArrowUp` → `{ x: 0, y: -1 }`, если змейка не ползёт вниз;
- `ArrowDown` → `{ x: 0, y: 1 }`, если не ползёт вверх;
- `ArrowLeft` → `{ x: -1, y: 0 }`, если не ползёт вправо;
- `ArrowRight` → `{ x: 1, y: 0 }`, если не ползёт влево.

В `step()` уже добавлена строчка `dir = nextDir;`.

@lesson snake-4
title: Шаг 4. Еда и рост
xp: 20
@theory
Пора кормить змейку! Правило: если голова попала на клетку с едой — змейка **растёт**, счёт увеличивается, а еда появляется в новом месте.

## Как вырасти

Очень просто! Помнишь, шаг — это «добавить голову + убрать хвост»? Если змейка съела еду, просто **не убираем хвост** — и она станет на клетку длиннее:

```code
snake.unshift(head);
if (head.x === food.x && head.y === food.y) {
  score++;
  placeFood();      // новая еда
} else {
  snake.pop();      // хвост убираем, только если не ели
}
```

## Новая еда — не на змейке!

Еда должна появиться в случайной клетке, но **не там, где змейка**. Используем цикл `do...while`: «выбирай случайную клетку, **пока** она занята змейкой»:

```code
function placeFood() {
  do {
    food = { x: randomInt(0, COLS - 1), y: randomInt(0, ROWS - 1) };
  } while (snake.some((p) => p.x === food.x && p.y === food.y));
}
```

- `do { ... } while (условие)` — как `while`, но сначала **делает**, а потом проверяет. Хоть один раз выполнится обязательно — а нам и нужно выбрать клетку хотя бы раз.
- `snake.some(...)` — есть ли хоть одна клетка змейки на этом месте.

@theory
Последний шаг! Змейка должна **проигрывать**, если:

1. врезалась в **стену** (вышла за поле);
2. врезалась **сама в себя**.

## Проверка в step()

Новую голову проверяем **до того**, как добавить её в змейку:

```code
const head = { x: snake[0].x + dir.x, y: snake[0].y + dir.y };

const hitWall = head.x < 0 || head.x >= COLS || head.y < 0 || head.y >= ROWS;
const hitSelf = snake.some((p) => p.x === head.x && p.y === head.y);

if (hitWall || hitSelf) {
  gameOver = true;
  return;   // дальше не идём
}
```

А в самом начале `step()`: если игра уже окончена — ничего не делаем:

```code
if (gameOver) return;
```

## Новая игра

По пробелу начинаем заново. Удобно сделать функцию `restart()`, которая возвращает всё в начальное состояние: змейку, направление, счёт, флаг `gameOver` и еду.

## Экран «Игра окончена»

В `draw()`, если `gameOver`, рисуем поверх поля полупрозрачный прямоугольник и текст:

```code
if (gameOver) {
  ctx.fillStyle = "rgba(0, 0, 0, 0.6)";
  ctx.fillRect(0, 0, canvas.width, canvas.height);
  ctx.fillStyle = "white";
  ctx.textAlign = "center";
  ctx.fillText("Игра окончена! Пробел — заново", canvas.width / 2, canvas.height / 2);
  ctx.textAlign = "left";
}
```

`rgba(0, 0, 0, 0.6)` — чёрный с прозрачностью 60%: поле видно, но затемнено.

function placeFood() {
  do {
    food = { x: randomInt(0, COLS - 1), y: randomInt(0, ROWS - 1) };
  } while (snake.some((p) => p.x === food.x && p.y === food.y));

// 3. Новая игра
function restart() {
  snake = [
    { x: 10, y: 10 },
    { x: 9, y: 10 },
    { x: 8, y: 10 }
  ];
  dir = { x: 1, y: 0 };
  nextDir = { x: 1, y: 0 };
  score = 0;
  gameOver = false;
  placeFood();
}

function step() {
  // 1. Игра окончена — ничего не делаем
  if (gameOver) return;

  dir = nextDir;
  const head = { x: snake[0].x + dir.x, y: snake[0].y + dir.y };
  // 2. Врезались в стену или в себя?
  const hitWall = head.x < 0 || head.x >= COLS || head.y < 0 || head.y >= ROWS;
  const hitSelf = snake.some((p) => p.x === head.x && p.y === head.y);
  if (hitWall || hitSelf) {
    gameOver = true;
    return;
  }

  snake.unshift(head);
  if (head.x === food.x && head.y === food.y) {
    score++;
    placeFood();
  } else {
    snake.pop();
  }
}
