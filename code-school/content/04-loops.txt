@lesson loops-1
title: Цикл for — повтори много раз
@theory
Представь: нужно вывести числа от 1 до 100. Писать сто строчек `console.log`? Нет! Для повторений есть **циклы**.

```js
for (let i = 1; i <= 5; i++) {
  console.log("Шаг номер " + i);
}
```

`for` [фор] — «для». Читается: «**для** i от 1, пока i ≤ 5, увеличивая i на 1 — повторяй».

## Три части цикла

```code
for (let i = 1;   i <= 5;   i++) {
     начало      условие    шаг
  // тело цикла — то, что повторяется
}
```

1. **Начало** `let i = 1` — создаём счётчик. Выполняется один раз.
2. **Условие** `i <= 5` — проверяется **перед каждым** повтором. Пока true — повторяем. Как только false — цикл закончен.
3. **Шаг** `i++` — выполняется **после каждого** повтора: счётчик растёт.

## Как компьютер выполняет цикл

| Повтор | i | i <= 5? | Что выводим |
|---|---|---|---|
| 1 | 1 | да | Шаг номер 1 |
| 2 | 2 | да | Шаг номер 2 |
| … | … | … | … |
| 5 | 5 | да | Шаг номер 5 |
| — | 6 | **нет** | цикл закончен |

> 🧠 Почему `i`? Это традиция: от слова index [и́ндекс] — «номер». Можно назвать счётчик как угодно, но `i` поймёт любой программист в мире.

## Можно считать с нуля

Программисты часто считают с нуля — дальше увидишь почему. Этот цикл тоже повторится 5 раз (0, 1, 2, 3, 4):

```js
for (let i = 0; i < 5; i++) {
  console.log("Враг появился! Номер " + i);
}
```

> 🎮 В играх циклы везде: создать 10 врагов, нарисовать 50 звёзд, проверить каждую пулю — попала ли она во врага.

@lesson loops-2
title: Обратный отсчёт и другие шаги
@theory
Счётчик не обязан расти на 1. Он может **уменьшаться** или шагать через несколько чисел.

## Обратный отсчёт

```js
for (let i = 3; i >= 1; i--) {
  console.log(i + "...");
}
console.log("Старт! 🏁");
```

Здесь начинаем с 3, повторяем пока `i >= 1`, и каждый раз **уменьшаем** `i--`.

## Шаг больше единицы

```js
for (let i = 0; i <= 100; i += 25) {
  console.log("Загрузка: " + i + "%");
}
```

`i += 25` — прибавляем по 25.

## Опасность: бесконечный цикл

Если условие **никогда** не станет ложным — цикл будет крутиться вечно, и программа зависнет:

```bad
for (let i = 1; i >= 1; i++) {
  // i всегда >= 1 — бесконечно!
}
```

> ⚠️ Если в этом курсе случится бесконечный цикл, приложение остановит программу и покажет подсказку. В обычном браузере вкладка просто зависнет — поэтому всегда проверяй: счётчик идёт **в сторону** выполнения условия?
@task
Сделай обратный отсчёт перед стартом гонки: выведи числа **от 5 до 1**, а после цикла — `Старт!`

```text
5
4
3
2
1
Старт!
```
@starter

@solution
for (let i = 5; i >= 1; i--) {
  console.log(i);
}
console.log("Старт!");
@test Выведено 5, 4, 3, 2, 1, Старт!
__out.join(",") === "5,4,3,2,1,Старт!"
@test Числа выводит цикл for с уменьшением счётчика
/for\s*\(/.test(__codeNS) && /--|-=/.test(__codeNS)
@hint
Начни с 5, повторяй, пока `i >= 1`, уменьшай `i--`.
@hint
`console.log("Старт!");` — **после** закрывающей фигурной скобки цикла, иначе «Старт!» напечатается 5 раз.
@quiz
? Что выведет `for (let i = 10; i > 0; i -= 5) console.log(i);`?
+ 10 и 5
- 10, 5, 0
- 5 и 0
= i = 10 → выводим, i = 5 → выводим, i = 0 → условие `0 > 0` ложно, конец.
? Какой цикл бесконечный?
- `for (let i = 0; i < 10; i++)`
+ `for (let i = 0; i < 10; i--)`
- `for (let i = 10; i > 0; i--)`
= i уменьшается от 0: −1, −2, … — всегда меньше 10. Условие никогда не станет ложным.

@lesson loops-3
title: Накопление — считаем в цикле
@theory
Очень частая задача: что-то **накопить** в цикле. Сосчитать сумму, количество, найти самое большое.

## Сумма

Сколько монет соберёт игрок, если на уровне 1 — 1 монета, на уровне 2 — 2, … на уровне 10 — 10?

```js
let total = 0;

for (let level = 1; level <= 10; level++) {
  total += level;
}

console.log("Всего монет: " + total);
```

Как это работает:
1. **До цикла** создаём «копилку» `total = 0`.
2. **В цикле** каждый раз кладём в неё очередное значение.
3. **После цикла** выводим результат.

> ⚠️ Если создать копилку **внутри** цикла, она будет обнуляться на каждом повторе!

## Счётчик

Сколько чисел от 1 до 50 делятся на 7? Используем `%` (остаток от деления) и `if` внутри цикла:

```js
let count = 0;
for (let i = 1; i <= 50; i++) {
  if (i % 7 === 0) {
    count++;
  }
}
console.log("Делятся на 7: " + count);
```

> 🧠 `i % 7 === 0` — классический способ проверить «делится ли нацело». Например, `i % 2 === 0` — число чётное.

> 🎮 Так считают итоговый счёт уровня, общий урон серии ударов, число побеждённых врагов.
@task
В игре **10 волн** врагов. В первой волне 3 врага, во второй — 6, в третьей — 9… В волне номер `i` ровно `i * 3` врагов.

Посчитай в цикле, сколько **всего** врагов во всех волнах, и выведи: `Всего врагов: ...`

Ответ компьютер должен посчитать сам — не вписывай число в код.
@starter

@solution

for (let i = 1; i <= 10; i++) {
  total += i * 3;
}

console.log("Всего врагов: " + total);

__line("Всего врагов: 165")
@test Сумма считается в цикле for

@test Ответ не вписан в код готовым числом

@hint

@hint
После цикла: `console.log("Всего врагов: " + total);`
@quiz
? Где нужно создать переменную-копилку для суммы?
+ До цикла
- Внутри цикла
- После цикла
= Внутри цикла она будет обнуляться на каждом повторе.
? Как проверить, что число n чётное?
- `n / 2 === 0`
+ `n % 2 === 0`

= Остаток от деления на 2 равен нулю — значит чётное.

@lesson loops-4
title: Цикл while — пока…
@theory
`for` хорош, когда **знаешь**, сколько раз повторять. А если не знаешь? Например: «бей монстра, **пока** он жив». Сколько ударов понадобится — заранее неизвестно. Для этого есть `while` [уа́йл] — «пока».

```js
let monsterHp = 100;
let hits = 0;

while (monsterHp > 0) {
  monsterHp -= 30;
  hits++;
  console.log(`Удар ${hits}! У монстра ${monsterHp} HP`);
}

console.log("Монстр повержен за " + hits + " ударов");
```

## Как устроен while

```code
while (условие) {
  // повторяется, пока условие true
}
```

У `while` есть только условие. Всё остальное — счётчик, его изменение — делаешь сам. Поэтому особенно легко сделать бесконечный цикл:

```bad
let hp = 100;
while (hp > 0) {
  console.log("Бью!");
  // забыли уменьшить hp — цикл никогда не закончится!
}
```

> ⚠️ Внутри `while` обязательно должно что-то менять условие — иначе цикл будет вечным.

## for или while?

- знаешь число повторов (10 врагов, 5 жизней) → `for`;
- повторяешь до какого-то события (пока жив, пока не найдём) → `while`.

> 🎮 Сам «игровой цикл», который крутит любую игру, — это тоже повторение «пока игра не закончена». Но в браузере его делают особым способом — узнаешь в модуле про анимацию.

Не вписывай ответ в код — пусть посчитает цикл.

@solution

@lesson loops-5
title: break и continue — управляем циклом
@theory
Иногда цикл нужно **прервать** раньше времени или **пропустить** шаг.

## break — выйти из цикла

`break` [брейк] — «сломать». Цикл сразу заканчивается.

```js
let treasures = 0;
for (let room = 1; room <= 10; room++) {
  console.log("Обыскиваю комнату " + room);
  if (room === 4) {
    console.log("Нашёл сундук! Ухожу из подземелья.");
    break;
  }
}
```

Цикл должен был пройти 10 комнат, но остановился на четвёртой.

## continue — пропустить шаг

`continue` [конти́нью] — «продолжить». Остаток текущего шага пропускается, цикл переходит к следующему.

```js
for (let i = 1; i <= 6; i++) {
  if (i === 3) {
    continue;
  }
  console.log("Волна " + i);
}
```

Волны 3 не будет — например, это «бонусный уровень без врагов».

> 💡 `break` часто используют в поиске: перебираем, пока не нашли, — нашли, выходим. Зачем искать дальше?
@task
Найди **первое** число от 1 до 100, которое делится **и на 6, и на 8** без остатка. Как только нашёл — выведи его и выйди из цикла с помощью `break`.

После цикла ничего больше выводить не надо — в консоли должно быть одно число.
@starter
for (let i = 1; i <= 100; i++) {

}
@solution

  if (i % 6 === 0 && i % 8 === 0) {
    console.log(i);
    break;
  }
}
@test Выведено 24 — и только оно
__out.join(",") === "24"
@test Используется break
/break/.test(__codeNS)
@test Используется проверка через %
/%\s*6/.test(__codeNS) && /%\s*8/.test(__codeNS)
@hint
Условие «делится на 6 и на 8»: `i % 6 === 0 && i % 8 === 0`
@hint
Внутри if: сначала `console.log(i);`, потом `break;`
@quiz
? Что делает break?
+ Сразу завершает цикл
- Пропускает один шаг
- Останавливает всю программу
= break выходит из цикла, программа продолжается после него.

@lesson loops-6
title: Цикл в цикле — игровое поле
@theory
Многие игры — это **поле из клеток**: шахматы, сапёр, змейка, «три в ряд». Чтобы пройти по каждой клетке, нужен **цикл внутри цикла**.

```js
for (let row = 1; row <= 3; row++) {
  for (let col = 1; col <= 4; col++) {
    console.log(`Клетка: строка ${row}, столбец ${col}`);
  }
}
```

Внешний цикл перебирает строки. Для **каждой** строки внутренний цикл перебирает все столбцы. Всего 3 × 4 = 12 повторов.

> 🧠 Имена `row` [ро́у] — «ряд, строка» и `col` (от column [ко́лам] — «столбец») — стандартные для таблиц и полей.

## Рисуем поле символами

Соберём строку символ за символом, а потом выведем:

```js
for (let row = 0; row < 3; row++) {
  let line = "";
  for (let col = 0; col < 8; col++) {
    line += "🟩";
  }
  console.log(line);
}
```

`line = ""` — пустая строка. Внутренний цикл приклеивает к ней по клеточке. Когда строка готова — выводим её.

## Шахматная доска

С помощью `%` можно чередовать клетки:

```js
for (let row = 0; row < 4; row++) {
  let line = "";
  for (let col = 0; col < 8; col++) {
    if ((row + col) % 2 === 0) {
      line += "⬛";
    } else {
      line += "⬜";
    }
  }
  console.log(line);
}
```

> 🎮 В модуле про холст ты нарисуешь поле уже настоящей графикой — тем же самым двойным циклом.
