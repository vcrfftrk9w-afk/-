# Проверки

Живые проверки в настоящем браузере: поднимают приложение, кликают по нему
и смотрят, что получилось. Не юнит-тесты — они ловят то, что ломается
на самом деле: потерянные нажатия, съехавшую вёрстку, исчезнувшие данные.

## Как запустить

```bash
python3 -m http.server 8792 &          # из корня репозитория
node tests/smoke.js                     # 5 секунд: все модули загрузились
node tests/journey.js                   # полный первый день на телефоне
```

Нужен Playwright и Chromium. В этом окружении:
```bash
NODE_PATH=/opt/node22/lib/node_modules node tests/smoke.js
```

## Что проверяет каждая

| Файл | Что ловит |
|---|---|
| `smoke.js` | Все 17 модулей объявились, в консоли пусто. Первое, что стоит запустить после любой правки. |
| `journey.js` | Сквозной первый день на телефоне: онбординг → режим → шаблон → разбор → вода и еда → залипание → итог дня → перезагрузка. |
| `edge.js` | Граничные случаи: день занят целиком, длительность 0 и 9999, абсурдные деньги, удалённая задача в плане, сброс пути, экспорт/импорт. |
| `robust.js` | Длинные слова без пробелов, 25 привычек и 50 дел, двадцать быстрых нажатий подряд, переполнение хранилища. |
| `data-safety.js` | Две вкладки не затирают работу друг друга; испорченное сохранение не стирает прогресс. |
| `recovery.js` | Подробно: восстановление из запасной копии, поведение когда испорчены обе. |
| `score.js` | Оценка режима считает только измеримое: первый день без вчерашней ночи, первый час после подъёма. |
| `a11y.js` | Размер нажимаемых элементов на телефоне, подписи кнопок и полей, контраст текста, видимый фокус. |
| `perf.js` | Время рендера каждого экрана. Всё, что дольше 50 мс, — заметное подвисание. |
| `core.js` | Музыка реально звучит на всех станциях, фокус-таймер идёт и ставится на паузу, гиперфокус, звуковые слои. |
| `main-card.js` | Карточка «Сегодня главное» стоит первой, ведёт к ближайшему делу, отмечается прямо с главной, и ничего с главной не пропало. |
| `week-schedule.js` | Недельный график складывается во все семь дней: задачи не налезают на пары, встают в свой час, ничего не теряется. |
| `bottom-bar.js` | Мини-плеер не накрывает нижнюю панель вкладок — на четырёх сочетаниях экрана и размера шрифта. |
| `music.js` | Смена станции слышна сразу, темп берётся у новой станции, эквалайзер не крутится впустую. |
| `longterm.js` | Полгода ежедневных данных: размер сохранения, скорость загрузки и рендера, горячие клавиши. |

## Про «ошибки шрифтов»

В песочнице без доступа к `fonts.googleapis.com` проверки показывают
`ERR_CERT_AUTHORITY_INVALID` — это TLS-прокси окружения, а не приложение.
В обычном браузере шрифты грузятся нормально.
