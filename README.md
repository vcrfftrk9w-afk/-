# Мост

Приложение, которое помогает превратить «хочу, но не знаю как» в реальное действие.

Не список задач, где копится чувство вины. Человек приходит с чем-то расплывчатым —
«хочу сменить работу», «достал постоянный бардак», «мечтаю сделать игру, но ничего не умею» —
и уходит с одним посильным шагом, у которого есть осязаемый результат.

Главное свойство: **приложение не борется за внимание**. Ни уведомлений, ни серий, ни ленты.
Хорошая сессия — та, после которой ты закрыл вкладку и пошёл жить. Успех — когда приложение
становится не нужно.

## Как открыть

Просто открыть `index.html` в браузере — двойным кликом, без сборки, без интернета.
Ничего устанавливать не нужно: ни сборщика, ни зависимостей.

Если браузер капризничает с локальными файлами:

```
python3 -m http.server 8000     # затем http://localhost:8000
```

Одностраничная версия (всё приложение в одном файле) собирается так:

```
node tools/build.js             # → dist/most.html
```

## Что происходит внутри

1. **Разбор** — пять вопросов, отделяющих своё желание от ожидаемого.
   Главный из них: «Представь: дело сделано, и об этом никто не узнал. Ты всё ещё хочешь?»
   Если ответ «нет» — приложение не бросает человека, а переводит разговор на то желание,
   которое за этим стоит (перестать оправдываться, перестать сравнивать себя с лентой).
2. **Силы** — честная опись: часы в неделю, деньги, энергия, уже имеющиеся умения.
   Единственное место, где приложение просит быть скупым, а не смелым.
3. **Пути** — две-три дороги разной формы: «Тихая разведка», «Боковая дверь», «Прыжок»,
   «Починка». Они отличаются не качеством, а ценой. Приложение помечает, что по силам,
   но выбирает человек — дорогой путь тоже показан и не заблокирован.
4. **Шаг** — ровно один следующий шаг, у каждого есть: зачем он, сколько займёт и что
   останется в руках в конце. У каждого шага есть **равноправная уменьшенная версия**:
   если сил нет, восемь минут — это не поражение, а нормальный размер.
5. **Мастерская** — часть работы приложение делает вместе с человеком:
   - **прототип за двадцать минут** — собирает настоящий HTML-файл (кнопка со случайной
     фразой, таймер, счётчик, страница для одного человека), который открывается
     в браузере и работает, плюс подсказка «измени одну строчку»;
   - **письмо, которое трудно написать** — уйти с работы, попросить больше денег,
     предложить свою работу, отказать, написать без повода, попросить о неудобном;
   - **двадцать минут против бардака** — одна поверхность, таймер, четыре решения.
6. **Конец сессии** — экран, который отпускает: сколько времени ушло, что появилось
   сегодня, и прямое обещание не дёргать.

Когда сделано три шага и появилось несколько готовых вещей, приложение само предлагает
закрыть мост: «Кажется, дальше ты и без нас».

## Данные

Всё лежит в `localStorage` этого браузера. Ни аккаунта, ни сервера, ни синхронизации,
ни аналитики. В `index.html` прописано `connect-src 'none'` — браузеру запрещено отправлять
отсюда сетевые запросы, поэтому утечь записям физически некуда. Шрифты системные,
оформление своё: ни один внешний сервер не узнаёт, что человек сюда заходил.

На экране «Мои данные» видно всё, что приложение знает, — и это выгружается одним файлом
или стирается одной кнопкой, без «вы уверены, что хотите нас покинуть».

## Как устроен код

Ванильный JavaScript без зависимостей и без сборки: девятнадцать обычных скриптов,
которые складываются в пространство имён `Most`.

```
index.html              разметка и политика безопасности
styles.css              оформление, светлая и тёмная темы
src/util.js             DOM-помощники, склонения, копирование, выгрузка
src/store.js            localStorage, схема данных, миграции, экспорт, стирание
src/content/pulls.js    семь тяг — то, что тянет под словом «хочу»
src/content/clarify.js  вопросы разбора
src/content/paths.js    17 путей × 4 шага, у каждого шага уменьшенная версия
src/logic/choose.js     подбор пути под силы, размер шага, момент «пора отпускать»
src/workshop/           прототипы, письма, разбор бардака
src/screens/            экраны
src/app.js              маршруты, подвал, счётчик времени сессии
tools/build.js          сборка в одну страницу
```

## Проверки

```
node tests/run.js
```

83 проверки без единой зависимости: содержание путей, подбор под силы, хранилище
и миграции, сборка писем и файлов. Отдельная проверка следит за тем, чтобы в текстах
не было форм, назначающих человеку пол: приложение обращается на «ты» и не знает,
кто по ту сторону.

`tests/walkthrough.html` — прогон всего пути в браузере: открыть файл и посмотреть
на список проверок внизу страницы.

## Что сюда сознательно не попало

- Уведомления, серии, напоминания, «ты не заходил 5 дней».
- Аккаунты и синхронизация: они требуют сервера, а сервер требует доверия.
- Соцсеть, лента, чужие успехи.
- Оплата за ускорение.
- Геймификация прогресса: пройденные шаги видно, но это список вещей, а не очки.

## Куда это может расти

Живой разговорный разбор (языковая модель, которая переформулирует желание своими
словами, а не выбором из готовых вариантов) — следующий очевидный шаг. Важно только,
чтобы он не сломал главное обещание: данные уходят наружу либо никогда, либо по явной
просьбе человека и только та их часть, которую он видит своими глазами.

Правила, по которым принимались решения, — в [docs/PRINCIPLES.md](docs/PRINCIPLES.md).
