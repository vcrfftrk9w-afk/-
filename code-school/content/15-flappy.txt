@theory
Третий проект — **Flappy Bird** [флэ́ппи бёрд] — «хлопающая птичка». В 2014 году эту простую игру скачали больше 50 миллионов раз! Правила: птица падает, нажатие — взмах вверх. Нужно пролетать между трубами.

## План

1. **Птица машет крыльями** ← ты здесь
2. Бесконечные трубы
3. Столкновения и очки
4. Старт, рекорд и новая игра

## Физика птицы

Всё как в уроке про гравитацию и прыжок:

- каждый кадр `vy += gravity` — птица разгоняется вниз;
- взмах — резкая скорость вверх: `vy = -flapPower`.

Главное отличие от прыжка: взмахивать можно **в воздухе** сколько угодно — никакой проверки «на земле».

## Управление: и клавиши, и клик

Чтобы играть и на компьютере, и на телефоне, взмах делаем по пробелу **и** по клику (касанию). Обе подписки вызывают одну функцию `flap()`:

```code
function flap() {
  bird.vy = -flapPower;
}

document.addEventListener("keydown", (e) => {
  if (e.key === " " || e.key === "ArrowUp") flap();
});
canvas.addEventListener("click", flap);
```

Обрати внимание: в `addEventListener("click", flap)` мы передаём **саму функцию** — без скобок! Со скобками `flap()` функция выполнилась бы сразу, один раз, а нам нужно «вызывать при каждом клике».

> 🎮 Холст в этом проекте **вертикальный** — 360 × 480, как экран телефона.
@task

2. Функция `flap()` задаёт `bird.vy = -flapPower`.
3. Вызывай `flap()` по пробелу и по клику по холсту.

@lesson flp-2
title: Шаг 2. Бесконечные трубы
xp: 20
@theory
Теперь — **трубы**. Они появляются справа и едут налево. Каждая «труба» — это пара: верхняя и нижняя, а между ними **проход** (gap [гэп] — «промежуток»).

Хранить можно всего два числа на пару: `x` (где труба) и `gapY` (где начинается проход):

```code
{ x: 360, gapY: 150 }
```

Верхняя труба — от 0 до `gapY`, нижняя — от `gapY + GAP` до низа холста.

## Новые трубы через равные промежутки

Будем считать кадры. Каждые 90 кадров (≈1.5 секунды) — новая труба:

```code
frame++;
if (frame % 90 === 0) addPipe();
```

`frame % 90 === 0` — «номер кадра делится на 90» — верно на 90-м, 180-м, 270-м кадре…

## Проход в случайном месте

```code
function addPipe() {
  const gapY = randomInt(60, canvas.height - 60 - GAP);
  pipes.push({ x: canvas.width, gapY: gapY, passed: false });
}
```

Отступ 60 сверху и снизу — чтобы проход не прилипал к краю экрана. Свойство `passed` [пэст] — «пролетели» — пригодится в следующем шаге для очков.

## Уборка

Трубы, уехавшие за левый край, удаляем — иначе через пару минут их будут тысячи, и игра начнёт тормозить:

```code
pipes = pipes.filter((p) => p.x + PIPE_W > 0);
```

> 🎮 Так делают «бесконечные» игры (раннеры): мир создаётся впереди и удаляется позади. Сам мир стоит на месте — двигаются препятствия.
@task

@lesson flp-3
title: Шаг 3. Столкновения и очки
xp: 20
@theory
Теперь птица может **разбиться**, а за каждую пролетённую трубу — **очко**.

## Столкновение с трубой

Птица задела трубу, если она одновременно:
1. **по горизонтали** — на уровне трубы: правый край птицы правее левого края трубы **и** левый край птицы левее правого края трубы;
2. **по вертикали** — **не** внутри прохода.

```code
function hitsPipe(p) {
  const inX = bird.x + bird.r > p.x && bird.x - bird.r < p.x + PIPE_W;
  const inGap = bird.y - bird.r > p.gapY && bird.y + bird.r < p.gapY + GAP;
  return inX && !inGap;
}
```

(Птицу считаем квадратом вокруг круга — для этой игры этого достаточно.)

## Земля и небо

Коснулась земли или улетела выше экрана — тоже конец:

```code
if (bird.y + bird.r > canvas.height || bird.y - bird.r < 0) gameOver = true;
```

## Очки

Очко — когда труба целиком проехала **левее** птицы. Чтобы не засчитать одну трубу 60 раз (каждый кадр!), помечаем её `passed = true`:

```code
if (!p.passed && p.x + PIPE_W < bird.x) {
  p.passed = true;
  score++;
}
```

> 🧠 Флажок «уже засчитано» — очень частый приём. Без него условие верно много кадров подряд, и событие срабатывает многократно.
@task
1. Напиши `hitsPipe(p)` — возвращает `true`, если птица задевает трубу `p` (формула в теории).
2. В `update()`: если игра окончена (`gameOver`) — ничего не делай (`return`).
3. В цикле по трубам: если птица задела трубу — `gameOver = true`; если труба пролетела левее птицы и ещё не засчитана — `passed = true` и `score++`.
4. Если птица коснулась земли или верхнего края — `gameOver = true`.

const bird = { x: 80, y: 200, r: 14, vy: 0 };
const gravity = 0.4;
const flapPower = 7;
const GAP = 140;
const PIPE_W = 60;
const PIPE_SPEED = 2;
let pipes = [];
let frame = 0;
let score = 0;
let gameOver = false;

function randomInt(min, max) {
  return Math.floor(Math.random() * (max - min + 1)) + min;
}

function flap() { bird.vy = -flapPower; }
document.addEventListener("keydown", (e) => {
  if (e.key === " " || e.key === "ArrowUp") flap();
});
canvas.addEventListener("click", flap);

function addPipe() {
  const gapY = randomInt(60, canvas.height - 60 - GAP);
  pipes.push({ x: canvas.width, gapY: gapY, passed: false });
}

// 1. Задела ли птица трубу?
function hitsPipe(p) {
  const inX = bird.x + bird.r > p.x && bird.x - bird.r < p.x + PIPE_W;
  const inGap = bird.y - bird.r > p.gapY && bird.y + bird.r < p.gapY + GAP;
  return inX && !inGap;
}

function update() {
  // 2. Игра окончена — стоим
  if (gameOver) return;

  bird.vy += gravity;
  bird.y += bird.vy;

  frame++;
  if (frame % 90 === 0) addPipe();
  for (const p of pipes) {
    p.x -= PIPE_SPEED;
    // 3. Столкновение и очки
    if (hitsPipe(p)) gameOver = true;
    if (!p.passed && p.x + PIPE_W < bird.x) {
      p.passed = true;
      score++;
    }
  }
  pipes = pipes.filter((p) => p.x + PIPE_W > 0);

  // 4. Земля и небо
  if (bird.y + bird.r > canvas.height || bird.y - bird.r < 0) gameOver = true;
}

function draw() {
  ctx.fillStyle = "#4ec0ff";
  ctx.fillRect(0, 0, canvas.width, canvas.height);
  ctx.fillStyle = "#3cb043";
  for (const p of pipes) {
    ctx.fillRect(p.x, 0, PIPE_W, p.gapY);
    ctx.fillRect(p.x, p.gapY + GAP, PIPE_W, canvas.height - p.gapY - GAP);
  }
  ctx.font = bird.r * 2 + "px Arial";
  ctx.textAlign = "center";
  ctx.fillText(gameOver ? "💥" : "🐤", bird.x, bird.y + bird.r * 0.7);
  ctx.fillStyle = "white";
  ctx.font = "bold 40px Arial";
  ctx.fillText(score, canvas.width / 2, 60);
  ctx.textAlign = "left";
}

@lesson flp-4
title: Шаг 4. Старт, рекорд и новая игра
xp: 25
@theory
Финальные штрихи, которые превращают прототип в игру:

1. **Экран старта.** Игра не начинается сразу — птица висит в воздухе и ждёт первого нажатия.
2. **Рекорд**, который сохраняется даже после закрытия браузера.
3. **Новая игра** по нажатию после проигрыша.

## Три состояния

```code
let state = "ready";   // "ready" — ждём старта, "play" — летим, "over" — разбились
```

Одна функция `flap()` делает разное в зависимости от состояния:

```code
function flap() {
  if (state === "over") { restart(); return; }
  state = "play";
  bird.vy = -flapPower;
}
```

## Рекорд в localStorage

```code
let best = Number(localStorage.getItem("flappyBest")) || 0;

function endGame() {
  state = "over";
  if (score > best) {
    best = score;
    localStorage.setItem("flappyBest", best);
  }
}
```

> 💡 Ключ называем по имени игры (`"flappyBest"`), чтобы рекорды разных игр не перепутались.

> 🏆 Готово! Твой Flappy Bird можно показывать друзьям. Идеи для улучшений: трубы ускоряются со временем, птица наклоняется по скорости (`ctx.rotate`), медали за 10, 20, 50 очков.
@task
1. `flap()`: если `state === "over"` — вызови `restart()` и выйди; иначе поставь `state = "play"` и сделай взмах.
2. `endGame()`: `state = "over"` и, если `score > best`, обнови `best` и сохрани его в `localStorage` под ключом `"flappyBest"`.
3. `restart()`: птица в начальную точку (`y = 200`, `vy = 0`), трубы пустые, `frame = 0`, `score = 0`, `state = "ready"`.
4. В `update()`: пока `state !== "play"` — ничего не делай. Вместо `gameOver = true` вызывай `endGame()`.
