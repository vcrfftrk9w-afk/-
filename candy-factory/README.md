# 🍬 Конфетная фабрика (тайкун для Roblox)

Каждый игрок получает свою фабрику: машины делают конфеты, конвейер везёт их в приёмник, конфеты превращаются в деньги. На деньги покупаются новые машины и улучшения, а перерождение даёт множитель дохода.

## Как собрать игру

1. Roblox Studio → **New → Baseplate** (новая игра, не Лавовая башня).
2. **ServerScriptService → ⊕ → Script**, вставь [`FactoryEconomy.server.lua`](FactoryEconomy.server.lua).
3. Ещё раз **⊕ → Script**, вставь [`FactoryPlots.server.lua`](FactoryPlots.server.lua).
4. В обоих скриптах проверь, что последняя строчка — `-- КОНЕЦ СКРИПТА`.
5. **File → Publish to Roblox** → новая игра → Create.
6. В Creator Hub: **Аудитория → Общественный**, заполнить анкету.
7. **Experience Settings → Basic Info** или Creator Hub: поставь **макс. игроков на сервере = 6** (фабрик 6).

## Что внутри

| Покупка | Цена | Что даёт |
|---|---|---|
| Конфетная машина | бесплатно | 1 💰 за конфету |
| Вторая машина | 40 | 1 💰 |
| Мармеладная машина | 150 | 3 💰 |
| Стены фабрики | 400 | красота |
| Сахарный турбо | 800 | конфеты +50% |
| Шоколадная машина | 1.5K | 8 💰 |
| Леденцовая машина | 4K | 15 💰 |
| Двойная выдача | 9K | машины делают по 2 конфеты |
| Радужная машина | 20K | 40 💰 |
| Конфетная башня | 35K | красота |
| Золотая машина | 60K | 100 💰 |

- **Перерождение** (фиолетовая кнопка): 100K, 200K, 300K… Сбрасывает фабрику, но доход умножается на (1 + число перерождений).
- **Ежедневная награда** раз в 20 часов.
- Прогресс сохраняется (в опубликованной игре).

## Заработок Robux

В лобби стоят 4 кнопки магазина. Чтобы они начали продавать:

1. **create.roblox.com → Creations → твоя игра → Monetization → Passes → Create a Pass**
   - «Деньги x2» и «Автосбор». Включи продажу (**For Sale**) и поставь цену, например 99 и 149 Robux.
2. **Monetization → Developer Products → Create**
   - «Мешок денег» (например 25 Robux) и «Буст x3 на 10 минут» (например 15 Robux).
3. Скопируй ID каждой покупки и впиши их в начало `FactoryEconomy` в `CONFIG`:
   `PassDoubleMoney`, `PassAutoCollect`, `ProductCashBag`, `ProductBoost`.
4. Опубликуй снова (**Alt + P**).

Пока ID равен 0, кнопка просто пишет «Эта покупка скоро появится!».
