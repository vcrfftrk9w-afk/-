## Ракетка и мяч — объекты

```code
const paddle = { x: 200, y: 296, w: 80, h: 12, speed: 7 };   // ракетка
const ball = { x: 240, y: 200, r: 7, vx: 3, vy: -3 };       // мяч
```

`paddle` [пэдл] — «ракетка», `ball` [бол] — «мяч».

> 💡 Хорошая практика: сначала сделать, чтобы всё **двигалось**, а уже потом — чтобы **сталкивалось**. Маленькими шагами, проверяя каждый.
@task

2. **Мяч:** сдвигай `ball.x` на `ball.vx` и `ball.y` на `ball.vy`.

  if (keys["ArrowLeft"]) paddle.x -= paddle.speed;
  if (keys["ArrowRight"]) paddle.x += paddle.speed;

@lesson brk-2
title: Шаг 2. Ракетка отбивает мяч
xp: 20
@theory
Теперь мяч должен **отскакивать от ракетки**, а если игрок промахнулся — теряется жизнь.

## Столкновение мяча с ракеткой

Используем `rectsCollide` из модуля «Физика». Мяч — круг, но для простоты представим его квадратом вокруг круга:

```code
function ballRect() {
  return { x: ball.x - ball.r, y: ball.y - ball.r, w: ball.r * 2, h: ball.r * 2 };
}
```

Отскакиваем, только если мяч летит **вниз** (`ball.vy > 0`). Иначе мяч, попавший в ракетку сбоку, может застрять и дрожать внутри.

## Угол отскока — секрет хорошего арканоида

Если мяч всегда отскакивает одинаково, игрок не может им управлять — скучно. В настоящем арканоиде угол зависит от того, **куда** мяч попал:

- в середину ракетки — летит почти вертикально вверх;
- ближе к правому краю — уходит вправо;
- ближе к левому — влево.

```code
const center = paddle.x + paddle.w / 2;
const hit = (ball.x - center) / (paddle.w / 2);   // от -1 (левый край) до 1 (правый)
ball.vx = hit * 5;
ball.vy = -Math.abs(ball.vy);
```

`hit` — насколько далеко от центра попал мяч: −1 на левом краю, 0 в центре, 1 на правом.

## Потеря мяча

Если мяч ушёл за нижний край — минус жизнь и мяч возвращается в центр:

```code
if (ball.y - ball.r > canvas.height) {
  lives--;
  resetBall();
}
```

@lesson brk-3
title: Шаг 3. Стена кирпичей
xp: 20
@theory
Самое приятное — **кирпичи**! Их 40 штук: 5 рядов по 8. Создадим их двойным циклом, как карту в модуле «Массивы».

```code
function makeBricks() {
  bricks = [];
  for (let row = 0; row < 5; row++) {
    for (let col = 0; col < 8; col++) {
      bricks.push({
        x: 10 + col * 58,
        y: 40 + row * 22,
        w: 54,
        h: 18,
        color: `hsl(${row * 45}, 80%, 60%)`
      });
    }
  }
}
```

- `col * 58` — ширина кирпича 54 плюс зазор 4;
- `row * 22` — высота 18 плюс зазор 4;
- цвет зависит от ряда — получается радуга.

Проверим ширину: 8 кирпичей × 58 = 464, плюс отступ 10 слева — правый край на 464 + 10 − 4 = 470. Влезает в холст шириной 480. ✓

## Мяч разбивает кирпич

Каждый кадр проверяем мяч со **всеми** кирпичами. Попал — удаляем кирпич, разворачиваем мяч по вертикали, добавляем очки:

```code
for (let i = bricks.length - 1; i >= 0; i--) {
  if (rectsCollide(ballRect(), bricks[i])) {
    bricks.splice(i, 1);
    ball.vy = -ball.vy;
    score += 10;
    break;   // за один кадр — только один кирпич
  }
}
```

`break` нужен, чтобы при попадании сразу в два соседних кирпича мяч не развернулся дважды (и не полетел дальше сквозь стену).

> 🎮 Хочешь крепкие кирпичи, которые разбиваются со второго удара? Добавь каждому `hp: 2` и удаляй только когда `hp` станет 0. Сделай это в песочнице после проекта!

  if (ball.vy > 0 && rectsCollide(ballRect(), paddle)) {
    const hit = (ball.x - (paddle.x + paddle.w / 2)) / (paddle.w / 2);
    ball.vx = hit * 5;
    ball.vy = -Math.abs(ball.vy);
  }

  // 3. Мяч разбивает кирпич
  for (let i = bricks.length - 1; i >= 0; i--) {
    if (rectsCollide(ballRect(), bricks[i])) {
      bricks.splice(i, 1);
      ball.vy = -ball.vy;
      score += 10;
      break;
    }
  }

  if (ball.y - ball.r > canvas.height) {
    lives--;
    resetBall();
  }
}

function draw() {
  ctx.fillStyle = "#0d1326";
  ctx.fillRect(0, 0, canvas.width, canvas.height);
  // 2. Нарисовать кирпичи
  for (const b of bricks) {
    ctx.fillStyle = b.color;
    ctx.fillRect(b.x, b.y, b.w, b.h);
  }
  ctx.fillStyle = "#7c6cff";
  ctx.fillRect(paddle.x, paddle.y, paddle.w, paddle.h);
  ctx.fillStyle = "white";
  ctx.beginPath();
  ctx.arc(ball.x, ball.y, ball.r, 0, Math.PI * 2);
  ctx.fill();
  ctx.font = "18px Arial";
  ctx.fillText("❤️".repeat(Math.max(0, lives)) + "   Очки: " + score, 10, 26);
}

title: Шаг 4. Победа и поражение
xp: 25
@theory
Осталось превратить это в законченную игру: **победа**, когда разбиты все кирпичи, **поражение**, когда кончились жизни, и **новая игра** по пробелу.

## Состояние игры

Заведём переменную `state` [стэйт] — «состояние»:

| state | Что происходит |
|---|---|
| `"play"` | идёт игра |
| `"win"` | победа — все кирпичи разбиты |
| `"lose"` | поражение — кончились жизни |

```code
let state = "play";

function update() {
  if (state !== "play") return;   // не играем — ничего не двигаем
  // ...
  if (bricks.length === 0) state = "win";
  if (lives <= 0) state = "lose";
}
```

> 🧠 Такой подход называется **конечный автомат** (state machine). У игры есть несколько состояний, и в каждом она ведёт себя по-своему. Меню, игра, пауза, экран победы — всё это состояния. Так устроены почти все игры.

## Экран результата

```code
if (state === "win") showMessage("ПОБЕДА! 🏆");
if (state === "lose") showMessage("Игра окончена");
```

Функция `restart()` возвращает всё как было: жизни, очки, кирпичи, мяч, состояние.
