# Terra Forge (Roblox)

Стратегия на настоящей карте мира. Ставишь столицу в любой точке Земли, захватываешь землю войсками, строишь шахты и заводы и выпускаешь пехоту, танки и самолёты. Над страной видны твой ник и аватарка из Roblox.

Название пока рабочее.

## Как запустить

Нужен компьютер (Windows или Mac) с Roblox Studio.

1. Скачай `build/TerraForge.rbxlx`.
2. В Roblox Studio выбери **File → Open from File** и открой этот файл.
3. Опубликуй игру: **File → Publish to Roblox**.
4. Открой **Game Settings** и включи **Allow Mesh / Image APIs** (обычно в разделе Security). Без этого карта не нарисуется: игра покажет сообщение об этом.
5. Нажми **Play**. Проверить игру с друзьями можно через **Test → Clients and Servers**, там же выбирается число игроков.

## Как устроено

| Где | Что |
| --- | --- |
| `src/shared` | общее для сервера и клиента: правила (`Config`), карта мира (`Map`, `MapData`), иконки (`Icons`), формат сетевых данных (`Codec`) |
| `src/server` | сервер: матч, боты, экономика, постройки, войска (`Match`), захват территории (`World`) |
| `src/client` | клиент: карта на экране (`MapView`), меню и интерфейс (`Ui`), иконки (`Sprites`), стиль (`Theme`) |
| `tools` | генераторы данных и сборка файла игры |

Сервер ведёт один матч на 40 стран: игроки плюс боты. Всё считает сервер, клиенты только рисуют. Каждые 0,2 секунды сервер рассылает изменения территории сжатыми пакетами.

Карту рисуют два EditableImage размером 720 × 336: рельеф и территории. Войска, постройки и подписи лежат поверх как обычные элементы интерфейса.

## Правка и пересборка

Код можно править прямо в Studio. Если работаешь с файлами из этой папки, после правок собери файл игры заново:

```
python3 tools/build_place.py
```

Ещё можно подключить [Rojo](https://rojo.space) к `default.project.json`.

Генераторы данных:

- `tools/gen_map.py` переводит карту Natural Earth (общественное достояние) в клетки;
- `tools/gen_icons.js` рисует иконки из `tools/icons.js`, для него нужен Playwright;
- `tools/gen_data.py` записывает `Icons.luau` и `MapData.luau`;
- `tools/check_luau.py` быстро проверяет код Luau: блоки, скобки, неизвестные имена.
