@lesson canvas-1
title: Холст и координаты
@theory
Пора рисовать! Браузерные игры рисуются на **холсте** — по-английски `canvas` [кэ́нвас]. Это прямоугольная область, на которой можно рисовать фигуры, текст и картинки.

Рисуют на холсте с помощью «кисти» — **контекста рисования**. Обычно её называют `ctx` (сокращение от context [ко́нтекст]).

> 💡 В этом курсе холст и кисть уже готовы: просто пиши `ctx.`… Размер холста — **480 × 320** точек (пикселей). В настоящей веб-странице их достают так: `const canvas = document.getElementById("game"); const ctx = canvas.getContext("2d");` — об этом подробно в последнем модуле.

## Первый прямоугольник

```js canvas
ctx.fillStyle = "orange";
ctx.fillRect(50, 40, 120, 80);
```

- `ctx.fillStyle = "orange"` — выбрать цвет заливки (`fillStyle` [фил стайл] — «стиль заливки»);
- `ctx.fillRect(x, y, ширина, высота)` — нарисовать закрашенный прямоугольник (`fill rect` [фил ре́кт] — «залить прямоугольник»).

## Координаты — самое важное

Каждая точка холста имеет два числа: **x** и **y**.

- **x** — сколько шагов **вправо** от левого края;
- **y** — сколько шагов **вниз** от верхнего края.

> ⚠️ Внимание: в отличие от школьной математики, **y растёт вниз**! Точка (0, 0) — в **левом верхнем** углу. Чем больше y, тем ниже.

```js canvas
ctx.fillStyle = "red";
ctx.fillRect(0, 0, 40, 40);

ctx.fillStyle = "lime";
ctx.fillRect(440, 0, 40, 40);

ctx.fillStyle = "cyan";
ctx.fillRect(0, 280, 40, 40);

ctx.fillStyle = "yellow";
ctx.fillRect(220, 140, 40, 40);
```

Красный — в левом верхнем углу (x = 0, y = 0). Зелёный — в правом верхнем (x = 440, потому что 480 − 40). Голубой — в левом нижнем. Жёлтый — примерно в центре.

У прямоугольника `x` и `y` — это его **левый верхний угол**.

> 🎮 Двигать героя по экрану = менять его x и y. Вправо — x больше, влево — меньше, вниз — y больше, вверх — меньше.

@lesson canvas-2
title: Цвета
@theory
Цвет можно задать несколькими способами.

## 1. Названием

Английское слово: `"red"`, `"blue"`, `"green"`, `"yellow"`, `"orange"`, `"purple"`, `"pink"`, `"white"`, `"black"`, `"gray"`, `"gold"`, `"cyan"`, `"lime"`, `"brown"`… Всего названий больше 140!

```js canvas
const colors = ["red", "orange", "yellow", "lime", "cyan", "blue", "purple", "pink"];
for (let i = 0; i < colors.length; i++) {
  ctx.fillStyle = colors[i];
  ctx.fillRect(20 + i * 56, 120, 50, 80);
}
```

## 2. Шестнадцатеричным кодом

`"#ff0000"` — так задают цвета дизайнеры. Решётка и шесть символов: две цифры на красный, две на зелёный, две на синий. Цифры — от `00` (ноль) до `ff` (максимум).

| Код | Цвет |
|---|---|
| `#ff0000` | красный |
| `#00ff00` | зелёный |
| `#0000ff` | синий |
| `#ffffff` | белый |
| `#000000` | чёрный |
| `#ffa500` | оранжевый |

## 3. rgb — красный, зелёный, синий

`"rgb(255, 100, 0)"` — три числа от 0 до 255: сколько красного, зелёного и синего. Экран смешивает свет — как в фонарике.

```js canvas
for (let i = 0; i < 10; i++) {
  ctx.fillStyle = `rgb(${i * 25}, 50, ${255 - i * 25})`;
  ctx.fillRect(i * 48, 0, 48, 320);
}
```

## 4. hsl — по кругу оттенков

`"hsl(оттенок, 100%, 50%)"`: оттенок — угол на цветовом круге от 0 до 360 (0 — красный, 120 — зелёный, 240 — синий). Удобно для радуги:

```js canvas
for (let i = 0; i < 24; i++) {
  ctx.fillStyle = `hsl(${i * 15}, 90%, 55%)`;
  ctx.fillRect(i * 20, 100, 20, 120);
}
```

> 💡 `fillStyle` действует на всё, что рисуется **после** него, пока не выберешь другой цвет. Это как обмакнуть кисть в краску.

@lesson canvas-3
title: Круги и линии
@theory
Прямоугольники рисуются одной командой, а для остальных фигур нужно «вести перо» — рисовать **путь** (path [пас]).

## Круг

```js canvas
ctx.fillStyle = "gold";
ctx.beginPath();
ctx.arc(240, 160, 60, 0, Math.PI * 2);
ctx.fill();
```

1. `ctx.beginPath()` [биги́н пас] — «начать новый путь». Без этого новая фигура склеится со старыми.
2. `ctx.arc(x, y, радиус, начальныйУгол, конечныйУгол)` — `arc` [арк] — «дуга». Для полного круга углы от `0` до `Math.PI * 2`.
3. `ctx.fill()` — залить фигуру.

> ⚠️ У круга `x` и `y` — это **центр**, а не угол, как у прямоугольника.

> 🧠 Почему `Math.PI * 2`? Углы в программировании меряют не в градусах, а в радианах. Полный круг = 2π ≈ 6.28 радиан. Половина круга — `Math.PI`.

## Линии

```js canvas
ctx.strokeStyle = "white";
ctx.lineWidth = 4;
ctx.beginPath();
ctx.moveTo(40, 280);
ctx.lineTo(240, 40);
ctx.lineTo(440, 280);
ctx.closePath();
ctx.stroke();
```

- `moveTo(x, y)` [мув ту] — поставить перо в точку (не рисуя);
- `lineTo(x, y)` [лайн ту] — провести линию до точки;
- `closePath()` — соединить с началом;
- `stroke()` [стро́ук] — «обвести» — нарисовать линии;
- `strokeStyle` — цвет линий, `lineWidth` — толщина.

## Контур и заливка

У любой фигуры можно сделать и заливку (`fill`), и контур (`stroke`):

```js canvas
ctx.beginPath();
ctx.arc(120, 160, 50, 0, Math.PI * 2);
ctx.fillStyle = "tomato";
ctx.fill();
ctx.lineWidth = 6;
ctx.strokeStyle = "white";
ctx.stroke();

ctx.strokeStyle = "lime";
ctx.strokeRect(260, 110, 140, 100);
```

@lesson canvas-4
title: Текст на холсте
@theory
В каждой игре есть надписи: счёт, жизни, «Game Over». Текст рисуется командой `fillText`:

```js canvas
ctx.fillStyle = "white";
ctx.font = "28px Arial";
ctx.fillText("Счёт: 150", 20, 40);

ctx.fillStyle = "tomato";
ctx.font = "bold 48px Arial";
ctx.fillText("GAME OVER", 100, 180);
```

- `ctx.font = "28px Arial"` — размер и шрифт (`font` [фонт] — «шрифт»). Можно добавить `bold` — жирный;
- `ctx.fillText(текст, x, y)` — нарисовать текст.

> ⚠️ У текста `y` — это **нижняя линия букв** (как линейка в тетради), а не верх. Если написать `y = 0`, текст уйдёт за верхний край.

## Текст по центру

```js canvas
ctx.fillStyle = "gold";
ctx.font = "bold 36px Arial";
ctx.textAlign = "center";
ctx.fillText("УРОВЕНЬ 2", canvas.width / 2, canvas.height / 2);
```

`textAlign = "center"` [текст элайн] — выравнивание: теперь x — это середина текста. `canvas.width` и `canvas.height` — размеры холста, так что `canvas.width / 2` — середина по горизонтали.

## Числа и переменные в тексте

```js canvas
let score = 1250;
let lives = 3;
ctx.fillStyle = "white";
ctx.font = "22px Arial";
ctx.fillText(`Очки: ${score}`, 16, 32);
ctx.fillText("❤️".repeat(lives), 380, 32);
```

> 💡 Эмодзи тоже можно рисовать текстом — это самый быстрый способ получить «картинку» персонажа! 🐸👾🚀

@lesson canvas-5
title: Рисуем персонажа функцией
@theory
Персонаж состоит из нескольких фигур. Но если координаты каждой фигуры вписать числами, двигать его будет мучением — придётся менять все числа.

Хитрость: всё рисуем **относительно одной точки** `x, y`. И оборачиваем в функцию:

```js canvas
function drawHero(x, y) {
  // тело
  ctx.fillStyle = "royalblue";
  ctx.fillRect(x, y, 40, 50);
  // голова
  ctx.fillStyle = "peachpuff";
  ctx.beginPath();
  ctx.arc(x + 20, y - 15, 15, 0, Math.PI * 2);
  ctx.fill();
  // глаза
  ctx.fillStyle = "black";
  ctx.fillRect(x + 12, y - 19, 4, 4);
  ctx.fillRect(x + 24, y - 19, 4, 4);
  // ноги
  ctx.fillStyle = "saddlebrown";
  ctx.fillRect(x + 4, y + 50, 12, 16);
  ctx.fillRect(x + 24, y + 50, 12, 16);
}

drawHero(60, 150);
drawHero(220, 120);
drawHero(380, 200);
```

Три героя одной функцией! Голова на `x + 20` (центр тела), глаза на `x + 12` и `x + 24`… Меняешь `x` и `y` — двигается весь персонаж.

> 🎮 Именно так и рисуют игровых персонажей: функция `draw` с координатами. Чтобы персонаж «шёл», в анимации каждый кадр рисуют его с чуть другим `x`.

## Рисуем с картинкой-эмодзи

Быстрый способ сделать симпатичного героя — эмодзи:

```js canvas
function drawFrog(x, y, size) {
  ctx.font = size + "px Arial";
  ctx.fillText("🐸", x, y);
}
drawFrog(50, 200, 60);
drawFrog(200, 220, 100);
drawFrog(380, 180, 40);
```

@lesson canvas-6
title: Циклы на холсте
@theory
Цикл + рисование = целые миры за пару строчек.

## Ряд монет

```js canvas
for (let i = 0; i < 8; i++) {
  ctx.fillStyle = "gold";
  ctx.beginPath();
  ctx.arc(40 + i * 55, 160, 18, 0, Math.PI * 2);
  ctx.fill();
}
```

`40 + i * 55` — каждая следующая монета на 55 пикселей правее.

## Стена из кирпичей — двойной цикл

```js canvas
const brickW = 56, brickH = 22;
for (let row = 0; row < 5; row++) {
  for (let col = 0; col < 8; col++) {
    ctx.fillStyle = `hsl(${row * 40}, 80%, 55%)`;
    ctx.fillRect(10 + col * (brickW + 2), 20 + row * (brickH + 4), brickW, brickH);
  }
}
```

Это почти готовое поле для арканоида!

```js canvas
  const y = Math.random() * canvas.height;
  const size = Math.random() * 2.5;
  ctx.fillStyle = "white";
  ctx.fillRect(x, y, size, size);
}
```

Запусти несколько раз — каждый раз новое небо.

## Рисуем карту из массива

Помнишь карту уровня из модуля про массивы? Вот она в графике:

```js canvas
const level = [
  "############",
  "#..........#",
  "#..##..o...#",
  "#......##..#",
  "#..o.......#",
  "############"
];
const size = 40;
for (let y = 0; y < level.length; y++) {
  for (let x = 0; x < level[y].length; x++) {
    const cell = level[y][x];
    if (cell === "#") ctx.fillStyle = "#5a4fcf";
    else if (cell === "o") ctx.fillStyle = "gold";
    else ctx.fillStyle = "#1c2244";
    ctx.fillRect(x * size, y * size, size - 1, size - 1);
  }
}
```

> 💡 Строка — это тоже как массив символов: `level[y][x]` даёт один символ. Так удобно «рисовать» уровни прямо текстом.
