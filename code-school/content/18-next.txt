## Из чего состоит веб-страница с игрой

Любая браузерная игра — это файл с расширением `.html`. Вот минимальный шаблон:

```text
<!DOCTYPE html>
<html lang="ru">
<head>
  <meta charset="utf-8">
  <title>Моя игра</title>
</head>
<body style="margin: 0; background: #111;">
  <canvas id="game" width="480" height="320"></canvas>
  <script>
    const canvas = document.getElementById("game");
    const ctx = canvas.getContext("2d");

    // здесь твой код игры
  </script>
</body>
</html>
```

- `<canvas id="game" ...>` — холст с именем (id [ай-ди]) «game»;
- `<script> ... </script>` — внутри пишется JavaScript;
- `document.getElementById("game")` — найти на странице элемент с id «game» — это наш холст;
- `canvas.getContext("2d")` — получить «кисть» для 2D-рисования.

Это ровно те две строчки, которые в нашем курсе были «уже готовы»!

> 🧠 HTML [эйч-ти-эм-эл] — это язык разметки страниц: он описывает, **что** на странице (заголовки, кнопки, холст). А JavaScript описывает, **как** это работает.

## Самый простой способ: кнопка «Скачать»

В **🧪 Песочнице** есть кнопка **⬇ Скачать игру** — она сама соберёт файл `.html` из твоего кода. Скачай его и открой двойным щелчком — игра запустится в браузере, даже без интернета. Файл можно отправить другу в мессенджере.

## Как сделать файл вручную

1. Открой «Блокнот» (Windows) или TextEdit (Mac, в режиме «простой текст»).
2. Вставь шаблон и свой код.
3. Сохрани как `game.html` — кодировка **UTF-8**.
4. Открой файл двойным щелчком.

> 💡 Для программирования удобнее специальный редактор — например, бесплатный **Visual Studio Code**. Он подсвечивает код как в нашем курсе, подсказывает команды и находит ошибки.

## Публикация в интернете — бесплатно

- **itch.io** [итч-ай-оу] — сайт для инди-игр. Загружаешь свой `.html` (в zip-архиве) — и игра доступна по ссылке, в неё может сыграть любой человек в мире.
- **GitHub Pages** [ги́тхаб пэйджес] — бесплатный хостинг страниц: создаёшь репозиторий, кладёшь туда `index.html` — получаешь адрес вида `имя.github.io/игра`.

> 🎮 Многие известные инди-разработчики начинали ровно так: маленькая игра в браузере, ссылка друзьям, отзывы, следующая игра — уже лучше.

## Ошибки по-английски — шпаргалка

Вне нашего приложения ошибки будут только на английском. Вот самые частые — теперь ты их узнаешь:

| Сообщение | Перевод | Что делать |
|---|---|---|
| `x is not defined` | x не определён | опечатка или переменная не объявлена |
| `x is not a function` | x — не функция | опечатка в имени функции |
| `Unexpected token` | неожиданный символ | лишняя или пропущенная скобка, запятая |
| `Unexpected end of input` | неожиданный конец | не закрыта скобка `}` |
| `Cannot read properties of undefined` | нельзя прочитать свойство у undefined | объект пустой, проверь имя |
| `Assignment to constant variable` | присваивание константе | замени `const` на `let` |
| `Maximum call stack size exceeded` | превышен размер стека | функция вызывает себя бесконечно |

## Как найти ответ на любой вопрос

1. **Документация на русском.** Справочник MDN (developer.mozilla.org) — главная энциклопедия веба. Многие статьи переведены на русский. Ищи: «MDN fillRect» или «MDN массивы».
2. **Переводчик в браузере.** Правая кнопка мыши → «Перевести на русский». Работает для любой документации.
3. **Скопируй ошибку в поиск.** Целиком, по-английски. Почти у любой ошибки есть ответ на форумах — и браузер их переведёт.
4. **Спроси нейросеть.** Вставь свой код и ошибку и попроси объяснить по-русски. Но не копируй ответ бездумно — разберись, почему так.

> 💡 Не нужно учить английский «на всякий случай». Учи слова, когда они встречаются в коде, — так они запоминаются сами. Именно так ты и учился весь этот курс.

## Игровые движки

**Движок** — это большая программа, где уже готовы физика, звук, анимации и редактор уровней. Ты пишешь только логику игры.

| Движок | Язык | Для чего | Сложность |
|---|---|---|---|
| **Phaser** [фэ́йзер] | JavaScript | 2D-игры в браузере — твой следующий шаг | ⭐⭐ |
| **Godot** [годо́] | GDScript (похож на Python) | 2D и 3D, бесплатный, очень популярен у инди | ⭐⭐ |
| **Roblox Studio** [ро́блокс] | Lua [лу́а] | игры внутри Roblox | ⭐⭐ |
| **Unity** [ю́нити] | C# [си-шарп] | 2D, 3D, мобильные игры | ⭐⭐⭐ |
| **Unreal Engine** [анри́л] | C++ / Blueprints | крупные 3D-игры | ⭐⭐⭐⭐ |

> 💡 Хорошая новость: переменные, условия, циклы, функции, массивы, объекты и классы есть **во всех** этих языках. Ты уже знаешь 80% идей — останется привыкнуть к другой записи.

Например, тот же цикл на Python (язык для Godot похож на него):

```text
for i in range(5):
    print("Шаг", i)
```

И на C# (Unity):

```text
for (int i = 0; i < 5; i++) {
    Debug.Log("Шаг " + i);
}
```

Узнаёшь? Это тот же `for`!

## Идеи для своих игр

Начинай с маленького — и обязательно **доводи до конца**:

1. **Кликер:** кликай по печенью, покупай улучшения.
2. **Пинг-понг на двоих:** W/S и стрелки на одной клавиатуре.
3. **Уворачивайся:** с неба падают предметы, уклоняйся как можно дольше.
4. **Лабиринт:** карта из символов, найди выход за время.
5. **Тетрис** — классика посложнее, отличная тренировка массивов.
6. **Pac-Man** — карта, враги с простым «интеллектом».
7. **Tower Defense** — враги идут по дорожке, ставь башни.

## Советы, которые реально работают

- 🔁 **Понемногу, но каждый день.** 20 минут в день лучше, чем 5 часов раз в неделю.
- ✅ **Заканчивай проекты.** Маленькая законченная игра ценнее десяти брошенных больших.
- 🧩 **Улучшай свои игры из курса.** Добавь в змейку уровни, в шутер — босса, в платформер — новые карты.
- 🏆 **Участвуй в геймджемах** (game jam [гейм джем]) — конкурсах «сделай игру за выходные». Их много на itch.io.
- 🤝 **Показывай игры людям.** Отзывы — лучший учитель.
