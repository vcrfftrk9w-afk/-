# 🎮 ИгроКод — программирование игр с нуля

Интерактивный курс программирования игр на JavaScript **на русском языке**. Подходит человеку, который
никогда не программировал и не знает английского: каждое английское слово в коде переводится
(наведи мышку или поставь курсор), ошибки объясняются по-русски, у каждого слова есть произношение.

Чистые HTML/CSS/JS — без сборки, без сервера, работает офлайн и на телефоне.

## Что внутри

- **18 модулей, 93 урока**: от `console.log("Привет")` до классов и игровой физики.
- **5 игровых проектов** шаг за шагом: Змейка, Арканоид, Flappy Bird, Платформер, Космический шутер.
- **Редактор кода** с подсветкой, номерами строк, автоотступами, панелью символов и переводом слова под курсором.
- **Автопроверка** каждого задания: робот запускает код ученика и отмечает выполненные пункты; в играх он сам «нажимает» клавиши.
- **Ошибки по-русски**: что случилось, на какой строке и как исправить; ловит русские буквы в английских словах, «ёлочки» вместо кавычек, бесконечные циклы.
- **Подсказки** (по одной) и решение; тесты после каждого урока; итоговый экзамен.
- **Песочница**: свой код, шаблоны и готовые игры, сохранение проектов, «⬇ Скачать игру» отдельным `.html`-файлом.
- **Словарь** — 280+ слов с переводом, произношением русскими буквами и озвучкой.
- **Опыт, 10 уровней, 39 достижений, серия дней** и сертификат в конце. Озвучка уроков.
- Тёмная и светлая тема, перенос прогресса на другое устройство кодом.

## Запуск

Открой `code-school/index.html` в браузере — и всё. Или подними сервер из корня репозитория:

```bash
python3 -m http.server 8793   # затем http://localhost:8793/code-school/
```

Через GitHub Pages курс доступен по адресу `https://<логин>.github.io/<репозиторий>/code-school/`
и устанавливается на телефон как приложение («Добавить на главный экран»).

## Как устроено

| Папка | Что там |
|---|---|
| `content/*.txt` | **Исходники уроков** — теория, задание, код, проверки, подсказки, тесты. Правь здесь. |
| `course/*.js` | Собранные уроки. Не правь руками — пересобери. |
| `js/` | Приложение: редактор (`editor.js`), запуск кода в песочнице (`runner.js`), перевод ошибок (`errors.js`), словарь (`glossary.js`), экраны (`view-*.js`). |
| `tools/build-course.js` | Сборка `content/` → `course/` и шаблонов песочницы. |
| `tests/` | Проверки в настоящем браузере. |

После правки уроков:

```bash
node code-school/tools/build-course.js
```

Формат урока описан в начале `tools/build-course.js`. Коротко:

```text
@lesson id-урока
title: Название
@theory
Текст теории. ```js — пример с кнопкой «Запустить», ```js canvas — пример с холстом.
@task
Текст задания.
@canvas
@starter
начальный код
@solution
эталонное решение
@test Что проверяем
выражение JavaScript, которое должно быть true
@hint
подсказка
@quiz
? Вопрос
- неверный ответ
+ верный ответ
= объяснение
```
