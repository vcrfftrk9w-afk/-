@lesson cls-1
title: Класс — чертёж для объектов
@theory
В игре сто врагов. У каждого — `x`, `y`, здоровье, скорость, методы `update` и `draw`. Писать сто одинаковых объектов вручную? Конечно нет. Нужен **чертёж**, по которому объекты создаются сами. Такой чертёж называется **класс**.

```js
class Enemy {
  constructor(x, y) {
    this.x = x;
    this.y = y;
    this.hp = 30;
    this.speed = 2;
  }
}

const goblin = new Enemy(100, 50);
const orc = new Enemy(300, 80);

console.log(goblin);
console.log(orc.x, orc.hp);
```

## Разбор

- `class Enemy { ... }` — объявляем класс (`class` [класс]). Имя класса принято писать **с большой буквы**.
- `constructor(x, y)` [констра́ктор] — особый метод, который **настраивает** новый объект. Вызывается автоматически при создании.
- `this.x = x` — «у этого нового объекта свойство x равно переданному x».
- `new Enemy(100, 50)` [нью] — «создай **новый** объект по чертежу Enemy». Аргументы попадают в constructor.

> 🧠 Сравни: класс — это **форма для печенья**, а объекты — сами **печенья**. Форма одна, печений сколько угодно. Каждое печенье — отдельное: если откусить одно, другие останутся целыми.

## Каждый объект — отдельный

```js

  constructor(x, y) {
    this.x = x;
    this.y = y;
    this.value = 10;
  }

const coins = [];

  coins.push(new Coin(i * 50, 100));

coins[2].value = 100;
```

@lesson cls-2
title: Методы класса — update и draw
@theory
В классе можно описать не только свойства, но и **методы** — то, что объект умеет делать. Методы пишутся внутри класса после конструктора:

```js canvas
class Ball {
  constructor(x, y, color) {
    this.x = x;
    this.y = y;
    this.vx = Math.random() * 6 - 3;
    this.vy = Math.random() * 6 - 3;
    this.r = 12;
    this.color = color;
  }

  update() {
    this.x += this.vx;
    this.y += this.vy;
    if (this.x < this.r || this.x > canvas.width - this.r) this.vx = -this.vx;
    if (this.y < this.r || this.y > canvas.height - this.r) this.vy = -this.vy;
  }

  draw() {
    ctx.fillStyle = this.color;
    ctx.beginPath();
    ctx.arc(this.x, this.y, this.r, 0, Math.PI * 2);
    ctx.fill();
  }
}

const balls = [];
for (let i = 0; i < 25; i++) {
  balls.push(new Ball(240, 160, `hsl(${i * 14}, 90%, 60%)`));
}

function loop() {
  ctx.clearRect(0, 0, canvas.width, canvas.height);
  for (const b of balls) {
    b.update();
    b.draw();
  }
  requestAnimationFrame(loop);
}
loop();
```

Смотри, как просто стал игровой цикл: «каждый мяч — обновись и нарисуйся». Вся логика мяча спрятана внутри класса.

## Методы, которые отвечают на вопросы

Метод может возвращать значение. Например, «улетел ли объект за экран?»:

```code
isOffScreen() {
  return this.y < 0 || this.y > canvas.height;
}
```

> 💡 Внутри методов к свойствам объекта обращаются через `this` — как в объектах из модуля 7.

> 🎮 Почти любой игровой объект — это класс с методами `update()` и `draw()`. Добавить в игру новый вид врагов = написать новый класс.

@lesson cls-3
title: Наследование — босс тоже враг
@theory
Обычный враг: здоровье, движение, получение урона. Босс: всё то же самое, **плюс** больше здоровья и особая атака. Копировать весь код врага в босса? Нет — можно сказать, что босс **наследует** всё от врага.

```js
class Enemy {
  constructor(x, y) {
    this.x = x;
    this.y = y;
    this.hp = 20;
  }

  takeDamage(amount) {
    this.hp -= amount;
    if (this.hp <= 0) console.log("Враг повержен!");
  }
}

class Boss extends Enemy {
  constructor(x, y) {
    super(x, y);
    this.hp = 200;
  }

  roar() {
    console.log("БОСС РЫЧИТ! 🐉");
  }
}

const boss = new Boss(240, 50);
boss.roar();
boss.takeDamage(50);
console.log("У босса осталось " + boss.hp);
```

## Разбор

- `class Boss extends Enemy` — «Boss **расширяет** Enemy» (`extends` [экстэ́ндз]). Boss получает **все** свойства и методы Enemy.
- `super(x, y)` [су́пер] — вызвать конструктор **родителя** (Enemy), чтобы он настроил x, y и hp. Пишется первой строчкой в конструкторе.
- После `super` можно поменять или добавить свои свойства: у босса `hp = 200`.
- `roar()` — новый метод, которого у обычного врага нет.
- `takeDamage` у босса работает, хотя мы его не писали, — он унаследован!

## Переопределение метода

Если у наследника написать метод с тем же именем — он **заменит** родительский:

```js
class Enemy {
  attack() { return 5; }
}
class Archer extends Enemy {
  attack() { return 12; }
}
console.log(new Enemy().attack(), new Archer().attack());
```

> 🎮 В больших играх целые «деревья» классов: `GameObject` → `Enemy` → `FlyingEnemy` → `Dragon`. Каждый следующий берёт всё от предыдущего и добавляет своё.

@lesson cls-4
title: Менеджер объектов — волны врагов
@theory
Соберём всё вместе: класс врага, массив, создание волн и удаление погибших. Это скелет почти любой игры с врагами.

```js canvas
class Enemy {
  constructor(x, y) {
    this.x = x;
    this.y = y;
    this.size = 30;
    this.speed = 0.5 + Math.random();
    this.hp = 3;
  }
  update() { this.y += this.speed; }
  draw() {
    ctx.font = this.size + "px Arial";
    ctx.fillText("👾", this.x, this.y);
  }
  isDead() { return this.hp <= 0 || this.y > canvas.height + 40; }
}

let enemies = [];
let wave = 0;

function spawnWave(count) {
  wave++;
  for (let i = 0; i < count; i++) {
    enemies.push(new Enemy(20 + Math.random() * 420, -20 - Math.random() * 200));
  }
}

canvas.addEventListener("click", (e) => {
  const r = canvas.getBoundingClientRect();
  const mx = (e.clientX - r.left) * canvas.width / r.width;
  const my = (e.clientY - r.top) * canvas.height / r.height;
  for (const en of enemies) {
    if (mx > en.x && mx < en.x + en.size && my > en.y - en.size && my < en.y) en.hp--;
  }
});

function loop() {
  ctx.clearRect(0, 0, canvas.width, canvas.height);
  for (const en of enemies) { en.update(); en.draw(); }
  enemies = enemies.filter((en) => !en.isDead());
  if (enemies.length === 0) spawnWave(3 + wave * 2);
  ctx.fillStyle = "white"; ctx.font = "18px Arial";
  ctx.fillText(`Волна ${wave} · кликай по пришельцам (3 клика)`, 10, 24);
  requestAnimationFrame(loop);
}
loop();
```

## Главные идеи

1. **Класс** описывает одного врага.
2. **Функция `spawnWave(count)`** создаёт пачку врагов и кладёт их в массив. С каждой волной врагов больше — растёт сложность.
3. **Игровой цикл** обновляет и рисует всех.
4. **Уборка:** `enemies = enemies.filter((en) => !en.isDead())` — оставляем только живых. Это ещё один способ удалять (вместо `splice` с конца). Для этого массив объявлен через `let`: мы заменяем его новым.
5. **Новая волна**, когда враги кончились.
