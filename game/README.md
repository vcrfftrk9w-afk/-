# Ржавый остров

Браузерная игра-выживалка в духе Rust. Чистые HTML/CSS/JS, без сборки и без файлов графики: остров, иконки и звуки генерируются кодом.

Запуск: открыть `game/index.html` через локальный сервер (`python3 -m http.server`, затем `/game/`) или по адресу GitHub Pages `…/game/`.

## Что есть

- **Процедурный остров** 160 × 160 клеток: пляжи, луга, лес, скалы, мелководье. Каждый «Новый остров» — новый сид.
- **Добыча**: деревья, камень, металлическая и серная руда, конопля, черника, грибы, бочки со скрапом, деревянные и военные ящики.
- **28 рецептов** с очередью создания: каменные и самодельные инструменты, копьё, мачете, лук и стрелы, револьвер, самодельный дробовик, порох, патроны, бинты, аптечки, броня. Оружейные рецепты требуют верстак рядом.
- **Стройка по сетке**: деревянные и каменные стены, дверь, колючая баррикада, костёр, печь, ящик, спальный мешок, верстак. Молоток чинит (ЛКМ) и разбирает (X).
- **Печь и костёр**: руда плавится в металл и серу, дерево даёт уголь, мясо жарится. Костёр греет и ускоряет лечение.
- **Выживание**: здоровье, сытость, вода, кровотечение. Пить можно прямо из моря (E).
- **Звери**: олени убегают, кабаны защищаются, волки и медведи охотятся (ночью волков больше).
- **Мародёры** с копьями, луками, револьверами и дробовиками: видят на дистанции, стрейфят, слышат выстрелы. Охраняют Радарную станцию и заправки.
- **Ночные налёты** на лагерь: мародёры ломают стены, чтобы добраться до вас.
- **Аирдроп**: самолёт сбрасывает груз на парашюте, мародёры спешат к нему.
- **Смена дня и ночи** с динамическим светом от факела, костров и печей.
- **Смерть**: вещи остаются в рюкзаке, возрождение у спальника или на пляже.
- **Задания-подсказки** ведут от булыжника до револьвера.
- Автосохранение в `localStorage`, мини-карта и большая карта (M), синтезированный звук.
- **Телефон**: два виртуальных стика (ходьба / удар и прицел) и кнопки действий.

## Управление

| Клавиша | Действие |
| --- | --- |
| WASD | ходить, Shift — бег |
| ЛКМ | удар, выстрел, поставить постройку |
| E | подобрать, открыть, пить, дверь |
| Tab / I | рюкзак и создание |
| 1–6, колесо | пояс |
| R | перезарядка |
| X | разобрать постройку молотком |
| M | карта |
| Esc | пауза |

В рюкзаке: нажать на предмет, потом на ячейку — переложить; ПКМ — съесть, надеть или перекинуть между поясом и рюкзаком.

## Код

| Файл | Что внутри |
| --- | --- |
| `js/data.js` | предметы, постройки, рецепты, таблицы добычи, звери, мародёры |
| `js/world.js` | генерация острова и памятников, узлы ресурсов, столкновения, отрисовка земли |
| `js/game.js` | логика: игрок, бой, ИИ, огонь, события |
| `js/render.js` | отрисовка мира и ночного света |
| `js/ui.js` | HUD, инвентарь, крафт, контейнеры, карта |
| `js/main.js` | ввод (клавиатура, мышь, сенсор), цикл, сохранения, меню |
| `js/icons.js`, `js/audio.js` | процедурные иконки и звуки |
