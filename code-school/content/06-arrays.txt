@lesson arr-1
title: Массив — список значений
@theory
У героя в инвентаре меч, щит и зелье. Можно сделать три переменные — `item1`, `item2`, `item3`. А если предметов 50? Для списков есть **массивы**.

```js
const inventory = ["меч", "щит", "зелье"];
console.log(inventory);
```

Массив пишется в **квадратных скобках** `[ ]`, элементы — через запятую. В массиве может быть что угодно: текст, числа, даже другие массивы.

```code
const scores = [120, 85, 300];
const flags = [true, false, true];
const empty = [];
```

## Номера элементов (индексы)

Каждый элемент имеет **номер** — индекс. И номера начинаются **с нуля**!

| Индекс | 0 | 1 | 2 |
|---|---|---|---|
| Элемент | "меч" | "щит" | "зелье" |

Достать элемент — имя массива и номер в квадратных скобках:

```js
const inventory = ["меч", "щит", "зелье"];
console.log(inventory[0]);
console.log(inventory[2]);
console.log(inventory[5]);
```

`inventory[5]` — такого элемента нет, получаем `undefined`.

> 🧠 Почему с нуля? Индекс — это «сколько шагов от начала». Первый элемент — в нуле шагов от начала. Так принято почти во всех языках программирования — придётся привыкнуть.

## Длина массива

`length` [ленс] — «длина» — сколько элементов в массиве:

```js
const enemies = ["гоблин", "орк", "тролль", "дракон"];
console.log(enemies.length);
console.log(enemies[enemies.length - 1]);
```

Последний элемент всегда имеет номер `length - 1`: элементов 4, а номера 0, 1, 2, 3.

## Изменить элемент

```js
const inventory = ["меч", "щит", "зелье"];
inventory[0] = "огненный меч";
console.log(inventory);
```

> 💡 Массив, объявленный через `const`, всё равно можно менять внутри: заменять и добавлять элементы. Нельзя только заменить весь массив целиком на другой.

@lesson arr-2
title: Добавить и убрать — push, pop и другие
@theory
Инвентарь постоянно меняется: подобрал предмет — добавился, использовал — исчез. У массивов есть для этого готовые команды — **методы**. Метод вызывается через точку.

## Добавить в конец — push

`push` [пуш] — «толкнуть»:

```js
const inventory = ["меч"];
inventory.push("лук");
inventory.push("факел");
console.log(inventory);
console.log(inventory.length);
```

## Убрать с конца — pop

`pop` [поп] — «вытолкнуть». Удаляет последний элемент и возвращает его:

```js
const inventory = ["меч", "лук", "факел"];
const lost = inventory.pop();
console.log("Потерян: " + lost);
console.log(inventory);
```

## Начало массива: unshift и shift

| Метод | Что делает |
|---|---|
| `push(x)` | добавить в **конец** |
| `pop()` | убрать из **конца** |
| `unshift(x)` | добавить в **начало** |
| `shift()` | убрать из **начала** |

## Поиск: includes и indexOf

- `includes(x)` [инклю́дз] — «включает»: есть ли элемент? Вернёт `true`/`false`.
- `indexOf(x)` [индекс оф] — номер элемента, или `-1`, если его нет.

```js
const bag = ["ключ", "карта", "яблоко"];
console.log(bag.includes("ключ"));
console.log(bag.includes("меч"));
console.log(bag.indexOf("карта"));

if (bag.includes("ключ")) {
  console.log("Ты открыл дверь!");
}
```

> 🎮 `push` — «подобрать предмет», «выстрелить» (добавить пулю), «появился новый враг». `includes` — «есть ли у героя ключ?».

@lesson arr-3
title: Перебор массива
@theory
Самое частое действие с массивом — пройти по **всем** элементам: нарисовать всех врагов, проверить все пули, посчитать сумму очков.

## Цикл for с индексом

```js
const enemies = ["гоблин", "орк", "тролль"];

for (let i = 0; i < enemies.length; i++) {
  console.log(`Враг №${i}: ${enemies[i]}`);
}
```

Вот зачем считать с нуля! Индексы массива — от `0` до `length - 1`, и цикл `for (let i = 0; i < arr.length; i++)` проходит ровно по ним.

> ⚠️ Условие — `i < arr.length`, а **не** `<=`. Иначе на последнем шаге получишь `arr[length]` — а это `undefined`.

## Цикл for...of — проще

Если номер не нужен, есть короткий цикл `for...of` [фор ов] — «для каждого из»:

```js
const loot = ["золото", "рубин", "свиток"];

for (const item of loot) {
  console.log("Найдено: " + item);
}
```

Читается: «для каждого `item` **из** `loot`».

## Сумма и максимум

```js
const scores = [12, 45, 7, 30];
let sum = 0;
let best = scores[0];

for (const s of scores) {
  sum += s;
  if (s > best) {
    best = s;
  }
}

console.log("Сумма: " + sum);
console.log("Лучший: " + best);
```

Для максимума берём первый элемент как «лучший пока что» и сравниваем с каждым следующим.

> 🎮 В каждой игре каждый кадр есть цикл «для каждого врага: сдвинуть, нарисовать, проверить столкновение».

@lesson arr-4
title: Удаляем из середины — splice
@theory
Враг погиб — его нужно убрать из массива врагов. Но он может быть где угодно, не обязательно в конце. Для удаления из любого места есть `splice` [сплайс]:

```js
const enemies = ["гоблин", "орк", "тролль", "дракон"];
enemies.splice(1, 1);
console.log(enemies);
```

`splice(индекс, сколько)` — с позиции `1` удалить `1` элемент.

## Ловушка: удаление в цикле

Допустим, нужно удалить всех погибших врагов (у кого здоровье 0). Наивный способ ломается:

```js
const hp = [10, 0, 0, 30];
for (let i = 0; i < hp.length; i++) {
  if (hp[i] === 0) {
    hp.splice(i, 1);
  }
}
console.log(hp);
```

Один ноль остался! Почему? Когда мы удалили элемент с номером 1, всё сдвинулось влево: второй ноль переехал на место 1. А цикл уже идёт к номеру 2 — и **перепрыгивает** его.

## Правильно: идти с конца

Если идти **от конца к началу**, сдвиг касается только уже проверенных элементов:

```js
const hp = [10, 0, 0, 30];
for (let i = hp.length - 1; i >= 0; i--) {
  if (hp[i] === 0) {
    hp.splice(i, 1);
  }
}
console.log(hp);
```

> 🎮 Это настоящий профессиональный приём! Именно так в играх удаляют погибших врагов, исчезнувшие пули и собранные монеты.

## Вставить через splice

`splice` умеет и вставлять: `arr.splice(индекс, 0, новый)` — удалить ноль элементов и вставить новый.

```js
const queue = ["Аня", "Боря"];
queue.splice(1, 0, "Вика");
console.log(queue);
```

@lesson arr-5
title: forEach, map, filter, find — умные помощники
@theory
У массивов есть методы, которые принимают **функцию** и сами делают перебор. Это короче и понятнее, чем писать цикл.

## forEach — для каждого

```js
const heroes = ["Рыцарь", "Маг", "Лучник"];
heroes.forEach((hero) => {
  console.log("В отряде: " + hero);
});
```

`forEach` [фор и́ч] вызывает функцию для каждого элемента.

## map — преобразовать каждый

`map` [мэп] создаёт **новый** массив, где каждый элемент изменён функцией:

```js
const prices = [100, 250, 40];
const sale = prices.map((p) => p / 2);
console.log(sale);
```

## filter — оставить подходящие

`filter` [фи́льтер] создаёт новый массив только из элементов, для которых функция вернула `true`:

```js
const hp = [30, 0, 15, 0, 50];
const alive = hp.filter((h) => h > 0);
console.log(alive);
```

Кстати, это ещё один способ избавиться от погибших врагов: `enemies = enemies.filter(...)`.

## find — найти первый

`find` [файнд] возвращает **первый** подходящий элемент (или `undefined`):

```js
const damages = [5, 12, 30, 8];
const bigHit = damages.find((d) => d > 10);
console.log(bigHit);
```

## Ещё пара полезных

| Метод | Что возвращает |
|---|---|
| `some(f)` | есть ли **хоть один** подходящий (true/false) |
| `every(f)` | подходят ли **все** (true/false) |
| `join(", ")` | склеивает элементы в строку |

```js
const bag = ["меч", "щит"];
console.log(bag.join(" + "));
console.log([3, 7, 9].every((n) => n > 2));
```

> 💡 `map`, `filter`, `find` не меняют исходный массив — они создают новый. Это часто удобно: старые данные остаются нетронутыми.

@lesson arr-6
title: Двумерный массив — карта уровня
@theory
Массив может хранить другие массивы. Получается **таблица** — идеальный способ описать **карту уровня**:

```js
const level = [
  [1, 1, 1, 1, 1],
  [1, 0, 0, 2, 1],
  [1, 0, 1, 0, 1],
  [1, 1, 1, 1, 1]
];
console.log(level[1][3]);
```

Здесь `1` — стена, `0` — пол, `2` — сундук.

## Как достать клетку

`level[y][x]` — сначала номер **строки** (сверху вниз), потом номер **столбца** (слева направо). `level[1][3]` — строка 1, столбец 3 — там сундук `2`.

> ⚠️ Порядок «сначала строка, потом столбец» — то есть `[y][x]`, а не `[x][y]`. Это частая путаница.

## Перебираем всю карту

Двойной цикл — как в уроке про поле:

```js
const level = [
  [1, 1, 1, 1, 1],
  [1, 0, 0, 2, 1],
  [1, 0, 1, 0, 1],
  [1, 1, 1, 1, 1]
];
const symbols = ["⬛", "⬜", "🎁"];

for (let y = 0; y < level.length; y++) {
  let line = "";
  for (let x = 0; x < level[y].length; x++) {
    line += symbols[level[y][x]];
  }
  console.log(line);
}
```

Обрати внимание на хитрость: `symbols[level[y][x]]` — число из карты используется как номер в массиве символов.

> 🎮 Так устроены уровни в Марио, Зельде, Бомбермене, Pac-Man: дизайнер рисует таблицу из чисел, а программа превращает её в мир. В проекте «Платформер» мы сделаем так же.

/map\s*\[\s*\w+\s*\]\s*\[\s*\w+\s*\]/.test(__codeNS) || /of\s+map/.test(__codeNS)
@hint
Перед циклами: `let walls = 0;`. Внешний цикл по `y` до `map.length`, внутренний по `x` до `map[y].length`.
@hint
Внутри: `if (map[y][x] === 1) { walls++; }`
@quiz
? В карте `level[2][4]` — это…
+ строка 2, столбец 4
- столбец 2, строка 4
- элемент номер 24
= Сначала номер строки (y), потом столбца (x).
