@lesson phys-1
title: Столкновение прямоугольников
@theory
Самый важный вопрос в любой игре: **столкнулись ли два объекта?** Пуля попала во врага? Герой подобрал монету? Мяч коснулся ракетки?

Если объекты — прямоугольники (а в играх почти всё можно считать прямоугольниками), есть простая проверка. Она называется **AABB** — сложное имя, простая идея.

## Идея: когда прямоугольники НЕ пересекаются?

Проще подумать наоборот. Два прямоугольника точно **не** касаются, если один из них:
- целиком **левее** другого, или
- целиком **правее**, или
- целиком **выше**, или
- целиком **ниже**.

Во всех остальных случаях — пересекаются! Записываем «пересекаются» сразу:

```code
function rectsCollide(a, b) {
  return a.x < b.x + b.w &&   // левый край a левее правого края b
         a.x + a.w > b.x &&   // правый край a правее левого края b
         a.y < b.y + b.h &&   // верх a выше низа b
         a.y + a.h > b.y;     // низ a ниже верха b
}
```

Все четыре условия через `&&` — должны выполняться **одновременно**.

@lesson phys-2
title: Столкновение кругов
@theory
Мячи, монеты, астероиды — круглые. Для кругов проверка ещё проще!

Два круга касаются, если **расстояние между их центрами меньше суммы радиусов**.

```code
function circlesCollide(a, b) {
  const dx = a.x - b.x;
  const dy = a.y - b.y;
  const dist = Math.sqrt(dx * dx + dy * dy);
  return dist < a.r + b.r;
}
```

Расстояние считается по теореме Пифагора: `dx` и `dy` — катеты, `dist` — гипотенуза. Есть и готовая функция: `Math.hypot(dx, dy)` [хайпо́т] делает то же самое.

```js canvas
const a = { x: 100, y: 160, r: 40 };
const b = { x: 300, y: 160, r: 60 };

canvas.addEventListener("mousemove", (e) => {
  const rect = canvas.getBoundingClientRect();
  a.x = (e.clientX - rect.left) * canvas.width / rect.width;
  a.y = (e.clientY - rect.top) * canvas.height / rect.height;
});

function loop() {
  const hit = Math.hypot(a.x - b.x, a.y - b.y) < a.r + b.r;
  ctx.clearRect(0, 0, canvas.width, canvas.height);
  ctx.fillStyle = hit ? "gold" : "slateblue";
  ctx.beginPath(); ctx.arc(b.x, b.y, b.r, 0, Math.PI * 2); ctx.fill();
  ctx.fillStyle = "tomato";
  ctx.beginPath(); ctx.arc(a.x, a.y, a.r, 0, Math.PI * 2); ctx.fill();
  ctx.fillStyle = "white"; ctx.font = "18px Arial";
  ctx.fillText(hit ? "Столкновение!" : "Води мышкой", 12, 26);
  requestAnimationFrame(loop);
}
loop();
```

> 💡 Хитрость профессионалов: квадратный корень — медленная операция. Можно сравнивать **квадраты**: `dx*dx + dy*dy < (a.r + b.r) * (a.r + b.r)`. Результат тот же, а считается быстрее. Для наших игр разницы не будет — но приятно знать.

@lesson phys-3
title: Гравитация
@theory
Как сделать, чтобы предметы **падали**, как в жизни? В реальности падающий предмет не просто летит вниз — он **разгоняется**. Каждую секунду быстрее и быстрее.

В игре это делается в две строчки:

```code
player.vy += gravity;   // гравитация увеличивает скорость падения
player.y += player.vy;  // скорость меняет положение
```

`gravity` [гра́вити] — небольшое число, например `0.5`. Каждый кадр скорость падения `vy` увеличивается на 0.5: 0.5, 1, 1.5, 2… — объект разгоняется.

## Земля

Чтобы объект не провалился сквозь пол, проверяем: если его низ ниже земли — ставим ровно на землю и обнуляем скорость.

```js canvas
const groundY = 280;
const gravity = 0.5;
const box = { x: 220, y: 0, w: 40, h: 40, vy: 0 };

canvas.addEventListener("click", () => { box.y = 0; box.vy = 0; });

function update() {
  box.vy += gravity;
  box.y += box.vy;
  if (box.y + box.h > groundY) {
    box.y = groundY - box.h;
    box.vy = 0;
  }
}

function draw() {
  ctx.clearRect(0, 0, canvas.width, canvas.height);
  ctx.fillStyle = "#3b7d3b";
  ctx.fillRect(0, groundY, canvas.width, canvas.height - groundY);
  ctx.fillStyle = "orange";
  ctx.fillRect(box.x, box.y, box.w, box.h);
  ctx.fillStyle = "white";
  ctx.font = "16px Arial";
  ctx.fillText("Кликни, чтобы уронить ящик ещё раз", 10, 24);
}

function loop() { update(); draw(); requestAnimationFrame(loop); }
loop();
```

## Отскок вместо остановки

Если вместо `vy = 0` написать `vy = -vy * 0.7`, ящик будет подпрыгивать, каждый раз всё ниже — как мячик. Число 0.7 — «упругость».

> 🎮 Подбирая `gravity`, можно сделать игру «на Луне» (0.15) или «на Юпитере» (1.2). В Марио гравитация сильнее при падении, чем при подъёме, — от этого прыжок кажется «тяжёлым» и приятным.

@lesson phys-4
title: Прыжок
@theory
Прыжок — это просто **резкая скорость вверх**. Помнишь, что вверх — это отрицательный y? Значит, прыжок — это `vy = -10` (или другое отрицательное число). А дальше гравитация сама замедлит подъём, остановит героя в верхней точке и вернёт вниз. Получается красивая дуга — бесплатно!

```code
if (keys[" "] && player.onGround) {
  player.vy = -jumpPower;
}
```

## Зачем проверять onGround?

Без этой проверки герой сможет прыгать **в воздухе** — бесконечно взлетая вверх. Поэтому прыгать можно, только стоя на земле. (А если захочешь сделать «двойной прыжок» — считай прыжки и разрешай второй в воздухе.)

```js canvas
const groundY = 280, gravity = 0.6, jumpPower = 12;
const player = { x: 60, y: 200, w: 36, h: 36, vy: 0, onGround: false };
const keys = {};
document.addEventListener("keydown", (e) => { keys[e.key] = true; });
document.addEventListener("keyup", (e) => { keys[e.key] = false; });

function update() {
  if (keys["ArrowRight"]) player.x += 4;
  if (keys["ArrowLeft"]) player.x -= 4;
  if (keys[" "] && player.onGround) player.vy = -jumpPower;

  player.vy += gravity;
  player.y += player.vy;
  if (player.y + player.h > groundY) {
    player.y = groundY - player.h;
    player.vy = 0;
    player.onGround = true;
  } else {
    player.onGround = false;
  }
}

function draw() {
  ctx.clearRect(0, 0, canvas.width, canvas.height);
  ctx.fillStyle = "#3b7d3b";
  ctx.fillRect(0, groundY, canvas.width, 40);
  ctx.font = "36px Arial";
  ctx.fillText("🐱", player.x, player.y + 32);
  ctx.fillStyle = "white"; ctx.font = "16px Arial";
  ctx.fillText("← → — бег, пробел — прыжок", 10, 24);
}

function loop() { update(); draw(); requestAnimationFrame(loop); }
loop();
```

> 🧠 Высота прыжка зависит от `jumpPower` и `gravity`. Хочешь прыжок выше — увеличь `jumpPower`. Хочешь «парящий» прыжок — уменьши `gravity`.

@lesson phys-5
title: Сбор предметов
@theory
Соединим всё вместе: у нас есть **массив монет** и функция **столкновения**. Если герой касается монеты — монета исчезает, счёт растёт.

```js canvas
const player = { x: 30, y: 140, w: 34, h: 34 };
const coins = [];
```

@lesson phys-6
title: Частицы — взрывы и искры
@theory
Хочешь, чтобы игра выглядела «сочно»? Добавь **частицы**: при взрыве разлетаются искры, при сборе монеты — звёздочки. Это делается очень просто, а эффект — огромный.

**Частица** — маленький объект с координатами, скоростью и **временем жизни**. Каждый кадр она летит, а её жизнь уменьшается. Жизнь закончилась — частицу удаляем.

```js canvas
const particles = [];

function explode(x, y) {
  for (let i = 0; i < 40; i++) {
    const angle = Math.random() * Math.PI * 2;
    const speed = 1 + Math.random() * 4;
    particles.push({
      x: x, y: y,
      vx: Math.cos(angle) * speed,
      vy: Math.sin(angle) * speed,
      life: 60,
      color: `hsl(${20 + Math.random() * 40}, 100%, 60%)`
    });
  }
}

canvas.addEventListener("click", (e) => {
  const r = canvas.getBoundingClientRect();
  explode((e.clientX - r.left) * canvas.width / r.width, (e.clientY - r.top) * canvas.height / r.height);
});

function update() {
  for (let i = particles.length - 1; i >= 0; i--) {
    const p = particles[i];
    p.x += p.vx;
    p.y += p.vy;
    p.vy += 0.05;
    p.life--;
    if (p.life <= 0) particles.splice(i, 1);
  }
}

function draw() {
  ctx.fillStyle = "rgba(10, 14, 35, 0.35)";
  ctx.fillRect(0, 0, canvas.width, canvas.height);
  for (const p of particles) {
    ctx.globalAlpha = p.life / 60;
    ctx.fillStyle = p.color;
    ctx.fillRect(p.x, p.y, 3, 3);
  }
  ctx.globalAlpha = 1;
  ctx.fillStyle = "white"; ctx.font = "18px Arial";
  ctx.fillText("Кликай — будут взрывы!", 12, 26);
}

function loop() { update(); draw(); requestAnimationFrame(loop); }
explode(240, 160);
loop();
```

## Новые приёмы

- `Math.cos(angle)` и `Math.sin(angle)` [кос, сайн] превращают **угол** в направление: частицы разлетаются во все стороны по кругу.
- `ctx.globalAlpha` [гло́убал а́льфа] — прозрачность от 0 до 1. Чем меньше жизни, тем прозрачнее частица — она красиво тает.
- Фон рисуется **полупрозрачным** `rgba(..., 0.35)`, поэтому старые кадры не стираются полностью — остаётся лёгкий шлейф.

> 🧠 Не пугайся синусов и косинусов: достаточно запомнить, что `Math.cos(угол) * скорость` и `Math.sin(угол) * скорость` дают vx и vy для движения под этим углом.
