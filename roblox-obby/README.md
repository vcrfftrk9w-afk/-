# Obby «Лавовая башня» для Roblox

Готовая игра-обби (полоса препятствий над лавой) в одном скрипте. Карту строит сам код, руками ничего собирать не нужно.

## Как запустить (2 минуты)

1. Открой **Roblox Studio** → **New** → **Baseplate**.
2. В окне **Explorer** найди **ServerScriptService** → нажми **+** → **Script**.
3. Удали `print("Hello world!")` и вставь весь код из [`ObbyGame.server.lua`](ObbyGame.server.lua).
4. Нажми **Play** (F5). Ты появишься на зелёной платформе «СТАРТ».

## Что внутри

| # | Этап | Что делать |
|---|------|-----------|
| 1 | Прыжки | Прыгать по цветным платформам |
| 2 | Лава | Перепрыгивать светящиеся полосы лавы |
| 3 | Лифты | Ловить момент, пока платформы ездят вверх-вниз |
| 4 | Вертушка | Перепрыгивать огненную палку, которая крутится |
| 5 | Призраки | Стеклянные платформы исчезают через полсекунды |
| 6 | Башня | Залезть по ферме на высокую стену |
| 7 | Конвейер | Бежать против ленты и обходить блоки |
| 8 | Балки | Узкие балки зигзагом |
| 🏆 | Финиш | Пройти через золотые ворота |

Ещё есть:
- **Чекпоинты** после каждого этапа: умер — появляешься на последнем.
- **Монеты** (крутятся и появляются снова через 10 секунд).
- **Таблица лидеров** справа сверху: `Stage`, `Coins`, `Wins`.
- За финиш: +1 победа и +50 монет, потом можно пройти заново.
- Море лавы под трассой.

## Сохранение прогресса

Чтобы этап, монеты и победы сохранялись между заходами:
1. Опубликуй игру: **File → Publish to Roblox**.
2. **Game Settings → Security** → включи **Enable Studio Access to API Services**.

Без этого игра тоже работает, просто в Output будет предупреждение, что сохранения выключены.

## Настройки

Вверху скрипта есть таблица `CONFIG`:

```lua
StartHeight = 100,         -- высота трассы
LavaHeight = 70,           -- уровень лавы
CoinRespawn = 10,          -- через сколько секунд монета появляется снова
FinishCoins = 50,          -- награда за финиш
RestartAfterFinish = true, -- после финиша вернуть на старт
SaveProgress = true,       -- сохранять прогресс
```

## Как добавить свой этап

Напиши функцию по образцу `stageJumps`: она получает `z, y` (где начинается этап) и возвращает `z, y` (где он закончился). Потом добавь её в список `stages`, и чекпоинт после неё появится сам.
