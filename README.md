# Следующий шаг

Личная система действий: приложение не спрашивает «ну что хочешь поделать», а показывает **одно
конкретное действие**, которое приближает к цели прямо сейчас. Для рутины, саморазвития и роста дохода.

Есть обычный режим и режим, адаптированный под трудности с вниманием, запуском задач и ощущением
времени. Приложение не лечит СДВГ и не заменяет помощь специалиста; диагноз не нужен, чтобы включить
удобные инструменты.

## Запуск

```bash
npm install
npm run dev        # разработка
npm run build      # сборка (типы + бандл)
npm run preview    # посмотреть собранную версию
npm test           # тесты логики (vitest)
```

Данные хранятся локально в браузере (`localStorage`). Сервера, аккаунта и отправки данных наружу нет.

## Что реализовано

Первая версия сознательно меньше полной концепции — пять ключевых функций:

1. **Одна цель → недельный план → следующий шаг.** Онбординг из шести вопросов, путь из шаблона
   разворачивается в этапы и конкретные задания. Одновременно активны одна большая цель и максимум
   две привычки; остальные идеи живут в отдельном списке.
2. **Обычный режим и настраиваемый режим под трудности с вниманием.** Отличаются логикой, а не
   цветом: одна задача на экране, первый шаг на 1–5 минут, наглядное время, мягкий выход из блока,
   меньше настроек перед стартом. Каждая настройка включается по отдельности.
3. **Кнопки «Начать», «Сделать проще», «Я завис».** «Сделать проще» спускается по лестнице упрощения:
   «Обновить резюме» → «Открыть файл» → «Найти нужный раздел» → «Написать один черновой пункт».
   «Я завис» спрашивает, что именно мешает, и запускает разный сценарий для каждой причины.
4. **Фокус-сессии и добровольные ограничения отвлечений.** Контракт с собой на три уровня строгости,
   предупреждение за три минуты до остановки, подсказка «с чего продолжить», повторный запрос, если
   не начал. Аварийный выход доступен всегда.
5. **Недельный разбор с корректировкой плана.** Три вопроса и гипотеза на следующую неделю,
   построенная на фактах из журнала действий, — с обязательным подтверждением человеком.

Дополнительно работают вкладки **Деньги** (финансовая картина, один путь роста дохода, счётчик
внешних результатов) и небольшой виртуальный город, который можно полностью отключить.

## Как устроено

```
src/
  domain/      предметная логика без React
    types.ts       модель: цель, этапы, задания, привычки, контракты, деньги
    templates.ts   пути роста дохода и привычки как шаблоны
    engine.ts      выбор одного следующего действия
    simplify.ts    лестница упрощения
    stuck.ts       сценарии кнопки «Я завис»
    habits.ts      привычки без обнуления прогресса
    reminders.ts   напоминание о договорённости и повторный запрос
    metrics.ts     метрики по результатам, а не по открытиям приложения
    review.ts      вопросы недельного разбора и гипотезы
  store/       состояние: действия, редьюсер, контекст
  screens/     Сейчас, Путь, Деньги, Разбор, Фокус, Онбординг, Настройки
  components/  примитивы интерфейса, таймер, город, шторки помощи
  lib/         даты, хранилище, идентификаторы
```

Вся предметная логика — чистые функции, поэтому она покрыта тестами: выбор следующего шага,
упрощение, переносы, различение подготовки и проверки реальностью, привычки, напоминания,
гипотезы недельного разбора.

## Принципы, зашитые в код

- **Пропуск не обнуляет прогресс.** Вместо «ты потерял серию из 47 дней» — «за две недели привычка
  выполнена 9 раз, был перерыв, продолжаем».
- **Пропущенные задачи не становятся долгом на завтра.** Они попадают в переоценку: оставить,
  упростить или удалить.
- **Перенос всегда с причиной** — это данные для разбора, а не повод для вины.
- **Подготовка и проверка реальностью считаются отдельно.** Если подготовки много, а внешних шагов
  нет, приложение предлагает маленький внешний шаг.
- **Нагрузка не растёт автоматически за успешную неделю.** Объём меняет только человек.
- **Отдых не нужно заслуживать.** Нехватка сил — не лень, и система спрашивает, а не ставит диагнозы.
- **Никаких денежных штрафов, азартных механик, рейтингов и рекламы на основе долгов.**

## Честные ограничения этой версии

- Блокировка сторонних приложений браузеру недоступна. Строгий уровень показывает договорённость и
  держит её на виду, но не ограничивает другие программы. Звонки, банки, медицинские сервисы и
  важные контакты не ограничиваются никогда — ни при какой реализации.
- Совместный фокус с живым человеком требует сервера и модерации. Сейчас доступна одиночная сессия
  с короткими проверками, и приложение честно называет её автоматическим сопровождением.
- Подсказки работают на локальных правилах. Отправка содержимого задач внешнему ИИ выключена и в
  этой версии не используется.
- Системные уведомления не запрашиваются: напоминание о договорённости появляется в приложении.
