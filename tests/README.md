# Проверки

Живые проверки в настоящем браузере: поднимают приложение, кликают по нему
и смотрят, что получилось. Не юнит-тесты — они ловят то, что ломается
на самом деле: потерянные нажатия, съехавшую вёрстку, исчезнувшие данные.

## Как запустить

```bash
python3 -m http.server 8792 &          # из корня репозитория
node tests/smoke.js                     # 5 секунд: все модули загрузились
node tests/journey.js                   # полный первый день на телефоне
```

Нужен Playwright и Chromium. В этом окружении:
```bash
NODE_PATH=/opt/node22/lib/node_modules node tests/smoke.js
```

## Что проверяет каждая

| Файл | Что ловит |
|---|---|

| `journey.js` | Сквозной первый день на телефоне: онбординг → режим и дела ставятся сами по графику → разбор → вода и еда → залипание → итог дня → перезагрузка. |
| `edge.js` | Граничные случаи: день занят целиком, длительность 0 и 9999, абсурдные деньги, удалённая задача в плане, сброс пути, экспорт/импорт. |
| `robust.js` | Длинные слова без пробелов, 25 привычек и 50 дел, двадцать быстрых нажатий подряд, переполнение хранилища. |
| `data-safety.js` | Две вкладки не затирают работу друг друга; испорченное сохранение не стирает прогресс. |
| `recovery.js` | Подробно: восстановление из запасной копии, поведение когда испорчены обе. |
| `score.js` | Оценка режима считает только измеримое: первый день без вчерашней ночи, первый час после подъёма. |

| `main-card.js` | Карточка «Сегодня главное» стоит первой, ведёт к ближайшему делу, отмечается прямо с главной, и ничего с главной не пропало. |

| `psychology.js` | Серии по делу («4 дня подряд — ты тот, кто публикует»), «чистый лист» в понедельник, идеальный день засчитывается один раз, вечерний толчок, старые закрытые задачи уходят в журнал. |
| `coach.js` | Тренировка по шагам до конца (записана и отмечена), прогулка с таймером, который останавливается при закрытии; рецепт дня, меню чередуется по неделям, список покупок сохраняет отметки; разбор с ИИ на имитации — ИИ получает данные дня, «поставить на завтра» создаёт задачу; без ИИ — встроенный разбор. |

| `levels.js` | Уровни «Моих дел»: старт — TikTok кино и orca; 2 дня подряд → тренировка 5 отжиманий (со следующего дня); пропуск — серия заново, уровень не падает; 4 дня → YouTube и тренировка труднее; ▶ тренировки — пошаговая сессия, после неё дело засчитано. |

| `android-bridge.js` | APK-версия: имитирует Android WebView (нет голоса, уведомлений, скачивания) и проверяет, что `js/android.js` отправляет голос тренера, уведомления и сохранение файлов в мост `AndroidApp`, а в обычном браузере ничего не меняет. |

| `plans.js` | Свои дела с будильником: «Тренировка» пн 07:00, вт 10:00 — сохраняется, стоит в «Моих делах» в понедельник, в APK будильники на оба дня со своим временем; «сделано» даёт опыт; «время как у первого»; ошибки без названия и без дней; дело с названием открытого задания уровня встаёт к нему без дубля; дело с другого телефона сам получает будильник; удаление убирает будильник; ⏰ у публикации «кино» — «за 15 минут» ставит будильник на 19:40 каждый день, выключение убирает; ⏰ у «Тренировки» уровня открывает редактор с подставленным названием. |
| `courses.js` | Окно «🎓 Курсы»: три кнопки окон; старт английского — урок дня в ежедневнике на выбранное время и будильник APK; «Мои дела» не тронуты; встроенное видео урока 1 Бебриса; шаги по очереди; время и урок из плеера запоминаются; пазлы с ошибкой и без; мягкая перерисовка не сбрасывает упражнение; день закрыт — задача закрыта, следующий урок завтра; итоговая не сдана → +5 дней, сдана → курс пройден; стойка — тренировка, промежуточная проверка не завершает курс; сальто без страховки не начать; деньги — дела-чекбоксы; окно запоминается. |

| `bottom-bar.js` | Мини-плеер не накрывает нижнюю панель вкладок, и все её кнопки стоят в один ряд с видимыми подписями, а активная вкладка читается и в светлой теме — на четырёх сочетаниях экрана и размера шрифта. |
| `music.js` | Смена станции слышна сразу, темп берётся у новой станции, эквалайзер не крутится впустую. |
| `longterm.js` | Полгода ежедневных данных: размер сохранения, скорость загрузки и рендера, горячие клавиши. |

## Про «ошибки шрифтов»

В песочнице без доступа к `fonts.googleapis.com` проверки показывают
`ERR_CERT_AUTHORITY_INVALID` — это TLS-прокси окружения, а не приложение.
В обычном браузере шрифты грузятся нормально.
