@lesson cond-1
title: Правда или ложь — сравнения
@theory
Игры постоянно задают вопросы: «здоровье кончилось?», «счёт больше рекорда?», «у игрока есть ключ?». Ответ на такой вопрос — `true` (да) или `false` (нет).

Вопросы задаются с помощью **сравнений**:

```js
console.log(10 > 5);
console.log(10 < 5);
console.log(7 === 7);
console.log(7 !== 7);
```

## Знаки сравнения

| Знак | Значение | Пример | Ответ |
|---|---|---|---|
| `>` | больше | `5 > 3` | true |
| `<` | меньше | `5 < 3` | false |
| `>=` | больше или равно | `5 >= 5` | true |
| `<=` | меньше или равно | `4 <= 3` | false |
| `===` | равно | `2 === 2` | true |
| `!==` | не равно | `2 !== 3` | true |

> ⚠️ Запомни раз и навсегда: `=` — **положить** значение в переменную, `===` — **сравнить**. Перепутать их — очень частая ошибка.

## Сравниваем переменные

```js
let hp = 0;
let isDead = hp <= 0;
console.log("Герой погиб?", isDead);

let score = 1500;
let record = 1200;
console.log("Новый рекорд?", score > record);
```

Результат сравнения можно положить в переменную — получится логическая переменная (`boolean`).

## Сравнение текста

Текст тоже можно сравнивать — он должен совпасть **точно**, вплоть до большой буквы:

```js
console.log("меч" === "меч");
console.log("Меч" === "меч");
```

> 🧠 Есть ещё `==` (два знака равно). Он «нестрогий»: считает, что `5 == "5"` — правда. Это часто приводит к странным ошибкам, поэтому всегда используй строгое `===`.

@lesson cond-2
title: if — если…
@theory
Теперь научим программу **принимать решения**. Для этого есть команда `if` [иф] — «если».

```js
let coins = 120;

if (coins >= 100) {
  console.log("Ты можешь купить меч!");
}

console.log("Конец магазина");
```

## Как устроен if

```code
if (условие) {
  // этот код выполнится, только если условие — true
}
```

- после `if` в **круглых скобках** — условие (вопрос);
- в **фигурных скобках** `{ }` — команды, которые выполнятся, если ответ «да»;
- если ответ «нет» — компьютер просто перепрыгнет через фигурные скобки.

Поменяй `coins` в примере на `50` и запусти снова — сообщения про меч не будет.

## Отступы

Код внутри `{ }` принято сдвигать вправо на 2 пробела (клавиша `Tab`). Компьютеру это не важно, а людям так гораздо легче читать — сразу видно, что «внутри» условия.

```bad
if (coins >= 100) {
console.log("Купил меч");
console.log("Монет стало меньше");
}
```

```good
if (coins >= 100) {
  console.log("Купил меч");
  console.log("Монет стало меньше");
}
```

> 💡 Редактор сам ставит отступ, когда ты нажимаешь `Enter` после `{`.

> 🎮 В каждой игре сотни таких if: если нажата клавиша — двигаем героя; если герой коснулся монеты — прибавляем очки; если жизни кончились — конец игры.

@lesson cond-3
title: else — иначе
@theory
Часто нужно сделать одно, **если** условие верно, и другое — **иначе**. Для этого после `if` добавляют `else` [элс] — «иначе»:

```js
let hp = 30;

if (hp > 50) {
  console.log("Ты в отличной форме!");
} else {
  console.log("Осторожно, мало здоровья!");
}
```

Выполнится **ровно один** из двух блоков: либо первый, либо второй. Никогда оба сразу и никогда ни одного.

## Пример из игры

```js
let score = 950;
let record = 1000;

if (score > record) {
  record = score;
  console.log("НОВЫЙ РЕКОРД! 🏆");
} else {
  console.log(`До рекорда не хватило ${record - score} очков`);
}
```

> ⚠️ После `else` **не пишут** условие в скобках. `else` срабатывает во всех остальных случаях.

@lesson cond-4
title: else if — много вариантов
@theory
Иногда вариантов больше двух. Например, медаль за результат: золото, серебро, бронза или ничего. Для этого цепочка `else if` — «иначе, если»:

```js
let score = 75;

if (score >= 90) {
  console.log("🥇 Золото");
} else if (score >= 70) {
  console.log("🥈 Серебро");
} else if (score >= 50) {
  console.log("🥉 Бронза");
} else {
  console.log("Попробуй ещё раз");
}
```

## Как это работает

Компьютер проверяет условия **сверху вниз** и выполняет **первый** подходящий блок. Остальные он уже не смотрит.

При `score = 75`:
1. `75 >= 90`? Нет — дальше.
2. `75 >= 70`? Да! Выводим «Серебро» и **выходим** из всей цепочки.
3. До проверки `>= 50` дело не доходит, хотя 75 тоже больше 50.

> ⚠️ Поэтому порядок важен! Если сначала проверить `score >= 50`, то и 95 очков получат бронзу. Проверяй от самого строгого условия к самому мягкому.

`else` в конце — необязательный: он ловит всё, что не подошло ни под одно условие.

@lesson cond-5
title: И, ИЛИ, НЕ — сложные условия
@theory
Бывает, что одного условия мало. Дверь открывается, только если **есть ключ И** уровень достаточный. Урон получен, если **задел шипы ИЛИ врага**. Для этого есть логические операторы.

| Оператор | Читается | Значение |
|---|---|---|
| `&&` | И | оба условия должны быть верны |
| `\|\|` | ИЛИ | хотя бы одно условие верно |
| `!` | НЕ | переворачивает: true ↔ false |

```js
let hasKey = true;
let level = 5;

if (hasKey && level >= 5) {
  console.log("Дверь открыта!");
}

let touchedSpikes = false;
let touchedEnemy = true;
if (touchedSpikes || touchedEnemy) {
  console.log("Ой! Минус жизнь");
}

let isPaused = false;
if (!isPaused) {
  console.log("Игра идёт");
}
```

## Таблица для запоминания

| A | B | A && B | A \|\| B |
|---|---|---|---|
| true | true | true | true |
| true | false | false | true |
| false | true | false | true |
| false | false | false | false |

> 💡 Где символы: `&` — `Shift` + `7`, `|` — `Shift` + `\` (клавиша над Enter) на английской раскладке. Ещё они есть на панели символов.

## Проверка «в промежутке»

Частая задача — проверить, что число между двумя значениями. Например, герой внутри экрана по горизонтали:

```js
let x = 250;
if (x >= 0 && x <= 480) {
  console.log("Герой на экране");
}
```

> ⚠️ Нельзя писать как в математике `0 <= x <= 480` — это работает неправильно. Только через `&&`.

@lesson cond-6
title: Мини-проект — битва с монстром
@theory
Соберём боевую логику из условий. В настоящих играх так и устроены бои: много маленьких проверок.

```js
let heroHp = 40;
const monsterAttack = 25;

  console.log("Герой пал...");
}
```

Запусти, потом поменяй `hasShield` на `false` — и посмотри, что изменится.

## Тернарный оператор

Для простых «если — то, иначе — это» есть короткая запись — **тернарный оператор** `условие ? значение1 : значение2`:

```js
let hp = 0;
let status = hp > 0 ? "жив" : "погиб";
console.log(status);
```

Читается: «hp больше нуля? Если да — "жив", иначе — "погиб"». Удобно, но для сложной логики лучше обычный `if`.

> 🎮 Знаешь, почему в играх так часто бывают «криты», «уклонения» и «блоки»? Это просто ещё несколько `if` перед тем, как отнять здоровье!
@task

3. Отними урон от `heroHp`.
4. Если здоровье больше 0 — выведи `Герой выжил! HP: ...` (с числом), иначе — `Герой пал...`
