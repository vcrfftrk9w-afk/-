@lesson obj-1
title: Объект — всё о персонаже в одном месте
@theory
У героя много характеристик: имя, здоровье, уровень, оружие, координаты. Хранить их в отдельных переменных неудобно — особенно если героев несколько. Удобнее собрать всё в **объект**.

```js
const hero = {
  name: "Рыцарь",
  hp: 100,
  level: 1,
  weapon: "меч"
};

console.log(hero.name);
console.log(hero.hp);
console.log(hero);
```

## Как устроен объект

- объект пишется в **фигурных скобках** `{ }`;
- внутри — пары **ключ: значение**, через запятую;
- ключ (имя свойства) — слово, значение — что угодно.

Такая пара называется **свойство**. У героя четыре свойства: `name`, `hp`, `level`, `weapon`.

## Как достать свойство

**Через точку** — самый частый способ:

```code
hero.name     // "Рыцарь"
hero.hp       // 100
```

**Через квадратные скобки** — если имя свойства хранится в переменной:

```js
const hero = { name: "Рыцарь", hp: 100 };
const what = "hp";
console.log(hero[what]);
console.log(hero["name"]);
```

> 💡 Сравни массив и объект: в массиве элементы по **номерам** (`inventory[0]`), в объекте — по **именам** (`hero.hp`). Массив — для списка однотипных вещей, объект — для описания одной вещи.

> 🎮 В играх объекты — это всё: игрок, враг, пуля, монета, кнопка. У каждого есть `x`, `y`, размеры, скорость…

@lesson obj-2
title: Меняем объект
@theory
Свойства объекта можно менять, добавлять и удалять — прямо как переменные.

```js
const hero = { name: "Рыцарь", hp: 100, level: 1 };

hero.hp -= 30;
hero.level++;
console.log(hero);
```

## Добавить новое свойство

Просто присвой значение свойству, которого ещё нет — оно появится:

```js
const hero = { name: "Рыцарь", hp: 100 };
hero.gold = 50;
hero.hasKey = true;
console.log(hero);
```

## Удалить свойство

```js
const hero = { name: "Рыцарь", hp: 100, curse: "слабость" };
delete hero.curse;
console.log(hero);
```

`delete` [дили́т] — «удалить».

## Есть ли свойство?

```js
const hero = { name: "Рыцарь", hp: 100 };
console.log("hp" in hero);
console.log("mana" in hero);
console.log(hero.mana);
```

Отсутствующее свойство даёт `undefined`, а оператор `in` [ин] отвечает, есть ли такой ключ.

> 💡 Как и с массивами: объект в `const` можно менять внутри. `const` только запрещает заменить весь объект на другой.

## Перебор свойств

```js
const stats = { сила: 8, ловкость: 5, ум: 3 };
for (const key in stats) {
  console.log(key + ": " + stats[key]);
}
console.log(Object.keys(stats));
```

`for...in` перебирает **ключи** объекта. `Object.keys(obj)` возвращает массив ключей.

@lesson obj-3
title: Методы — объекты умеют действовать
@theory
В объекте можно хранить не только данные, но и **функции**. Функция внутри объекта называется **методом**. Ты уже пользовался методами: `console.log` — это метод `log` объекта `console`!

```js
const player = {
  x: 0,
  speed: 5,
  moveRight() {
    this.x += this.speed;
  },
  report() {
    console.log("Игрок на позиции " + this.x);
  }
};

player.moveRight();
player.moveRight();
player.report();
```

## Что такое this

`this` [зис] — «этот». Внутри метода `this` — это **сам объект**, у которого вызвали метод. `this.x` — «мой x», `this.speed` — «моя скорость».

Зачем? Чтобы метод работал с данными своего объекта. Если объект переименовать или скопировать — метод всё равно будет работать с правильными данными.

## Как записать метод

```code
const obj = {
  имяМетода() {
    // команды, можно использовать this
  }
};
```

Вызов — через точку и скобки: `obj.имяМетода()`.

> ⚠️ Внутри метода пиши `this.x`, а не просто `x`. Просто `x` — это какая-то другая, внешняя переменная (скорее всего, её нет — будет ошибка).

> 🎮 У игровых объектов почти всегда есть методы `update()` — «обновиться» (сдвинуться, проверить столкновения) и `draw()` — «нарисоваться». Скоро увидишь!

@lesson obj-4
title: Массив объектов — армия врагов
@theory
Самое мощное сочетание в играх — **массив объектов**. Каждый враг — объект с координатами и здоровьем, а все враги — массив.

```js
const enemies = [
  { name: "Гоблин", hp: 30, x: 50 },
  { name: "Орк", hp: 0, x: 120 },
  { name: "Тролль", hp: 80, x: 200 }
];

console.log(enemies[0].name);
console.log(enemies[2].hp);
console.log("Врагов: " + enemies.length);
```

`enemies[0]` — первый объект, `enemies[0].name` — его имя.

## Перебираем объекты

```js
const enemies = [
  { name: "Гоблин", hp: 30 },
  { name: "Орк", hp: 0 },
  { name: "Тролль", hp: 80 }
];

for (const e of enemies) {
  if (e.hp > 0) {
    console.log(`${e.name} жив (${e.hp} HP)`);
  } else {
    console.log(`${e.name} повержен`);
  }
}

const alive = enemies.filter((e) => e.hp > 0);
console.log("Живых: " + alive.length);
```

## Удар по всем

Изменение объекта внутри цикла меняет его в массиве:

```js
const enemies = [{ hp: 30 }, { hp: 10 }, { hp: 50 }];
for (const e of enemies) {
  e.hp -= 20;
}
console.log(enemies);
```

> 🎮 Вот так выглядит «магия по площади»: один цикл — и урон получили все враги. Каждый кадр игры — это проход по массивам объектов: двигаем, рисуем, проверяем.

@lesson obj-5
title: JSON и сохранение рекорда
@theory
Как игра запоминает рекорд, даже если закрыть браузер? У браузера есть своя «память» — `localStorage` [ло́укал сто́ридж], «местное хранилище».

```js
localStorage.setItem("best", 500);
const saved = localStorage.getItem("best");
console.log("Сохранённый рекорд: " + saved);
```

- `setItem(ключ, значение)` [сет а́йтем] — сохранить;
- `getItem(ключ)` [гет а́йтем] — достать. Если ничего не сохранено — вернёт `null`.

> ⚠️ Хранилище умеет хранить **только текст**. Число 500 сохранится как `"500"`. Поэтому после чтения превращай в число: `Number(localStorage.getItem("best"))`.

> 💡 В этом курсе у песочницы своя память: сохранённое в одном запуске программы будет доступно в следующем. Запусти пример два раза!

```js
let visits = Number(localStorage.getItem("visits")) || 0;
visits++;
localStorage.setItem("visits", visits);
console.log("Ты запускаешь эту программу уже " + visits + " раз");
```

`|| 0` значит «а если там пусто (null превратится в 0, а NaN — тоже ложь) — возьми 0».

## Сохранить объект: JSON

А как сохранить целый объект — например, прогресс героя? Объект надо превратить в текст. Для этого есть формат **JSON** [джейсо́н]:

```js
const save = { level: 3, coins: 120, items: ["меч", "щит"] };

const text = JSON.stringify(save);
console.log(text);

const back = JSON.parse(text);
console.log(back.items[1]);
```

- `JSON.stringify(obj)` [стри́нгифай] — объект → текст;
- `JSON.parse(text)` [парс] — текст → объект.

> 🎮 Так работают сохранения почти во всех браузерных играх.
