@lesson func-1
title: Функция — своя команда
@theory
Ты уже пользовался готовыми командами: `console.log`, `Number`. А теперь научимся создавать **свои**. Такие команды называются **функциями**.

```js
function sayHello() {
  console.log("Привет, игрок!");
  console.log("Добро пожаловать в игру");
}

sayHello();
sayHello();
```

## Две части: создать и вызвать

**1. Создать (объявить)** функцию — это как записать рецепт:

```code
function имяФункции() {
  // команды
}
```

`function` [фа́нкшн] — «функция». После него — имя, круглые скобки и в фигурных скобках — команды.

> ⚠️ Когда функция только объявлена — **ничего не происходит**! Рецепт записан, но блюдо не приготовлено.

**2. Вызвать** функцию — это приготовить по рецепту:

```code
имяФункции();
```

Имя и круглые скобки. Каждый вызов выполняет все команды функции заново.

## Зачем это нужно

- **Не повторяться.** Код прыжка пишется один раз, а вызывается сколько угодно.
- **Порядок.** Большая игра делится на понятные части: `startGame()`, `spawnEnemy()`, `gameOver()`.
- **Легко исправлять.** Нашёл ошибку в функции — исправил в одном месте, и она исправилась везде.

> 💡 Имена функций обычно — глаголы: `jump` (прыгнуть), `shoot` (выстрелить), `drawPlayer` (нарисовать игрока), `resetGame` (сбросить игру).

@lesson func-2
title: Параметры — передаём данные в функцию
@theory
Функция может принимать **данные** — их передают в круглых скобках. Например, функция урона должна знать, **сколько** урона нанести.

```js
function showDamage(amount) {
  console.log(`💥 Урон: ${amount}!`);
}

showDamage(10);
showDamage(25);
showDamage(999);
```

`amount` [эма́унт] — «количество» — это **параметр**: переменная, которая живёт внутри функции. При каждом вызове в неё попадает значение из скобок.

## Несколько параметров

Параметры перечисляются через запятую:

```js
function greet(name, level) {
  console.log(`Привет, ${name}! Твой уровень: ${level}`);
}

greet("Рыцарь", 5);
greet("Маг", 12);
```

Значения подставляются **по порядку**: первое — в первый параметр, второе — во второй.

> ⚠️ Если забыть передать значение, параметр будет `undefined`. Попробуй вызвать `greet("Лучник")` — увидишь «уровень: undefined».

## Параметры по умолчанию

Можно указать значение «на всякий случай»:

```js
function heal(amount = 10) {
  console.log(`+${amount} HP`);
}
heal(50);
heal();
```

> 🧠 Слова-названия: то, что написано в объявлении (`amount`), называется **параметр**, а то, что передаёшь при вызове (`10`), — **аргумент**. Но многие программисты называют и то и другое «параметрами» — тебя поймут.

@lesson func-3
title: return — функция возвращает ответ
@theory
До сих пор наши функции только **печатали**. Но гораздо полезнее, когда функция **возвращает** результат, чтобы его можно было использовать дальше.

```js
function double(n) {
  return n * 2;
}

let result = double(5);
console.log(result);
console.log(double(100) + 1);
```

`return` [рите́рн] — «вернуть». Функция считает значение и **отдаёт его** туда, откуда её вызвали. Вызов `double(5)` превращается в число `10`.

## Печатать или возвращать?

```js
function printSum(a, b) {
  console.log(a + b);
}

function getSum(a, b) {
  return a + b;
}

printSum(2, 3);
let total = getSum(2, 3) * 10;
console.log(total);
```

`printSum` только показывает число на экране — использовать его дальше нельзя. `getSum` возвращает число — с ним можно считать, сравнивать, сохранять в переменную.

> 💡 Почти все полезные функции в играх **возвращают** значения: расстояние до врага, столкнулись ли объекты, сколько урона нанести.

## return заканчивает функцию

После `return` функция сразу останавливается. Код ниже не выполнится:

```js
function check(hp) {
  if (hp <= 0) {
    return "погиб";
  }
  return "жив";
}
console.log(check(0));
console.log(check(50));
```

> 🎮 Функции, которые возвращают `true`/`false`, называют «проверками». Например, `isGameOver()`, `canJump()`, `hasWon()`.

@lesson func-4
title: Полезные игровые функции и Math
@theory
В JavaScript есть готовый набор математических функций — `Math` [мэс]. Они нужны в играх постоянно:

| Функция | Что делает | Пример | Ответ |
|---|---|---|---|
| `Math.max(a, b)` | большее из чисел | `Math.max(3, 8)` | 8 |
| `Math.min(a, b)` | меньшее | `Math.min(3, 8)` | 3 |
| `Math.abs(x)` | без минуса (модуль) | `Math.abs(-7)` | 7 |
| `Math.round(x)` | округлить | `Math.round(4.6)` | 5 |
| `Math.floor(x)` | округлить вниз | `Math.floor(4.9)` | 4 |
| `Math.sqrt(x)` | квадратный корень | `Math.sqrt(25)` | 5 |

```js
console.log(Math.max(10, 50, 30));
console.log(Math.floor(7.99));
console.log(Math.abs(-15));
```

## Функция clamp — «зажать»

В играх часто нужно, чтобы значение **не выходило за границы**. Здоровье — не меньше 0 и не больше 100. Герой — не за краем экрана. Такая функция называется `clamp` [клэмп] — «зажим»:

```code
function clamp(value, min, max) {
  // если value меньше min — вернуть min
  // если value больше max — вернуть max
  // иначе — вернуть value
}
```

## Функция distance — расстояние

Расстояние между двумя точками (например, героем и врагом) считается по теореме Пифагора:

```js
function distance(x1, y1, x2, y2) {
  const dx = x2 - x1;
  const dy = y2 - y1;
  return Math.sqrt(dx * dx + dy * dy);
}

console.log(distance(0, 0, 3, 4));
let d = distance(100, 100, 130, 140);
if (d < 60) {
  console.log("Враг рядом! Расстояние: " + d);
}
```

> 🎮 `distance` — одна из самых популярных функций в играх: заметил ли враг героя, достаёт ли меч, подобрал ли игрок предмет.

@lesson func-5
title: Стрелочные функции
@theory
Есть короткий способ записать функцию — **стрелочная функция** (стрелка `=>`):

```js
const double = (n) => n * 2;
const add = (a, b) => a + b;
const sayHi = () => console.log("Привет!");

console.log(double(7));
console.log(add(2, 3));
sayHi();
```

## Сравни

```code
// Обычная функция
function double(n) {
  return n * 2;
}

// Стрелочная — то же самое
const double = (n) => n * 2;
```

- функция кладётся в переменную через `const`;
- параметры в скобках, потом стрелка `=>` (знаки `=` и `>`);
- если после стрелки одно выражение — оно **автоматически возвращается**, `return` писать не нужно.

Если команд несколько — нужны фигурные скобки и `return`:

```js
const damage = (attack, armor) => {
  const result = attack - armor;
  return Math.max(result, 0);
};
console.log(damage(10, 3));
console.log(damage(2, 8));
```

> 💡 Если параметр один, скобки можно не писать: `n => n * 2`. Но со скобками понятнее, особенно новичкам.

> 🎮 Стрелочные функции особенно удобны, когда функцию нужно передать в другую функцию — например, «что делать при нажатии клавиши». Это ждёт тебя в модуле «Управление».

@lesson func-6
title: Область видимости — где живут переменные
@theory
Переменные, созданные **внутри** функции, существуют **только внутри неё**. Снаружи их не видно:

```js error
function attack() {
  let damage = 25;
  console.log("Внутри функции: " + damage);
}
attack();
console.log(damage);
```

Это называется **область видимости**. Каждая пара фигурных скобок `{ }` — как отдельная комната: что создано внутри, наружу не выходит.

## Глобальные переменные

Переменная, созданная **снаружи** всех функций, видна везде — и в функциях тоже. Так хранят общее состояние игры:

```js
let score = 0;

function collectCoin() {
  score += 10;
  console.log("Монета! Счёт: " + score);
}

collectCoin();
collectCoin();
console.log("Итого: " + score);
```

Функция `collectCoin` **меняет** общую переменную `score`.

> 💡 Правило: если значение нужно только внутри функции — создавай его внутри. Если оно должно жить всё время игры (счёт, жизни, уровень) — снаружи.

## Одинаковые имена

Если внутри функции создать переменную с тем же именем, она «загородит» внешнюю:

```js
let hp = 100;
function test() {
  let hp = 5;
  console.log("Внутри: " + hp);
}
test();
console.log("Снаружи: " + hp);
```

> ⚠️ Это частая причина ошибок: написал `let` внутри функции — и вместо изменения общей переменной создал новую. Внутри функции для общей переменной пиши без `let`: `hp = hp - 10`.

@lesson func-7
title: Случайные числа
@theory
Без случайности игры были бы скучными: враги появлялись бы в одном месте, кубик всегда выпадал бы на 6. Случайное число даёт `Math.random()` [ра́ндом]:

```js
console.log(Math.random());
console.log(Math.random());
console.log(Math.random());
```

Каждый раз получается новое дробное число **от 0 до 1** (единица никогда не выпадает). Например, 0.4273…

## Как получить случайное целое число

Допустим, нужен кубик — от 1 до 6:

```js
const roll = Math.floor(Math.random() * 6) + 1;
console.log("Выпало: " + roll);
```

Разберём по шагам:
1. `Math.random()` → от 0 до 0.999…
2. `* 6` → от 0 до 5.999…
3. `Math.floor(...)` → целое: 0, 1, 2, 3, 4 или 5
4. `+ 1` → 1, 2, 3, 4, 5 или 6 ✓

## Универсальная функция

Чтобы не писать формулу каждый раз, сделаем функцию — она будет в каждой нашей игре:

```code
function randomInt(min, max) {
  return Math.floor(Math.random() * (max - min + 1)) + min;
}
```

`max - min + 1` — сколько всего вариантов. Например, от 3 до 5 — это 3 варианта (3, 4, 5).

## Случай с вероятностью

«С шансом 30% враг уклонится»:

```js
if (Math.random() < 0.3) {
  console.log("Враг уклонился!");
} else {
  console.log("Попадание!");
}
```

`Math.random() < 0.3` верно примерно в 30% случаев. Запусти несколько раз!
