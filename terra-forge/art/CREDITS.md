# Art and sound credits

## Pictures

The ground textures and the painted unit and building pictures in this folder were generated
for this game by the project owner with image AI tools (ChatGPT / Gemini). The simple vector
sprites (helicopter, rotor, explosion, dust, track prints) are drawn in code by
`tools/gen_sprites.js`.

## Sounds

`sounds.ogg` is cut from public-domain (CC0) sound packs on OpenGameArt.org by
`tools/build_sounds.py`. CC0 needs no attribution; the sources are listed so they can be found
again:

| Clips | Pack |
| --- | --- |
| rifle | [Gunshot Sounds](https://opengameart.org/content/gunshot-sounds) |
| mg, cannon, tower, flak | [25 CC0 bang / firework SFX](https://opengameart.org/content/25-cc0-bang-firework-sfx) |
| artillery | [Gunshots](https://opengameart.org/content/gunshots) (Black Powder) |
| rocket | [Rocket launch](https://opengameart.org/content/rocket-launch) |
| boom | [Sci-Fi Sounds](https://opengameart.org/content/sci-fi-sounds) by Kenney |
| bigboom | [Chunky Explosion](https://opengameart.org/content/chunky-explosion) |
| build, hammer | [100 CC0 SFX](https://opengameart.org/content/100-cc0-sfx) |
| built, ready, click, order, error, alarm, win, lose | [Interface Sounds](https://opengameart.org/content/interface-sounds) by Kenney |
