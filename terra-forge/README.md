# Terra Forge (Roblox)

Стратегия в реальном времени на настоящей карте мира. Ставишь столицу в любой точке Земли, захватываешь землю, строишь шахты и заводы, выпускаешь пехоту, танки и самолёты и сам командуешь ими. Над страной видны твой ник и аватарка из Roblox.

## Как играть

- **Старт:** 10 секунд, чтобы выбрать на карте мира, где появиться.
- **Захват земли войсками:** выбери внизу слева, сколько войск отправить (20–80%), и нажми на землю у своей границы. Граница расползается плавно.
- **Деньги:** столица даёт доход, каждая клетка земли добавляет ещё немного. Больше земли — больше денег. Экстрактор на месторождении (рыжие, серые и чёрные пятна) даёт +6 $/с.
- **Постройки:** выбери постройку внизу и нажми на свою землю. Она строится несколько секунд.
- **Заказ войск:** нажми на свою казарму, танковый завод или аэродром. «+1» ставит юнит в очередь, «Авто» выпускает его по кругу, «Точка сбора» задаёт, куда новым юнитам ехать.
- **Армия:** нажми на юнит или выбери группу (пехота, техника, авиация, все), потом нажми на карту. Войска едут в объезд воды, захватывают землю по пути и сами стреляют по врагам.
- **Туман войны:** видно только то, что рядом с твоей землёй, постройками и войсками.
- **Перелёт к базе:** кнопка с замком наверху или нажатие на свою землю издалека. Камера, как при смене героя в GTA, рывками взлетает в небо, пролетает над картой и ныряет к базе.
- **Кто кого бьёт:** танк силён против пехоты, ракетчик против техники и авиации, артиллерия бьёт издалека по постройкам, истребитель охотится за авиацией, вертолёт бьёт по наземным целям, башня и ПВО защищают базу.

Название пока рабочее.

## Как запустить

Нужен компьютер (Windows или Mac) с Roblox Studio.

1. Скачай `build/TerraForge.rbxlx`.
2. В Roblox Studio выбери **File → Open from File** и открой этот файл.
3. Опубликуй игру: **File → Publish to Roblox**.
4. Нажми **Play**. Проверить игру с друзьями можно через **Test → Clients and Servers**, там же выбирается число игроков.

## Как устроено

| Где | Что |
| --- | --- |
| `src/shared` | общее для сервера и клиента: правила (`Config`), карта мира (`Map`, `MapData`), иконки (`Icons`), формат сетевых данных (`Codec`) |
| `src/server` | сервер: матч, боты, экономика, постройки, войска (`Match`), захват территории (`World`) |
| `src/client` | клиент: матч в 3D (`MapView`), земля и вода (`Ground`), камера (`CameraRig`), 3D-модели (`Models`), меню и интерфейс (`Ui`), иконки (`Sprites`), стиль (`Theme`) |
| `tools` | генераторы данных и сборка файла игры |

Сервер ведёт один матч на 40 стран: игроки плюс боты. Всё считает сервер, клиенты только рисуют. Каждые 0,2 секунды сервер рассылает изменения территории сжатыми пакетами.

Войска движутся по маршрутам. Маршрут по суше ищет A* (`src/server/Path.luau`) и спрямляет его. Позицию юнита в любой момент считает общая функция `src/shared/Motion.luau` по маршруту, скорости и времени старта. Поэтому по сети уходят только приказы, а не координаты каждый кадр. Бой идёт на сервере: каждый юнит и каждая башня бьют ближайшего врага в радиусе, а клиенты получают здоровье, выстрелы и взрывы.

Мир трёхмерный, одна клетка карты равна двум стадам. Земля — нарисованная карта мира на ровных плитах (`src/client/Ground.luau`). Картинку рисует `tools/gen_texture.py` по той же клеточной карте, что и игра: плавные берега, мелководье, пляжи, леса, пустыни, горы с тенями и снегом. `tools/upload_art.py` загружает её в Roblox восемью наклейками через Open Cloud и записывает их номера в `src/shared/MapArt.luau`; сервер при старте достаёт из наклеек картинки (InsertService) и передаёт клиентам. Территории стран и туман войны — плоские полупрозрачные детали поверх карты (`src/client/Territory.luau`): в каждой строке карты подряд идущие клетки одной страны становятся одной плиткой.

Картинки и меши на лету (EditableImage, EditableMesh) игра для мира не использует: в опубликованной игре Roblox разрешает их только владельцу с подтверждённым возрастом 13+ и документом. Значки интерфейса рисуются картинками, где это можно (например, в Studio), а иначе маленькими 3D-моделями во ViewportFrame и символами (`src/client/Sprites.luau`).

Танки, пехота, самолёты, вертолёты и постройки собраны из деталей Roblox (`src/client/Models.luau`). Юниты двигаются каждый кадр через `workspace:BulkMoveTo`. Издалека вместо моделей видны цветные точки. Мини-карта в углу нарисована рамками интерфейса, по ней можно двигать камеру.

## Если что-то сломалось

Ошибки показываются прямо на экране красной плашкой, в том числе ошибки сервера. Сделай скриншот: по нему видно, где ошибка.

## Правка и пересборка

Код можно править прямо в Studio. Если работаешь с файлами из этой папки, после правок собери файл игры заново:

```
python3 tools/build_place.py
```

Ещё можно подключить [Rojo](https://rojo.space) к `default.project.json`.

Опубликовать новую версию в Roblox без Studio:

```
tools/publish.sh
```

Скрипт проверяет код, собирает файл и отправляет его через Open Cloud. Перерисовать и заново загрузить карту:

```
python3 tools/gen_texture.py /tmp/tex && python3 tools/upload_art.py /tmp/tex
```

Для загрузки картинок ключу нужны права «assets» (чтение и запись). Нужен ключ API с правом universe-places: write. В облачной среде Claude ключ лежит в сетевом секрете для `apis.roblox.com` (заголовок `x-api-key`). Ещё ключ можно передать вручную: `ROBLOX_API_KEY=... tools/publish.sh`.

Генераторы данных:

- `tools/gen_map.py` переводит карту Natural Earth (общественное достояние) в клетки;
- `tools/gen_icons.js` рисует иконки из `tools/icons.js`, для него нужен Playwright;
- `tools/gen_data.py` записывает `Icons.luau` и `MapData.luau`;
- `tools/check_luau.py` быстро проверяет код Luau: блоки, скобки, неизвестные имена.
