@lesson anim-1
title: Как работает анимация — игровой цикл
@theory
Мультфильм — это много картинок, которые быстро сменяют друг друга. Каждая картинка — **кадр**. Если показывать больше 24 кадров в секунду, глаз видит плавное движение.

Игры работают так же — обычно **60 кадров в секунду**. Каждый кадр программа:

1. **стирает** холст;
2. **меняет** положение объектов (чуть-чуть сдвигает);
3. **рисует** всё заново.

И так по кругу. Это называется **игровой цикл** (game loop [гейм луп]).

```js canvas
let x = 0;

function loop() {
  ctx.clearRect(0, 0, canvas.width, canvas.height);

  ctx.fillStyle = "tomato";
  ctx.fillRect(x, 140, 40, 40);

  x += 2;
  if (x > canvas.width) {
    x = -40;
  }

  requestAnimationFrame(loop);
}

loop();
```

## Разбор

- `ctx.clearRect(0, 0, canvas.width, canvas.height)` — стереть весь холст (`clear` [клир] — «очистить»). Без этого квадрат оставлял бы за собой след.
- `x += 2` — каждый кадр сдвигаем квадрат на 2 пикселя вправо.
- `requestAnimationFrame(loop)` [рикуэ́ст энимэ́йшн фрейм] — «попроси кадр анимации»: браузер вызовет `loop` ещё раз перед следующим кадром экрана. Функция сама себя «заказывает» снова и снова.
- `loop();` в самом конце — первый запуск цикла.

> 🧠 Почему не `while (true)`? Бесконечный while никогда не отдаст браузеру управление, и тот не успеет показать ни одного кадра — страница зависнет. `requestAnimationFrame` вызывает функцию ровно тогда, когда экран готов к новому кадру.

Попробуй убрать строчку с `clearRect` и запустить — увидишь «шлейф».

> 🎮 Абсолютно все игры, от «Змейки» до огромных 3D-миров, крутятся в таком цикле: стереть → обновить → нарисовать → повторить.

@lesson anim-2
title: Скорость и направление
@theory
Чтобы объект мог двигаться в любую сторону, у него две скорости:

- `vx` — на сколько пикселей сдвигаться **по горизонтали** за кадр;
- `vy` — на сколько **по вертикали**.

(`v` — от velocity [вело́сити] — «скорость».)

| vx | vy | Куда движется |
|---|---|---|
| 3 | 0 | вправо |
| -3 | 0 | влево |
| 0 | 3 | вниз |
| 0 | -3 | вверх |
| 3 | 2 | вправо и вниз (по диагонали) |

```js canvas
const ball = { x: 50, y: 50, vx: 3, vy: 2, r: 15 };

function update() {
  ball.x += ball.vx;
  ball.y += ball.vy;
}

function draw() {
  ctx.clearRect(0, 0, canvas.width, canvas.height);
  ctx.fillStyle = "cyan";
  ctx.beginPath();
  ctx.arc(ball.x, ball.y, ball.r, 0, Math.PI * 2);
  ctx.fill();
}

function loop() {
  update();
  draw();
  requestAnimationFrame(loop);
}

loop();
```

## Порядок в коде: update и draw

Профессионалы делят игровой цикл на две функции:

- `update()` [апде́йт] — «обновить»: только меняет данные (координаты, счёт), ничего не рисует;
- `draw()` [дро] — «нарисовать»: только рисует, ничего не меняет.

Так код намного проще понимать и исправлять. Мы будем всегда так делать.

@lesson anim-3
title: Отскок от стен
@theory
Мяч улетел за край экрана и пропал. Давай научим его **отскакивать**!

Идея простая: если мяч коснулся правой или левой стены — **разворачиваем** скорость по горизонтали: `vx = -vx`. Была `3` — стала `-3`, и мяч полетел обратно. С верхом и низом — то же самое с `vy`.

```js canvas
const ball = { x: 100, y: 80, vx: 4, vy: 3, r: 18 };

function update() {
  ball.x += ball.vx;
  ball.y += ball.vy;

  if (ball.x + ball.r > canvas.width || ball.x - ball.r < 0) {
    ball.vx = -ball.vx;
  }
  if (ball.y + ball.r > canvas.height || ball.y - ball.r < 0) {
    ball.vy = -ball.vy;
  }
}

function draw() {
  ctx.clearRect(0, 0, canvas.width, canvas.height);
  ctx.fillStyle = "gold";
  ctx.beginPath();
  ctx.arc(ball.x, ball.y, ball.r, 0, Math.PI * 2);
  ctx.fill();
}

function loop() {
  update();
  draw();
  requestAnimationFrame(loop);
}
loop();
```

## Почему `ball.x + ball.r`?

`ball.x` — это **центр** мяча. Его правый край — `x + r`, левый — `x - r`. Если проверять только центр, мяч будет наполовину проваливаться в стену.

| Стена | Условие касания |
|---|---|
| правая | `ball.x + ball.r > canvas.width` |
| левая | `ball.x - ball.r < 0` |
| нижняя | `ball.y + ball.r > canvas.height` |
| верхняя | `ball.y - ball.r < 0` |

> 💡 Бывает, что мяч «залипает» в стене и дрожит: на одном кадре скорость развернулась, но мяч ещё не успел выйти из стены, — и на следующем кадре развернулась обратно. Надёжнее не разворачивать, а задавать направление: у правой стены `vx = -Math.abs(vx)` (точно влево), у левой `vx = Math.abs(vx)` (точно вправо).

> 🎮 Отскок — основа арканоида, пинг-понга и бильярда.

@lesson anim-4
title: Таймеры — setInterval и setTimeout
@theory
Иногда нужно сделать что-то **через время** или **раз в N секунд**: обратный отсчёт, появление врага каждые 2 секунды, бонус, который действует 5 секунд.

## setTimeout — один раз через время

```js
console.log("Бомба заложена!");
setTimeout(() => {
  console.log("💥 БАБАХ!");
}, 2000);
```

`setTimeout(функция, миллисекунды)` [сет та́ймаут] — выполнить функцию **один раз** через указанное время. **1000 миллисекунд = 1 секунда**.

## setInterval — повторять

```js
let count = 0;
const timer = setInterval(() => {
  count++;
  console.log("Тик " + count);
  if (count === 5) {
    clearInterval(timer);
    console.log("Таймер остановлен");
  }
}, 500);
```

- `setInterval(функция, мс)` [сет и́нтервал] — повторять функцию каждые N миллисекунд;
- он возвращает «номер таймера» — сохраняем его в переменную;
- `clearInterval(номер)` [клир и́нтервал] — остановить.

## Таймер на экране

```js canvas
let timeLeft = 5;

const timer = setInterval(() => {
  timeLeft--;
  if (timeLeft <= 0) {
    clearInterval(timer);
  }
}, 1000);

function draw() {
  ctx.clearRect(0, 0, canvas.width, canvas.height);
  ctx.fillStyle = "white";
  ctx.font = "bold 48px Arial";
  ctx.textAlign = "center";
  ctx.fillText(timeLeft > 0 ? "⏰ " + timeLeft : "Время вышло!", 240, 175);
  requestAnimationFrame(draw);
}
draw();
```

> 💡 Обрати внимание: таймер **меняет данные** (timeLeft), а игровой цикл их **рисует**. Они работают одновременно и не мешают друг другу.

> 🎮 setInterval — способ сделать «тик» игры с постоянной скоростью. Например, змейка двигается ровно раз в 150 мс, а не 60 раз в секунду.

2. Когда `timeLeft` дошёл до 0 — останови таймер через `clearInterval`.
3. Игровой цикл уже рисует текст — посмотри, как меняется число.

@lesson anim-5
title: Много объектов в движении
@theory
Один мяч — скучно. Давай запустим **сотню**! Для этого объекты хранят в **массиве**, а в `update` и `draw` перебирают циклом.

```js canvas
const snow = [];
for (let i = 0; i < 100; i++) {
  snow.push({
    x: Math.random() * canvas.width,
    y: Math.random() * canvas.height,
    r: 1 + Math.random() * 3,
    speed: 0.5 + Math.random() * 2
  });
}

function update() {
  for (const f of snow) {
    f.y += f.speed;
    if (f.y > canvas.height) {
      f.y = -5;
      f.x = Math.random() * canvas.width;
    }
  }
}

function draw() {
  ctx.fillStyle = "#0b1030";
  ctx.fillRect(0, 0, canvas.width, canvas.height);
  ctx.fillStyle = "white";
  for (const f of snow) {
    ctx.beginPath();
    ctx.arc(f.x, f.y, f.r, 0, Math.PI * 2);
    ctx.fill();
  }
}

function loop() {
  update();
  draw();
  requestAnimationFrame(loop);
}
loop();
```

## Что здесь происходит

1. **Создание.** Цикл создаёт 100 снежинок со случайными координатами, размером и скоростью и кладёт их в массив `snow`.
2. **update.** Каждую снежинку сдвигаем вниз на её скорость. Упала за нижний край — переносим наверх: снег идёт бесконечно.
3. **draw.** Заливаем фон (это тоже «стирание» холста) и рисуем каждую снежинку.

> 💡 Маленькие снежинки падают медленнее — так кажется, что они дальше. Это простой трюк, который создаёт глубину. Называется **параллакс**.

> 🎮 Так делают звёздное небо в космических играх, дождь, листопад, искры от взрывов, пули и толпы врагов.

const stars = [];

// 1. Создай 30 звёзд
for (let i = 0; i < 30; i++) {
  stars.push({
    x: Math.random() * canvas.width,
    y: Math.random() * canvas.height,
    speed: 1 + Math.random() * 3
  });
}

function update() {
  // 2. Двигай звёзды вниз
  // 3. Возвращай наверх
  for (const s of stars) {
    s.y += s.speed;
    if (s.y > canvas.height) {
      s.y = 0;
    }
  }
}

function draw() {
  ctx.fillStyle = "#070b1f";
  ctx.fillRect(0, 0, canvas.width, canvas.height);
  ctx.fillStyle = "white";
  for (const s of stars) {
    ctx.fillRect(s.x, s.y, 3, 3);
  }
}

function loop() {
  update();
  draw();
  requestAnimationFrame(loop);
}
loop();
