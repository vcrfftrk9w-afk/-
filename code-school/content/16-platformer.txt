Четвёртый проект — **платформер**, как Марио: герой бегает, прыгает по платформам, собирает монеты, прыгает на врагов и добегает до флага.

## Уровень — это текст!

Рисовать уровень координатами — долго и неудобно. Профессионалы делают иначе: уровень описывают **картой из символов**, а программа превращает её в мир.

```code
const level = [
  "............",
  "............",
  "..........F.",
  "......o.####",
  "...o..###...",
  "..###.......",
  "o.......E..o",
  "############"
];
```

| Символ | Что это |
|---|---|
| `#` | блок земли / платформы |
| `.` | пустота |
| `o` | монета |
| `E` | враг (enemy) |
| `F` | флаг финиша (flag) |

Каждый символ — клетка 40 × 40 пикселей (`TILE` [тайл] — «плитка»). 12 символов × 40 = 480 — ширина холста, 8 строк × 40 = 320 — высота.

> 🎮 Хочешь новый уровень — просто нарисуй другую карту! Не нужно менять ни строчки кода. Так делают уровни во множестве игр, и ты тоже сможешь придумывать свои.

## Превращаем карту в блоки

Двойной цикл по строкам и символам (как в модуле «Массивы»):

```code
for (let row = 0; row < level.length; row++) {
  for (let col = 0; col < level[row].length; col++) {
    const ch = level[row][col];         // символ в этой клетке
    if (ch === "#") {
      tiles.push({ x: col * TILE, y: row * TILE, w: TILE, h: TILE });
    }
  }
}
```

Номер столбца × размер клетки = x в пикселях, номер строки × размер = y.

@lesson plt-2
title: Шаг 2. Стоим на платформах
xp: 25
@theory
Самая хитрая часть платформера — **столкновения с блоками**. Герой должен стоять на платформах, упираться в стены и ударяться головой о потолок.

## Секрет: двигаемся по осям по очереди

Если сдвинуть героя сразу по x и y, а потом обнаружить, что он застрял в блоке, непонятно, **откуда** он пришёл: сверху? сбоку? Поэтому профессионалы двигают **по очереди**:

1. Сдвинули по **x** → проверили все блоки → если врезались, значит упёрлись **сбоку**: выталкиваем по x.
2. Сдвинули по **y** → проверили все блоки → если врезались, значит пришли **сверху или снизу**: выталкиваем по y.

## Вертикальные столкновения

После сдвига по y, для каждого блока, с которым пересеклись:

- если летели **вниз** (`vy > 0`) — приземлились: ставим героя **на** блок, `vy = 0`, `onGround = true`;
- если летели **вверх** (`vy < 0`) — ударились головой: ставим героя **под** блок, `vy = 0`.

```code
player.onGround = false;
for (const t of tiles) {
  if (rectsCollide(player, t)) {
    if (player.vy > 0) {
      player.y = t.y - player.h;     // встать сверху
      player.vy = 0;
      player.onGround = true;
    } else if (player.vy < 0) {
      player.y = t.y + t.h;          // упереться головой снизу
      player.vy = 0;
    }
  }
}
```

`onGround = false` перед циклом — «пока не доказано, что стоим, считаем, что в воздухе».

## Горизонтальные столкновения

Уже написаны в коде — посмотри, они устроены так же: шли вправо — встаём слева от блока, шли влево — справа.

> 🧠 Этот приём («сначала x, потом y») — основа физики в тысячах 2D-игр. Разберись в нём, и сможешь сделать любой платформер.

## Расширяем buildLevel

В том же двойном цикле добавляем новые проверки:

```code
if (ch === "o") coins.push({ x: col * TILE + 12, y: row * TILE + 12, w: 16, h: 16 });
if (ch === "F") goal = { x: col * TILE + 8, y: row * TILE, w: 24, h: TILE };
```

Монета маленькая (16 × 16) и стоит в середине клетки: отступ 12 = (40 − 16) / 2. Флаг — узкий столб высотой в клетку.

## Сбор и финиш

Монеты собираются так же, как в модуле «Физика», — цикл с конца и `splice`. А флаг — это просто проверка столкновения, после которой игра переходит в состояние «победа»:

```code
if (rectsCollide(player, goal)) state = "win";
```

> 🎮 Хочешь, чтобы флаг открывался, только когда собраны все монеты? Добавь условие `&& coins.length === 0`. Такие маленькие правила делают игру интереснее.

  if (keys["ArrowLeft"]) player.vx = -SPEED;

@theory
Какой платформер без врагов! Добавим патрульных: они ходят туда-сюда, касание сбоку отнимает жизнь, а **прыжок сверху** побеждает врага — как в Марио.

## Враг-патрульный

```code
{ x: ..., y: ..., w: 30, h: 30, vx: 1.2 }
```

Каждый кадр враг идёт на `vx`. Упёрся в блок или край экрана — разворачивается: `vx = -vx`.

## Прыжок на голову или удар сбоку?

Касание врага бывает двух видов. Как их отличить? Посмотрим, **где был низ героя на прошлом кадре**: если выше верха врага — значит, герой падал сверху:

```code
const wasAbove = player.y + player.h - player.vy <= e.y + 6;
if (player.vy > 0 && wasAbove) {
  // прыжок сверху — враг повержен, герой отскакивает
} else {
  // удар сбоку — герой теряет жизнь
}
```

`player.y + player.h - player.vy` — где был низ героя кадр назад (мы вычитаем последний шаг). `+ 6` — небольшой запас, чтобы прыжок засчитывался даже при касании «вскользь».

## Жизни

Удар — минус жизнь и возврат на старт. Жизни кончились — состояние `"lose"`. Пробел после конца игры — `restart()`.

> 🏆 Готово! Это уже настоящий платформер. Нарисуй свои уровни картой, добавь шипы (символ `^`), двойной прыжок, движущиеся платформы — и у тебя будет своя игра!
