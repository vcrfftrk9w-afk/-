# 🧠 Умник — ИИ-помощник для Android, который видит экран

Круглая кнопка поверх любого приложения. Нажал — Умник делает снимок экрана и помогает именно с тем,
что у тебя открыто. Думать может двумя способами — выбираешь в приложении:

- **📱 Бесплатно, прямо в телефоне** — модель Gemma 4 от Google (лицензия Apache 2.0) через LiteRT-LM.
  Без ключей, без денег и даже без интернета; снимки экрана никуда не уходят. Один раз скачивается файл 2,6 ГБ.
- **🔑 Claude по ключу** — Claude Opus 5.5 от Anthropic: самый умный, но платный (нужен ключ API и деньги на счёте),
  и API Claude работает не во всех странах — например, недоступен в России и Беларуси.

## Что умеет

- **Видит экран и отвечает по нему.** Быстрые кнопки подстраиваются под приложение:
  в мессенджере — «Помоги ответить» и «Это не развод?», в браузере — «Кратко» и «Это правда?»,
  в учёбе — «Реши с объяснением», в играх — «Подсказка». Или свой вопрос текстом и голосом 🎤.
  Ответ печатается по мере прихода, по желанию читается вслух 🔊.
- **Шахматы — бесплатно и без интернета.** В шахматном приложении рядом с кнопкой появляется ♟: нажми в свой ход —
  Умник сам узнает доску на скриншоте, а встроенный шахматный движок найдёт лучший ход и покажет его стрелкой
  на мини-доске («Ход белых: конь g1 → f3», оценка, продолжение). В новом приложении один раз нажми ♟ в начале
  партии — Умник запомнит, как там выглядят фигуры. «🤔 Почему?» — объяснение хода, «⇄» — посчитать за другую
  сторону, «🔃 Доска наоборот» — если перепутал, кто снизу.
- **Перерывы.** Считает, сколько ты сидишь в телефоне без перерыва и в каких приложениях. Через 45 минут
  (настраивается) напоминает размяться. Ночью скажет, что пора спать.
- **Сам подсказывает** (выключено по умолчанию): раз в несколько минут смотрит на экран и говорит, только если
  заметил что-то важное — ошибку в тексте, похожее на мошенничество сообщение, подсказку к задаче.
- **Помнит, кто ты**: в настройках «О себе» — имя, класс, увлечения, чтобы ответы были под тебя.

## Установка

1. Скачай `umnik.apk` и открой его на телефоне. Android спросит разрешение ставить приложения из этого источника —
   разреши. Если Play Защита предупредит о неизвестном приложении — «Всё равно установить».
   На Samsung может мешать «Автоблокировка» (Настройки → Безопасность) — её нужно выключить на время установки.
2. **Чем думает Умник.**
   - Бесплатно: «Скачать бесплатный ИИ (2,6 ГБ)». Лучше по Wi-Fi; загрузка идёт сама, даже если закрыть приложение,
     прогресс — в уведомлениях. Нужно ~3 ГБ свободного места. Если сайт с моделью не открывается — «Скачать с зеркала».
     Телефону нужно хотя бы 4 ГБ оперативной памяти, лучше 6 и больше. Первый ответ после паузы — через 5–30 секунд
     (модель загружается в память), дальше быстрее; на телефонах с хорошей видеокартой — почти мгновенно.
   - Claude: ключ на [platform.claude.com](https://platform.claude.com/settings/keys) → API keys → Create key.
     На счёте нужны деньги: вопрос со снимком экрана на Opus стоит примерно 2–4 цента, на Haiku — в десятки раз дешевле.
3. **Доступ к экрану.** «Включить в спецвозможностях» → «Умник» → включить. Если переключатель серый
   («Настройка заблокирована») — это защита Android 13+ для приложений не из Google Play: Настройки → Приложения →
   Умник → ⋮ → «Разрешить настройки с ограниченным доступом», потом включить снова.
4. **Уведомления** (Android 13+) — чтобы напоминания о перерыве приходили, когда кнопка спрятана.

Кнопку можно таскать пальцем, долгое нажатие прячет её на 30 минут. Нужен Android 8 или новее (снимки экрана —
с Android 11) и 64-битный телефон (почти все телефоны последних лет).

## Приватность

- Бесплатный ИИ разбирает снимки прямо в телефоне — они никуда не отправляются.
  С Claude снимок уходит в Anthropic только вместе с вопросом: когда ты нажал кнопку или включил «Сам подсказывать».
  В телефоне снимки не сохраняются. Ключ API хранится только в телефоне и не попадает в резервные копии.
- Приложения банков и кино запрещают снимки экрана — там Умник видит только название приложения.
- «Сам подсказывать» не смотрит на экран в банковских приложениях и когда вводится пароль.
- Умник ничего не нажимает за тебя: доступ к спецвозможностям нужен только, чтобы видеть экран и показывать кнопку.

♟ В рейтинговых партиях против живых людей подсказки запрещены правилами chess.com и lichess — за это банят аккаунт.
Для учёбы, задач и игры с ботом — пожалуйста.

## Как устроено

| Файл | Что делает |
|---|---|
| `UmnikService.java` | служба спецвозможностей: какое приложение открыто, снимки экрана, время в телефоне, перерывы, сам-подсказки |
| `Overlay.java` | кнопка поверх экрана, кнопка ♟ и карточки с подсказками |
| `AssistantActivity.java` | окно помощника: беседа, быстрые кнопки, голос, чтение вслух |
| `MainActivity.java` | выбор «мозга», загрузка бесплатного ИИ, подключение и настройки, статистика за сегодня |
| `Mind.java` | общий вид «мозга»: беседа со снимком, разовый ответ |
| `LocalMind.java`, `ModelStore.java` | бесплатный ИИ: Gemma 4 E2B через LiteRT-LM (сначала видеокарта, потом процессор), загрузка модели системным загрузчиком с проверкой SHA-256 |
| `Brain.java`, `Prompts.java` | Claude через официальный Java SDK: потоковый ответ, распознавание доски (структурированный JSON), понятные ошибки |
| `chess/Eye.java` | «зрение» для шахмат без ИИ: находит плоскую доску 8×8, запоминает силуэты фигур по начальной позиции, узнаёт позицию, сторону и чей ход по подсветке |
| `chess/` | шахматный движок (альфа-бета, таблицы PeSTO), подсказка по-русски, мини-доска |

Модель в телефоне загружается в память при первом вопросе (окно помощника начинает её загружать сразу, пока
печатаешь вопрос) и выгружается через 5 минут без вопросов. Ответы идут по одному: вопрос человека прерывает
фоновую сам-подсказку. Если драйвер видеокарты не справился, Умник запоминает это и дальше считает на процессоре.

Беседа с Claude только дописывается и не правится задним числом — модель помнит свои рассуждения, а повтор начала
беседы берётся из кэша. Для Opus и Sonnet включена серверная подстраховка (`fallbacks: "default"`): если классификатор
безопасности ошибочно отклонит запрос, ответит другая подходящая модель.

## Сборка

Нужны JDK 21 (библиотека LiteRT-LM собрана под Java 21) и Android SDK 35.

```bash
gradle -p umnik :app:assembleRelease      # APK: umnik/app/build/outputs/apk/release/app-release.apk
gradle -p umnik :app:testReleaseUnitTest  # тесты: правила шахмат (perft), движок, «зрение», запросы к Claude, экраны
```

Тест `ScreensTest` рисует экраны через Robolectric в `umnik/app/build/screens/*.png` — удобно смотреть, что поменялось.
`EyeTest` рисует скриншоты телефона с доской и проверяет, что «зрение» узнаёт позицию.

GitHub Actions (`.github/workflows/umnik-apk.yml`) собирает APK при каждом изменении в `umnik/`:
Actions → **Umnik APK** → последний запуск → Artifacts → `umnik-apk`.
Без секретов APK подписан отладочным ключом сборщика. Чтобы каждое обновление ставилось поверх старого,
добавь в Settings → Secrets → Actions свой ключ: `UMNIK_KEYSTORE_BASE64` (keystore в base64) и `UMNIK_KEYSTORE_PASSWORD`
(пароль хранилища и ключа, псевдоним ключа — `umnik`).
