## Перезарядка

Если стрелять каждый кадр, пока зажат пробел, получится 60 выстрелов в секунду — сплошной луч. Нужна **перезарядка** (cooldown [ку́лдаун] — «остывание»):

```code
ship.cooldown--;                              // каждый кадр «остываем»
if (keys[" "] && ship.cooldown <= 0) {
  bullets.push(new Bullet(ship.x + ship.w / 2 - 2, ship.y));
  ship.cooldown = 12;                         // следующий выстрел через 12 кадров
}
```

12 кадров ≈ 0.2 секунды — 5 выстрелов в секунду.

## Пуля вылетает из носа корабля

`ship.x + ship.w / 2` — середина корабля. Минус половина ширины пули (2), чтобы пуля была ровно по центру. А `ship.y` — верх корабля.

> 💡 Класс `Bullet` ты уже писал в модуле «Классы». Здесь он почти такой же — только с размерами `w` и `h`, чтобы потом проверять попадания.

Теперь — угроза из космоса. Астероиды появляются сверху в случайном месте и летят вниз.

## Класс Rock

```code
class Rock {
  constructor(x, speed) {
    this.size = 24 + Math.random() * 20;   // случайный размер
    this.x = x;
    this.y = -this.size;                   // начинается чуть выше экрана
    this.w = this.size;
    this.h = this.size;
    this.speed = speed;
  }
  update() { this.y += this.speed; }
  isOff() { return this.y > canvas.height; }
}
```

`rock` [рок] — «камень». Астероид начинается **выше** экрана (`y = -size`), поэтому плавно «въезжает» сверху, а не появляется из ниоткуда.

## Появление через промежутки

Как с трубами во Flappy Bird — считаем кадры:

```code
frame++;
if (frame % 40 === 0) {
  const x = Math.random() * (canvas.width - 40);
  rocks.push(new Rock(x, 2));
}
```

`canvas.width - 40` — чтобы большой астероид не вылез за правый край.

> 🎮 Разные размеры и скорости делают картинку живой. Можно даже вращать астероиды — добавь `this.angle` и используй `ctx.rotate`.

@lesson sht-3
title: Шаг 3. Попадания и взрывы
xp: 20
@theory
Пора сбивать астероиды! Каждый кадр проверяем **каждую пулю** с **каждым астероидом** — двойной цикл. Попали — удаляем обоих, добавляем очки и запускаем **взрыв из частиц** (помнишь урок про частицы?).

## Двойной цикл с удалением

```code
for (let i = rocks.length - 1; i >= 0; i--) {
  for (let j = bullets.length - 1; j >= 0; j--) {
    if (rectsCollide(rocks[i], bullets[j])) {
      explode(rocks[i].x + rocks[i].w / 2, rocks[i].y + rocks[i].h / 2);
      rocks.splice(i, 1);
      bullets.splice(j, 1);
      score += 10;
      break;   // этого камня больше нет — к следующему
    }
  }
}
```

Оба цикла идут **с конца** — мы удаляем элементы прямо во время перебора. `break` обязателен: после удаления камня `rocks[i]` уже другой элемент (или вообще ничего), и проверять его дальше нельзя.

## Взрыв

Функция `explode(x, y)` уже написана — она выбрасывает 25 частиц из центра астероида. Посмотри её код: это почти то же самое, что ты делал в уроке про частицы.

> 🎮 Взрывы — дешёвый способ сделать игру «вкусной». Профессионалы называют это **juice** [джус] — «сок»: тряска экрана, вспышки, частицы, звуки. Механика та же, а играть в разы приятнее.

function rectsCollide(a, b) {
  return a.x < b.x + b.w && a.x + a.w > b.x && a.y < b.y + b.h && a.y + a.h > b.y;
}

function explode(x, y) {
  for (let i = 0; i < 25; i++) {
    const angle = Math.random() * Math.PI * 2;
    const speed = 1 + Math.random() * 3;
    particles.push({ x: x, y: y, vx: Math.cos(angle) * speed, vy: Math.sin(angle) * speed, life: 30 });
  }
}

function update() {
  ship.update(keys);
  ship.cooldown--;
  if (keys[" "] && ship.cooldown <= 0) {
    bullets.push(new Bullet(ship.x + ship.w / 2 - 2, ship.y));
    ship.cooldown = 12;
  }
  for (const b of bullets) b.update();
  bullets = bullets.filter((b) => !b.isOff());

  frame++;
  if (frame % 40 === 0) rocks.push(new Rock(Math.random() * (canvas.width - 40), 2));
  for (const r of rocks) r.update();
  rocks = rocks.filter((r) => !r.isOff());

  // Попадания пуль в астероиды


  for (const p of particles) { p.x += p.vx; p.y += p.vy; p.life--; }
  particles = particles.filter((p) => p.life > 0);
}

## Сложность растёт

```code
function rockSpeed() {
  return 2 + Math.floor(score / 100) * 0.5;
}
```

Каждые 100 очков скорость астероидов растёт на 0.5. `Math.floor(score / 100)` — сколько «сотен» набрано: 0 при 0–99 очках, 1 при 100–199 и так далее.

> 🎮 Плавный рост сложности — главный секрет «ещё одной попытки». Игроку должно быть немного трудно, но не невозможно. Это называется **кривая сложности**.
