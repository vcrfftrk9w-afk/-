@lesson vars-1
title: Переменная — коробка с именем
@theory
В любой игре нужно что-то **запоминать**: сколько у игрока очков, сколько жизней, как зовут героя. Для этого есть **переменные**.

Переменная — это **коробка с наклейкой**. На наклейке — имя, внутри — значение.

```js
let score = 0;
let lives = 3;
let heroName = "Рыцарь";

console.log(score);
console.log(lives);
console.log(heroName);
```

## Как создать переменную

```code
let score = 0;
```

| Часть | Значение |
|---|---|
| `let` [лет] | «пусть» — создаём новую переменную |
| `score` [скор] | имя переменной («счёт») — придумываешь сам |
| `=` | «положить в коробку» (это **не** «равно» из математики!) |
| `0` | значение, которое кладём |

Читается так: **«пусть счёт будет 0»**.

> ⚠️ Знак `=` в программировании означает «запиши значение в переменную». Сравнивать мы будем другими знаками — в модуле про условия.

## Используем переменную

После создания пиши просто имя — **без** `let` и **без** кавычек. Компьютер подставит значение:

```js
let coins = 25;
console.log("Монет: " + coins);
console.log(coins * 2);
```

> ⚠️ Если взять имя в кавычки — получится просто текст: `console.log("coins")` напечатает слово coins, а не 25.

## Почему имена английские?

Имя переменной можно было бы написать и по-русски — JavaScript это позволяет. Но во всём мире принято писать имена по-английски, так код понимают программисты любых стран. Не бойся: у каждого имени в курсе есть перевод — просто наведи на него.

Частые имена в играх: `score` (счёт), `lives` (жизни), `hp` (здоровье), `level` (уровень), `speed` (скорость), `player` (игрок), `enemy` (враг), `coins` (монеты).

@lesson vars-2
title: Меняем значения — очки и жизни
@theory
Переменные называются так, потому что их значение может **меняться**. Игрок собрал монету — очков стало больше. Получил удар — жизней меньше.

Чтобы поменять значение, пиши имя и `=` — уже **без** `let`:

```js
let score = 0;
console.log(score);

score = 10;
console.log(score);
```

## Изменить относительно старого значения

Чаще всего нужно не заменить, а **прибавить** к тому, что было:

```js
let score = 0;
score = score + 10;
console.log(score);
score = score + 10;
console.log(score);
```

Строчку `score = score + 10` компьютер читает так: «возьми текущий счёт, прибавь 10 и положи обратно в счёт».

## Короткие записи

Программисты ленивы, поэтому придумали сокращения:

| Длинно | Коротко | Что делает |
|---|---|---|
| `score = score + 10` | `score += 10` | прибавить 10 |
| `hp = hp - 25` | `hp -= 25` | отнять 25 |
| `damage = damage * 2` | `damage *= 2` | удвоить |
| `lives = lives + 1` | `lives++` | прибавить 1 |
| `lives = lives - 1` | `lives--` | отнять 1 |

```js
let lives = 3;
lives--;
console.log("Осталось жизней: " + lives);
lives++;
console.log("Нашёл сердечко! Жизней: " + lives);
```

> ⚠️ `let` пишется только **один раз** — когда переменная создаётся. Если написать `let score` второй раз, будет ошибка «уже объявлено».

> 🎮 Именно так работают все счётчики в играх: при каждом событии значение переменной увеличивается или уменьшается.

@lesson vars-3
title: const и правила имён
@theory
Кроме `let` есть второй способ создать переменную — `const` [конст], от слова «константа», постоянная.

```js
const maxLives = 5;
const gravity = 0.5;
console.log(maxLives, gravity);
```

Значение `const` **нельзя изменить**. Попробуй:

```js error
const speed = 5;
speed = 10;
```

## Когда что использовать

- `let` — если значение будет меняться: счёт, жизни, координаты героя.
- `const` — если не будет: размер поля, сила гравитации, максимум жизней.

> 💡 Совет профессионалов: по умолчанию пиши `const`, а `let` — только когда точно знаешь, что значение будет меняться. Так меньше случайных ошибок.

## Правила имён

| Правило | ✅ Можно | ❌ Нельзя |
|---|---|---|
| Буквы, цифры, `_` и `$` | `player1`, `max_hp` | `my-score`, `hp!` |
| Не начинается с цифры | `level2` | `2level` |
| Без пробелов | `heroName` | `hero name` |
| Не занятое слово | `myClass` | `let`, `if`, `class` |

**Большие и маленькие буквы различаются**: `score`, `Score` и `SCORE` — три разные переменные.

## Как называть: «верблюжий стиль»

Если имя из нескольких слов, их пишут слитно, а каждое новое слово — с большой буквы. Это называется **camelCase** [кэмел кейс] — «верблюжий регистр», потому что большие буквы торчат, как горбы:

```code
playerSpeed     // скорость игрока
enemyCount      // количество врагов
isGameOver      // игра окончена?
bestScore       // лучший счёт
```

> 💡 Давай понятные имена. `x1`, `a`, `qwe` через неделю никто не вспомнит, а `playerSpeed` понятно сразу.

@lesson vars-4
title: Типы данных — числа, текст, правда и ложь
@theory
У каждого значения есть **тип**. От типа зависит, что с ним можно делать.

| Тип | Как читается | Что это | Пример |
|---|---|---|---|
| `number` | на́мбер | число | `42`, `-7`, `3.14` |
| `string` | стринг | строка (текст) | `"Привет"`, `'меч'` |
| `boolean` | бу́лиан | логический: да/нет | `true`, `false` |
| `undefined` | андефа́йнд | «не определено» | переменная без значения |
| `null` | нал | «пусто» (нарочно) | `null` |

Узнать тип можно командой `typeof` [та́йпоф]:

```js
console.log(typeof 42);
console.log(typeof "42");
console.log(typeof true);
let empty;
console.log(empty);
```

## true и false

`true` [тру] — «правда, да», `false` [фолс] — «ложь, нет». Пишутся **без кавычек**. В играх их используют для флажков:

```code
let isAlive = true;      // герой жив?
let hasKey = false;      // есть ли ключ?
let isPaused = false;    // игра на паузе?
```

> 💡 Логическим переменным принято давать имена на `is` («является»), `has` («имеет»), `can` («может»): `isJumping`, `hasSword`, `canFly`.

## Осторожно: "5" — это не 5

```js
console.log(5 + 5);
console.log("5" + 5);
console.log("5" * 2);
```

`"5"` в кавычках — текст. Плюс его склеивает. А вот `*` склеивать не умеет, поэтому пытается превратить текст в число. Чтобы не гадать, превращай явно:

```js
let text = "10";
let num = Number(text);
console.log(num + 5);
console.log(String(7) + "7");
```

- `Number(...)` [на́мбер] — превратить в число;
- `String(...)` [стринг] — превратить в текст.

> 🎮 Это важно: всё, что игрок вводит с клавиатуры, и всё, что сохраняется в памяти браузера, приходит **текстом**. Перед вычислениями превращай в число!

Если превратить в число не получается, выйдет `NaN` [нан] — «не число» (Not a Number):

```js
console.log(Number("кот"));
```

@lesson vars-5
title: Шаблонные строки — удобный текст
@theory
Склеивать текст через `+` неудобно: легко забыть пробел или кавычку.

```code
console.log("Игрок " + name + " набрал " + score + " очков, уровень " + level);
```

Есть способ лучше — **шаблонные строки**. Они пишутся в **обратных кавычках** `` ` ``, а переменные вставляются через `${...}`:

```js
let name = "Рыцарь";
let score = 120;
let level = 3;
console.log(`Игрок ${name} набрал ${score} очков, уровень ${level}`);
```

## Где обратная кавычка

`` ` `` — это клавиша **Ё** (слева от цифры 1) на **английской** раскладке. Знак `$` — `Shift` + `4` на английской раскладке. Фигурные скобки `{` `}` — `Shift` + `Х` и `Shift` + `Ъ`. Всё это есть и на панели символов под редактором.

## Внутри ${ } можно считать

```js
let coins = 7;
console.log(`Монет: ${coins}, очков за них: ${coins * 15}`);
let hp = 35;
console.log(`Здоровье: ${hp} из 100 (${hp / 100 * 100}%)`);
```

> 💡 Шаблонные строки можно переносить на несколько строк — переносы сохранятся. Удобно для игровых экранов и диалогов.

```js
let hero = "Лучник";
console.log(`=== ${hero} ===
Здоровье: 80
Стрел: 24`);
```

@lesson vars-6
title: Мини-проект — расчёт битвы
@theory
Соберём всё, что знаем о переменных, в маленькую «боевую систему». Так устроены настоящие RPG-игры: у героя и монстра есть характеристики, а программа по формулам считает исход удара.

```js
const heroAttack = 15;
const monsterDefense = 4;
let monsterHp = 50;

const damage = heroAttack - monsterDefense;
monsterHp -= damage;

console.log(`Герой бьёт на ${damage} урона!`);
console.log(`У монстра осталось ${monsterHp} HP`);
```

Обрати внимание:

- характеристики, которые не меняются в бою, — `const`;
- здоровье монстра меняется — `let`;
- урон считается по **формуле** из других переменных. Если поменять силу атаки — урон пересчитается сам.

> 🎮 Профессиональные геймдизайнеры часами подбирают такие числа, чтобы игра была не слишком лёгкой и не слишком сложной. Это называется **баланс**.

## Критический удар

Добавим «крит» — удар с двойным уроном:

```js
const attack = 12;
const critMultiplier = 2;
const critDamage = attack * critMultiplier;
console.log(`Обычный удар: ${attack}, критический: ${critDamage}`);
```

@quiz
? Зачем считать урон формулой `attack - armor`, а не написать сразу 8?
- Так короче
+ Если поменять атаку или броню, урон пересчитается сам
- Компьютер не умеет хранить число 8
= Формулы делают игру гибкой: меняешь одно число — всё остальное подстраивается.
? Что в RPG лучше объявить через `const`?

- Количество монет в кошельке
