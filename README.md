# AI-видеоредактор

Загружаете видео, фото и музыку, пишете обычной фразой, какой нужен монтаж —
получаете готовый ролик.

> «Динамичный вертикальный эдит под бит, нарежь клипово, кинолук, подпись
> «Лето 2026» сверху, 15 секунд»

Фраза превращается в монтажный план, план показывается в интерфейсе (его можно
поправить руками), а рендер выполняет ffmpeg.

## Быстрый старт

```bash
npm install          # вместе с зависимостями скачает ffmpeg и ffprobe
cp .env.example .env # и вписать ANTHROPIC_API_KEY, если он есть
npm start            # http://localhost:3000
```

Ключ не обязателен: без него план собирает встроенный разбор фраз. Он понимает
формат кадра, темп, эффекты, скорость, хронометраж и подписи в кавычках —
просто буквальнее, чем модель.

```bash
npm test             # 32 теста, включая реальные рендеры
```

## Как это устроено

```
фраза + список исходников
          │
          ▼
   планировщик ──► монтажный план (JSON)
   Claude или                │
   локальный разбор          ▼
                      нормализация плана
                      (границы, белые списки)
                             │
                             ▼
                      рендер в три прохода
                             │
                             ▼
                          ролик
```

### Монтажный план

Центральная структура всей системы — обычный JSON:

```json
{
  "title": "Лето 2026",
  "output": { "preset": "reels", "width": 1080, "height": 1920, "fps": 30, "fit": "cover" },
  "clips": [
    {
      "assetId": "…", "start": 2.0, "end": 3.4, "speed": 1,
      "effects": [{ "type": "cinematic", "intensity": 0.7 }],
      "text": [{ "text": "Лето 2026", "start": 0, "end": 1.4, "position": "top", "animation": "pop" }],
      "transition": { "type": "fade", "duration": 0.4 }
    }
  ],
  "music": { "assetId": "…", "volume": 0.5, "fadeIn": 0.6, "fadeOut": 1.5, "duckOriginal": false },
  "audio": { "keepOriginal": true, "originalVolume": 0.8 }
}
```

План приходит от модели, от локального разбора или прямо из интерфейса — и в
любом случае проходит через `server/plan-schema.js`. Там значения зажимаются по
границам, строки сверяются с белыми списками, ссылки на исходники проверяются, а
всё непригодное превращается в понятное предупреждение вместо падения рендера.
Это же место защищает ffmpeg от произвольных строк из ответа модели.

### Рендер

`server/renderer.js` работает в три прохода, а не одним большим `filter_complex`:

1. **Клипы.** Каждый клип отдельным запуском ffmpeg приводится к общим размеру,
   fps и кодекам: обрезка по времени, скорость, вписывание в кадр, эффекты,
   титры. Каждому клипу гарантированно даётся звуковая дорожка — немым
   подставляется тишина, иначе склейка разъезжается.
2. **Склейка.** Если все стыки встык, клипы соединяет демуксер `concat` вообще
   без перекодирования. Как только появляется хоть один переход, собирается граф
   из `xfade` и `acrossfade` со сквозным пересчётом смещений.
3. **Музыка.** Подложка зацикливается до длины ролика, получает фейды и
   подмешивается через `amix`; при `duckOriginal` музыка приглушается под речь
   исходника через `sidechaincompress`.

Такое деление стоит одного лишнего прохода кодирования, но ошибка локализуется в
конкретном клипе, а не во всём графе, и типичный ролик без переходов собирается
почти мгновенно.

### Титры

В сборке ffmpeg из `ffmpeg-static` нет `drawtext`, зато есть libass. Поэтому
подписи генерируются в `.ass` (`server/ass.js`) и накладываются фильтром
`subtitles`. Побочно это оказалось лучше `drawtext`: нормальная кириллица,
переносы, обводка и анимации появления — проявление, «пружинка», выезд снизу,
печатная машинка. Текст пользователя экранируется, чтобы фигурные скобки не
превратились в ASS-разметку.

## Что умеет

**Эффекты** (`server/effects.js`, интенсивность 0–1): чб, сепия, винтаж, сочные
цвета, кинолук, холодный и тёплый тон, контраст, светлее, темнее, размытие,
резкость, виньетка, зерно, глитч, пикселизация, зеркало, инверсия, мягкое
свечение, тряска камеры, наезд, отъезд, Кен Бёрнс, кинополосы, наклон кадра,
стабилизация.

**Переходы**: встык, fade, fadeblack, fadewhite, dissolve, wipe и slide во все
стороны, circleopen/close, radial, pixelize, smooth-варианты.

**Ещё**: 4 формата кадра (9:16, 16:9, 1:1, 4:3), три способа вписывания
(обрезать, вписать с полями, вписать на размытый фон), скорость 0.25×–8×
с корректным питчем звука, музыкальная подложка с фейдами и дакингом,
нарезка одного видео на несколько клипов, ручная правка плана перед рендером.

## API

| Метод | Путь | Что делает |
| --- | --- | --- |
| `GET` | `/api/capabilities` | Списки эффектов, переходов, пресетов; режим планировщика |
| `POST` | `/api/projects` | Создать проект |
| `GET` | `/api/projects/:id` | Состояние проекта: исходники, план, рендеры |
| `POST` | `/api/projects/:id/assets` | Загрузить файлы (multipart) |
| `DELETE` | `/api/projects/:id/assets/:assetId` | Убрать исходник |
| `POST` | `/api/projects/:id/plan` | Собрать план по фразе |
| `PUT` | `/api/projects/:id/plan` | Сохранить правки плана |
| `POST` | `/api/projects/:id/render` | Поставить рендер в очередь |
| `GET` | `/api/jobs/:jobId/events` | Прогресс рендера (SSE) |
| `POST` | `/api/jobs/:jobId/cancel` | Отменить рендер |
| `GET` | `/api/renders/:file` | Забрать готовый ролик |

## Ограничения

- Проекты и очередь живут в памяти одного процесса. Для нескольких инстансов
  `server/projects.js` нужно перевести на БД, а файлы — в объектное хранилище;
  остальной код от этого не зависит.
- Рендерится одна задача за раз: параллельные ffmpeg только отнимают друг у
  друга процессор.
- Нет авторизации — это инструмент для запуска у себя, не для публичного хоста.
- Длительность ролика ограничена 20 минутами, один файл — 512 МБ (настраивается).

## Структура

```
server/
  index.js        HTTP-сервер и маршруты
  config.js       пути, лимиты, пресеты кадра
  ffmpeg.js       запуск ffmpeg/ffprobe, разбор метаданных
  planner.js      план через Claude (tool use)
  heuristic.js    запасной разбор фразы без сети
  plan-schema.js  нормализация и проверка плана
  effects.js      каталог эффектов → фильтры ffmpeg
  ass.js          титры в формате ASS
  renderer.js     три прохода рендера
  projects.js     проекты и исходники
  jobs.js         очередь рендеров и прогресс
public/           интерфейс без сборки
tests/            юнит-тесты и интеграционные рендеры
```

## Браузерная версия (`web/montage.html`)

Отдельный редактор, который работает целиком в браузере, без сервера и без
загрузки файлов куда-либо. Опубликован как артефакт claude.ai.

- **Детектор битов**: энергия баса и полосы → онсет-огибающая → темп по
  «гребёнке» автокорреляции (1–4 периода, опора на бочку) → доли трекером
  на динамическом программировании. Сильная доля — по басу.
- **Поиск дропа**: самый громкий кусок трека с бонусом за резкий вход.
- **Анализ видео**: раскадровка и карта движения; в ролик идут самые
  динамичные куски, склейки внутри исходника не режутся пополам.
- **Velocity и кривые скорости**, эффекты на бите (зум, тряска, вспышка,
  RGB-сдвиг, размытие), 13 переходов, 12 цветовых «луков», 7 стилей эдита.
- **Звук** — через буферы Web Audio с точным расписанием; видео играет
  беззвучно. Часы воспроизведения — аудиоконтекст, поэтому синхрон не плывёт.
- **ИИ-режиссёр**: Claude решает стиль, порядок и надписи (видит кадры
  контактным листом), точные резы по битам делает движок.
- Запись — `MediaRecorder` в реальном времени (MP4 или WebM по браузеру).

Открыть локально: положите файл в любую папку и откройте в браузере — демо
соберётся само из синтезированного бита и генеративной графики.
